# Dagric support

GitHub Issues are for reproducible defects and engineering work—not private
account, payment, license-transfer, or security requests.

- Installation, updates, and everyday help: https://dagric.com/support
- Private business, payment, or account contact: https://dagric.com/contact
- Security vulnerabilities: [SECURITY.md](SECURITY.md)
- Questions and ideas that are not confirmed bugs: use GitHub Discussions
- Reproducible product defects: choose the appropriate GitHub issue form

Before sharing logs, remove passwords, API keys, email addresses, usernames,
serial numbers, network identifiers, and unrelated personal data.
