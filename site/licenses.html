Licenses, honored.

Dagric OS is built from free and open-source software, and we play it straight.

What's inside

  • The base system is Debian 13 and KDE Plasma — thousands of packages under the GPL, LGPL, MIT, Apache-2.0, BSD, and similar licenses. Each package's license text ships on the installed system under /usr/share/doc/<package>/copyright.
  • Bundled open-source extras keep their upstream licenses — for example grub-btrfs (GPL-3.0, vendored from a pinned, checksum-verified release, license text included) and the PhotoGIMP configuration layout (open source, Pro).
  • Dagric's own scripts, branding hooks, and configuration are © DGR Operations; the Dagric name, D monogram, and wallpapers are trademarks/brand assets and may not be used to market derivative products.

Appearance components

The Dagric Styles and Dagric Looks tools use only KDE Plasma's own open-source switches — no third-party theming engines. The Dagric Dark and Dagric Light colour schemes are derived from KDE's Breeze schemes and stay under LGPL-2.0-or-later, with the original authors' notices intact. The Dagric wallpapers are our own work, released under CC BY-SA 4.0. Dagric's own scripts are GPL-3.0-or-later.

Pro's video-wallpaper support vendors Smart Video Wallpaper Reborn (GPL-2.0-or-later, pure QML) from a pinned, checksum-verified release; its licence ships on disk. It plays videos you supply — no media is bundled. We deliberately do not ship any Wallpaper Engine bridge: that software's wallpapers are proprietary, purchased assets we have no right to redistribute.

What's never bundled

Proprietary applications are never preinstalled. Steam (Valve), the NVIDIA driver and DaVinci Resolve (Blackmagic) are only ever installed when you ask — one-click, clearly labeled — fetched from their vendors under their own EULAs.

One exception on that list is worth stating plainly: DRM playback. Netflix, Spotify, Disney+ and Amazon all need Google's Widevine module, so Firefox ships configured to allow it. The module is proprietary and is not on the disc image — Firefox downloads it from Google the first time something needs it, without asking, because otherwise those services would simply appear broken. Turn it off in ☰ → Settings → General → Play DRM-controlled content, and it is never fetched.

One honest exception, the same one Debian's own official media makes: redistributable closed-source device firmware and CPU microcode (Wi-Fi chips, sound, security updates for your processor) ship preinstalled from Debian's non-free-firmware area, because without them Wi-Fi and audio simply don't work on real hardware. Every license text is on disk at /usr/share/doc/<package>/copyright.

Source code

Source for every Debian package in Dagric OS is available from Debian's package archive (matching the versions we ship). Per the GPL, we'll also supply the corresponding source for any GPL-licensed component we distribute — request it via the contact page.

Verifying releases

Every release publishes SHA256SUMS, a GPG signature, and the signing key, so you can prove your download is exactly what we built.

Buying Pro pays for curation, integration, testing, and support — the work — not for exclusive rights over free software. That's the honest trade, and it's why the free edition will always exist.
