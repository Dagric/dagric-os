Licenses, honored.

Dagric OS is built from free and open-source software, and we play it straight.

The Dagric Pro sale terms govern checkout, delivery, the one-machine hosted delivery, guided-upgrade and support service entitlement, refunds, and Dagric branding. They do not replace or narrow the licence of any open-source component. If a sale term conflicts with an applicable open-source licence, that component's licence controls.

What's inside

  • The base system is Debian 13 and KDE Plasma — thousands of packages under the GPL, LGPL, MIT, Apache-2.0, BSD, and similar licenses. Each package's license text ships on the installed system under /usr/share/doc/<package>/copyright.
  • Bundled open-source extras keep their upstream licenses — for example grub-btrfs (GPL-3.0, vendored from a pinned, checksum-verified release, license text included) and the PhotoGIMP configuration layout (open source, Pro).
  • Dagric's own scripts, branding hooks, and configuration are © IMPRESSIONSDIRECT360 LLC. Identified branding artwork is released under CC BY-SA 4.0 for copyright purposes. The Dagric name, D monogram, and logos remain trademarks; the copyright licence does not permit uses that imply an official Dagric product, affiliation, or endorsement.

Appearance components

The Dagric Styles and Dagric Looks tools use only KDE Plasma's own open-source switches — no third-party theming engines. The Dagric Dark and Dagric Light colour schemes are derived from KDE's Breeze schemes and stay under LGPL-2.0-or-later, with the original authors' notices intact. The Dagric wallpapers are our own work, released under CC BY-SA 4.0. Dagric's own scripts are GPL-3.0-or-later.

Pro's video-wallpaper support vendors Smart Video Wallpaper Reborn (GPL-2.0-or-later, pure QML) from a pinned, checksum-verified release; its licence ships on disk. It plays videos you supply — no media is bundled. We deliberately do not ship any Wallpaper Engine bridge: that software's wallpapers are proprietary, purchased assets we have no right to redistribute.

What's never bundled

Proprietary applications are never preinstalled. The Steam client (Valve), NVIDIA driver, and DaVinci Resolve (Blackmagic) are obtained only after you choose a clearly labeled helper, under the provider's own terms. Heroic is an optional GPL-3.0 application installed from Flathub. No GOG, Epic Games, or Amazon Games client, game, account, or store content is included in Dagric OS.

Those product and service names identify compatibility only. IMPRESSIONSDIRECT360 LLC and Dagric OS are not affiliated with, sponsored by, or endorsed by Valve, GOG, Epic Games, Amazon, Heroic Games Launcher, Lutris, or their respective owners.

One exception on that list is worth stating plainly: DRM playback. Netflix, Spotify, Disney+ and Amazon all need Google's Widevine module, so Firefox ships configured to allow it. The module is proprietary and is not on the disc image — Firefox downloads it from Google the first time something needs it, without asking, because otherwise those services would simply appear broken. Turn it off in ☰ → Settings → General → Play DRM-controlled content, and it is never fetched.

Hardware-enablement exceptions. The published 1.0 images include non-open-source device firmware and CPU microcode, Broadcom firmware installer packages, and the non-free libfishcamp1t64 and libsbig4t64 astronomy-camera libraries. Future build source disables live-build's broad automatic firmware scan and selects an explicit reviewed firmware list. Every candidate still requires an artifact-derived inventory and human notice review; the package manifest alone cannot identify files retrieved by an installer.

Corresponding source and notices — release 1.0

This is the source-and-notices route shown beside the held Free, Pro, and post-checkout controls. It is pinned to the two 1.0 “Foundation” images in the release record, not to whatever happens to be on a moving branch.

Dagric layer. The exact build source and Dagric modifications are at commit 3f19b305464b82478ce83db8d970a2abbf326cf9. You can also download that commit's source archive and inspect its pinned release-time licensing map and source-offer notice.

Legal-document supplement. The 1.0 source commit did not contain root COPYING, LICENSE, or THIRD-PARTY-NOTICES.md files. Those documents were added after the release at documentation-only commit 2446b49c76ba13426ae6a4562cc0164286b78040: the complete GPL version 3 text, Dagric repository licensing notice, and third-party notice overview. This supplement documents the applicable terms; it is not presented as source used to build the 1.0 images.

Binary inventories. The Free package manifest and Pro package manifest name each installed binary package and version. The release-pinned source index connects those inventories, both ISO hashes, the Dagric commit, notices, official Debian source services, and the exact-source retrieval procedure in one machine-readable record.

Exact binary-to-source map. The 1.0 record maps all 1,810 Free and 2,537 Pro binary package identities to the exact Dagric release commit or Debian source package and version. Each Debian entry includes an archived .dsc locator, its locally verified SHA-256, and every source-file SHA-256 listed by that signed control file. Dagric-authored packages point to the release-commit source archive and its SHA-256.

Use the machine-readable source index to retrieve and verify a named component through Debian Snapshot. The contact page remains available if you need help obtaining corresponding source for a named image and package. Binary delivery and new sales remain paused while the separate localization, trademark, rights-approval, physical-validation, and release-provenance gates are completed.

Each installed package also carries its applicable copyright and licence notice at /usr/share/doc/<package>/copyright. Dagric will supply corresponding source for any GPL-covered component it conveys for the period required by the applicable licence, at no further charge for network delivery. Source requests identify the edition, ISO filename, and package so the response can stay release-exact.
