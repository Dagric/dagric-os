August 29, 2026 · Update

Family Limits in six languages, and updates that finish the job

A maintenance release. Most of it is work that finishes things which were already half-shipped — the kind of update that adds no line to the feature list and makes the machine noticeably less annoying.

  • Family Limits, in every language we ship (free) — screen time and bedtime for a child's account are now translated into all six: English, German, Spanish, French, Italian and Brazilian Portuguese. They also now reach you the ordinary way, through the update channel, rather than only on a fresh install.
  • The login screen and the installer slideshow speak your language too. Both were English-only, which meant the first two things a new owner saw were the two things that had not been translated.
  • Steam brings its graphics drivers with it. The one-click install now pulls the 32-bit graphics libraries Proton needs, so Proton games run on the free edition instead of failing to start.
  • Kup's versioned backups work. The backup tool offered a versioned mode whose engine was not installed, so choosing it got you nothing. The engine ships now.
  • A camera app. There was no way to check your webcam before a call except by joining the call. Now there is one.
  • Phone pairing is not a Pro feature, and the guide finally agrees. KDE Connect moved to the free edition in the previous release; the guide had gone on marking it Pro ever since.

The update channel itself got the most careful attention. Security updates from Debian install silently, as they always have, and Dagric's own security baseline now updates automatically alongside them — previously it only ever arrived with a new release. Anything that changes how the machine looks or behaves still waits for you to click, which is the line we do not intend to move.

One addition to that: when a kernel update needs a restart before it takes effect, you now get a single quiet message at sign-in saying so. The computer still does not restart itself, and it will not ask twice. Before this, it said nothing at all — so a machine could sit for weeks running the old kernel with the new one already on disk, and no way to know.

July 25, 2026 · Update

Your files follow you: the Migration Assistant

The biggest fear about leaving Windows was never the desktop — it's the stuff. This update makes the move a one-click errand, on every edition:

  • Migration Assistant (free) — open the Hub, pick Migrate from Windows, and Dagric finds the Windows still on your PC, then copies your Documents, Pictures, Music, Videos, Desktop and Chrome / Edge / Firefox bookmarks into your new home. The Windows partition is only ever mounted read-only — nothing there is touched, and it checks free space before it copies a byte.
  • Drive-failure early warning (free) — Dagric now watches every disk's SMART health and warns you in plain language while a backup is still possible. The Security Checkup reports each drive's status alongside your hardening score.
  • A real music library (free) — Elisa, KDE's own player: your music, playlists, album art. No accounts, obviously.
  • Windows in a window (Pro) — for the rare app Wine can't handle: a full KVM virtual-machine stack with UEFI and a software TPM 2.0, so even Windows 11 installs in a box. You bring Microsoft's own ISO; Dagric never bundles Windows.
  • Joplin & ONLYOFFICE (one-click, both editions) — private Markdown notes that live on your disk, and the ribbon-style office suite with the best open-source .docx fidelity.

This release also lands a deep audit of the shipped images — every finding below was verified against the actual ISO contents, not just the source:

  • Silent security updates now actually install. Our own rebranding renamed the OS codename, which quietly stopped unattended-upgrades from matching any Debian security origin — patches were never applied. Fixed and pinned. This is the most important fix in the release.
  • USB Protection is safe to turn on. USBGuard could be pulled in at boot by a companion service with an empty allow-list, which would deauthorize USB keyboards and mice. It now ships fully masked, and a new USB Protection tool allow-lists your attached devices before arming — it can't lock you out.
  • Fingerprint login works — the PAM profile was installed but never enabled, so enrolled fingerprints were ignored.
  • Google Drive in Dolphin can sign in (Pro) — the account provider was missing, making the feature unreachable.
  • Firmware updates appear in Discover, not just the command line. CJK text no longer renders as empty boxes on the free edition. KDE Connect ports moved off untrusted networks, and SSH is no longer pre-opened in the firewall.

Consent installers are now truly per-user (no admin prompt), and every helper's documentation was re-checked against what actually ships.

July 24, 2026 · Update

More Looks, and a curated open-source toolkit

Dagric Looks grows to seven layouts. New this update:

  • Centered (free) — Dagric's clean centered taskbar.
  • Unity (Pro) — a side dock with a global menu bar up top.
  • Duo (Pro) — two panels, top and bottom, for power users.

Pro also gains a hand-picked set of open-source apps that make "own it outright" real — KeePassXC (passwords in a local vault), Syncthing (device-to-device sync with no cloud), Flatseal (control every app's permissions), darktable (RAW photography), Audacity and HandBrake (audio & video), plus qBittorrent and Filelight. The one-click LocalSend helper for private, cross-platform file sharing — like AirDrop, without the cloud — is in the Hub on both editions. See the rest on the Pro page.

July 23, 2026 · Update

Looks, the Hub, and a store

The biggest update yet to Dagric OS 1.0 “Foundation” — the one that turns it from a project into a product:

  • Dagric Looks — switch your desktop layout in one click. Classic and Focus on the free edition; Horizon (top bar + dock) and Command (side dock) on Pro. Every layout keeps the Dagric branding and your files untouched.
  • The Dagric Hub — one window gathering every owner tool: drivers, printers, the Security Checkup, layouts, guides, and Pro's one-click installers.
  • Branding, everywhere — the D monogram now carries through the boot splash, login, wallpaper, launcher button, and system pages.
  • Accessibility that actually speaks — the Orca screen reader now ships with its speech engine. If you can't see the screen, Dagric talks.
  • Honest Windows-app support — the one-click helpers for Bottles, Steam, Heroic (Epic/GOG/Amazon) and ProtonUp-Qt are in the Hub on both editions; Pro adds the tuned Wine and gaming stack underneath them, already installed. Nothing proprietary is bundled — everything installs only when you ask.
  • NVIDIA + Secure Boot, solved — the driver helper now enrolls the signing key and walks you through the reboot screen. No more black screens.
  • Print-to-PDF, L2TP VPNs, encrypted-boot plumbing, and a long list of audited fixes.

Alongside the release: this website, the Pro edition store with Stripe checkout and a published digital-download policy, and GPG-signed downloads on the download page.

July 21, 2026 · Announcement

Introducing Dagric OS: own it outright

Dagr — Old Norse for day. Ric — ruler. Dagric: your computer, your day, your rule.

Dagric OS is a fast, private desktop operating system built on Debian 13 and KDE Plasma — debloated, hardened, and finished. No telemetry exists in it. No ads, no accounts, no forced restarts, no subscriptions. The free edition is a complete daily driver, forever; Pro adds the creative studio, gaming and Windows apps, and the developer stack for a one-time $39. Local, private AI runs on either edition — one click from the Hub.

Version 1.0 "Foundation" ships with UEFI + Secure Boot support, btrfs snapshots with boot-menu rollback, a first-run welcome, and an offline guide. It was built and tested in the open: every release publishes signed checksums, and everything we add is open source.

Try it from a USB stick — your disk stays untouched until you choose otherwise.
