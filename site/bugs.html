Found a bug? Tell us.

This is the address your computer points at. Every Dagric machine carries it in /etc/os-release as BUG_REPORT_URL, so if you arrived here from a crash dialog or from that file, you are in the right place.

Report it

Use the contact page and pick A bug report from the topic list. There is no bug tracker to sign up for and no account to create — a human reads every message.

What to include

The more of this you can paste in, the better the odds of a real fix rather than a guess.

  • What you did, what you expected, what happened instead. Three sentences is plenty. "Opened the Hub, clicked NVIDIA driver, the window closed and nothing happened" is a better report than a page of theory.
  • Whether it happens every time, or only sometimes.
  • Your edition and version. Open Konsole (Meta → type Konsole) and paste the output of:
    cat /etc/os-release
  • A hardware report, if it is anything to do with Wi-Fi, graphics, sound, disks or Secure Boot. Open the Hub and run Check this PC — it produces exactly the report this needs.
  • A screenshot, if there is something to see. Press Print Screen to open Spectacle.

Before you write: two things that fix most of it

Roll back a bad update

If it started after an update, reboot and choose Dagric snapshots in the boot menu. Pick the snapshot from before the update — you are back in minutes, files intact. Then tell us, so the update gets fixed for everyone.

Check the manual first

Meta → Manual opens a page for every application on the machine. Its search understands the Windows names, so Notepad finds the text editor. It works with no internet.

Not a bug?

If you are stuck rather than sure something is broken, the support page lists the common fixes, and the FAQ covers pricing, privacy, hardware, Windows apps and refunds.
