The end of Windows 10

Windows 10 is done. Your PC isn't.

Microsoft ended Windows 10 support and left a perfectly good computer behind. Dagric OS brings it back — fast, private, secure, and yours. No new hardware, no subscription, no account — and the Migration Assistant copies your documents, pictures, music and videos across in one click, then gathers your old bookmarks into one file Firefox imports from its own menu.

And when you ask how long this one lasts: security updates into 2030 — Debian's own published schedule, which Dagric inherits. Roughly five more years out of the machine Windows already gave up on. The dates, in full.

Private by design. Secure by default.

The security baseline is enabled before you change a thing — and Dagric OS does not add telemetry.

Hardened out of the box

AppArmor confinement, a hardened kernel, and a firewall from first boot. Pro adds an opt-in application firewall and USB device controls.

Undo system changes

Automatic snapshots before every update. If an update causes trouble, roll the system back from the boot menu.

Updates, your way

Security patches install silently. The computer never restarts itself — you reboot when it suits you.

The Dagric Hub

Drivers, security checkup, the layout switcher, the guide, and every owner tool — gathered in one friendly window.

Set up before you get there

Printers, scanners, Wi-Fi, Bluetooth, NTFS drives, Print-to-PDF, media codecs and streaming are configured in the image, not left for you to wire up. Whether they work on your particular machine is a different question — Check This PC on the live USB answers it before you install.

For everyone

A talking screen reader you can boot straight from the USB stick, a measured high-contrast theme, and fingerprint login. The conformance report states the gaps as plainly as the features.

Bring your Windows apps.

Dagric runs Windows software in tidy, per-app containers with Bottles — and sets up Steam, Proton, and the Epic/GOG launcher in one click each, on both editions. Pro adds the runtime underneath: Wine, GameMode, MangoHud and 32-bit Vulkan, preinstalled and tuned.
