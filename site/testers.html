Community hardware testing

Put Dagric on your PC.

A virtual machine can prove that an image boots. It cannot prove your Wi-Fi, graphics, audio, Bluetooth, suspend, printer, game controller, display, or firmware. Boot the current signed Dagric OS 1.0 “Foundation” image from a USB stick and tell us what happens.

Safest first step: use the live USB before installing. It lets you test Dagric without writing to your internal drive. If you later install, back up anything you cannot replace first — an operating-system install changes disks by design.

Three steps

  1. Download and verify. Get the Free image from the download page. The same page has the signed SHA-256 verification instructions.
  2. Write a USB, then boot it. Pick the USB device from your firmware boot menu; do not install until you have tried the live desktop. The getting-started guide walks through the full process.
  3. Run “Check This PC”. It is on the live desktop and creates a report about the hardware in front of you without touching the internal disk.

What would help us most

Basics

Does it boot? Do Wi-Fi, Ethernet, sound, Bluetooth, display brightness, touchpad/mouse, keyboard, sleep and wake work as expected?

Real-world work

Try a browser video, a USB drive, a printer if you have one, an external display, and the apps you actually use. Gamers: test the game and Proton setup you care about, not a synthetic benchmark alone.

Install only when ready

If you choose to install, test reboot, updates, snapshots, and the features you depend on. Keep the initial report and note whether the problem existed on the live USB or began after installation.

Known limits, plainly stated

Dagric does not claim every Windows program or every PC works. The release proof page separates virtual-machine evidence from hardware testing that still needs community coverage.

Send useful feedback

Use Contact, choose A bug report, and include:

  • what you did, what you expected, and what happened instead;
  • whether the issue happens every time;
  • the output of cat /etc/os-release;
  • the Check This PC report for hardware, graphics, network, disk or Secure Boot problems; and
  • a screenshot or short video if the problem is visible.

You can also read the complete bug-report guide. Do not send passwords, private keys, recovery codes, or personal files. If you hit a security vulnerability, choose the security topic on Contact instead of posting sensitive details publicly.

Something broke after an update? Reboot and choose Dagric snapshots in the boot menu, then pick the snapshot from before the change. Your personal files are not part of that rollback. Tell us what happened so the update can be corrected for everyone.
