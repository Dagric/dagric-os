For reviewers and press

Test it, and tell people.

Dagric OS is a Debian 13 desktop with KDE Plasma, built for the person leaving Windows 10 rather than for someone who already runs Linux. There is a free edition and a Pro edition at a one-time $39. It is made by DGR Operations, an independent company in the United States.

This page is not a pitch. It exists so a hands-on test is easy to run and hard to get wrong: where the ISO is, how to check it is ours, what to click in what order, and — the part most of these pages leave out — a list of the things we ship that we have not yet proven. If you find a limitation on this page after you find it on the machine, we have wasted your time and earned none of your trust.

The two editions are one system, not two. Pro is the same base with the creative, gaming, developer and Windows-app suites already installed, and all seven desktop layouts rather than three. Anything you find wrong in one edition is almost certainly wrong in the other, so a review of the free edition is a review of the product.

Download and verify

Both editions are on the download page. The free ISO is a direct link — no form, no email address, no account. The Pro ISO is delivered after checkout; if you need it for a review, say so through the contact form.

Please verify before you write about it — a corrupted download is indistinguishable from a bad product until you check. Put SHA256SUMS, SHA256SUMS.sig and the signing key in the folder holding the ISO, then run the three commands the download page gives:

gpg --import dagric-signing-key.asc
gpg --verify SHA256SUMS.sig SHA256SUMS
sha256sum -c SHA256SUMS

On Windows, without installing anything: Get-FileHash .\dagric-os-1.0-amd64.iso in PowerShell, then compare the hash it prints against the matching line in SHA256SUMS. That checks the file arrived intact; it does not check who signed it, so use the GPG route if the provenance is part of what you are testing.

The signing key's fingerprint is published on the security page. Check it there rather than trusting the copy you just imported — a key that vouches for itself vouches for nothing.

How to test it properly

In this order. Steps two and three are the ones most reviews skip, and they are the two that decide whether the rest of the test means anything.

  1. Write the ISO to a USB stick. 8 GB or larger. Rufus or balenaEtcher on Windows; the Disks utility or dd on Linux. Write the image as-is — it is a hybrid ISO and needs no special mode.
  2. Boot the live session. Both UEFI and legacy BIOS machines boot from the same stick. The whole desktop runs from the stick with nothing written to your disk, so this step is reversible by pulling the stick out.
  3. Run “Check This PC” before you install anything. It is an icon on the live desktop, sitting right beside the installer. It reports in plain language on Wi-Fi and network, graphics and screen, sound, camera and printer, whether Secure Boot is on, the battery if it is a laptop, and whether your drives have room. It mounts nothing and unlocks nothing. This is the tool that answers “will it work on this machine”, and a spec list cannot — so run it on every machine you test, including the ones you expect to fail.
  4. Run the installer. The other icon on the live desktop. It names all of its steps up front and writes nothing to the disk until you confirm at the Summary step, so every screen before that one can be backed out of. Worth testing both Erase disk and Install alongside if you have a machine to spare.
  5. Let the first-run wizard run. It opens by itself at the first sign-in after install — six steps: Welcome, How it looks, Text size, The taskbar, Add your apps, You're ready. Every step can be skipped and everything it sets can be changed later.
  6. Open the Dagric Hub. Press Meta, type Hub. This is the one window gathering the owner tools: graphics drivers, Finish Setup for printers, the Security Checkup, the layout switcher, and the one-click installers for Steam, Bottles, Heroic and Ollama. Nothing proprietary is bundled — those install only when you click them, which is a claim worth checking rather than repeating.
  7. Switch layouts in Dagric Looks. In the Hub under Appearance, or press Meta and type Looks. Three layouts on the free edition, all seven on Pro. Switching keeps your apps, files and settings, and switching back is one click — which is the claim to try to break.
  8. Break something, then roll it back. Reboot, and in the boot menu open Dagric snapshots, then pick the snapshot from before the change. This works on the default btrfs install only: choose ext4 at the Partitions step and there is no rollback at all, which is a caveat we would rather you printed than discovered.

What we have tested, and what we have not

This is the section we would most like you to read. The left column is what the product does; the right column is how far it has actually been taken, which is not the same thing.

WhatHow far it has been taken
UEFI and BIOS installTested — both firmware modes, end to end, in the virtual-machine harness.
The installerTested — run through every step to a booting system, in a virtual machine.
First-run wizardTested — run end to end after a fresh install.
Dagric Looks layoutsTested — applied and switched between, in a virtual machine.
Snapshot rollbackTested — rolled back from the boot menu on a default btrfs install, in a virtual machine.
Six-language coverageTested — the desktop and the guide in English, German, Spanish, French, Italian and Brazilian Portuguese.
AccessibilityTested — a vendor self-assessment checked against the built image, published in full with its gaps as the conformance report. It is not an independent audit and does not claim to be.
Secure Boot with enforcing firmwareNot yet verified — it ships, and it has only ever been exercised in virtual machines. It has never booted on a physical machine with Secure Boot actually enforcing.
Full-disk-encryption installNot yet verified — the encrypted install path ships and has not been run end to end on real hardware.
A live screen-reader passNot yet verified — Orca ships with its speech engine, and the build refuses to produce an image if the speech chain is broken. Nobody who depends on a screen reader has sat down with it and told us what it is like.
Wi-Fi and GPU compatibilityNot yet verified — there is no broad hardware matrix. What we know is what Debian 13 supports; we have not measured it across a range of real machines.

The four rows marked not yet verified are shipped, not proven. They work in a virtual machine, and a virtual machine is not a laptop. We would far rather a reviewer found the gap than a customer did — so if one of them breaks on your hardware, that is a real finding, it belongs in your piece, and we will not write to argue with it. The full list of what we know is unfinished is on the security page.

Known limitations

Not of the software — of the project around it. These are the fair things to hold against us, stated before you have to find them.

  • Nobody independent has reviewed it. The project is new, the domain was registered in July 2026, and there is not one third-party test of Dagric OS in existence. Any confidence in it currently rests on our own word, which is exactly the wrong thing for it to rest on.
  • The source repository is not currently public. Dagric is assembled from Debian packages, and the GPL source for every one of those is available from Debian itself. The sources for the in-house packages — the Hub, Looks, the first-run wizard, the hardware check — are supplied on request through the contact form. That is a weaker answer than a public repository and we are not going to pretend otherwise.
  • There is no public issue tracker. Bug reports go through the bug page and reach a person rather than a queue. The cost is that you cannot read a list of what else is currently broken, and you have only our summary of it.
