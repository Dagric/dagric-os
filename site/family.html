What a household actually gets

The same Pro edition on each computer — not a shared pool, not a cut-down build. Every machine gets all of it.

The creative suite, on each machine

GIMP with PhotoGIMP's Photoshop-style layout, Krita, Inkscape, Kdenlive, Blender, OBS Studio, darktable for RAW photos, Audacity and HandBrake — preinstalled and working on first boot, on every computer the licence covers.

Windows software

Wine 10.0 and winetricks preinstalled, including 32-bit Wine for classic .exe installers. The free edition ships no Wine at all, so this is a real difference on each machine — the household's one stubborn Windows program has somewhere to run whichever computer it lands on.

The gaming runtime

The Mesa Vulkan drivers in both 64- and 32-bit, where the free edition ships the Vulkan loader with no Mesa driver behind it, plus GameMode, MangoHud with goverlay, and Lutris. The launchers themselves — Steam, Heroic, Bottles — are one click on the free edition too; what Pro puts underneath them is the part that shows up as frames.

Windows in a window

A full KVM virtual-machine stack with UEFI and TPM 2.0, so even Windows 11 installs inside Dagric. Genuinely Pro-only: the hypervisor, virt-manager and the TPM emulator are not on the free edition. You bring the Windows ISO; we never bundle it.

The developer stack

Docker and Compose, Podman, Distrobox, build-essential, Git, Python and SSH on whichever machine in the house needs them. Podman runs rootless immediately; the Docker daemon and the SSH server ship switched off until someone turns them on — one command each — so nothing in the house listens uninvited.

The security suite

The opt-in OpenSnitch application firewall, and USB Protection that allow-lists your own devices before it blocks anything. Armed when you choose, on each machine, never at the cost of somebody's keyboard.

Full office and CJK fonts

The complete LibreOffice suite, where the free edition ships Writer, Calc, Impress and Draw — plus Noto CJK — the 89 MB set that adds proper Japanese and Chinese typographic forms and Serif CJK. The free edition already renders Chinese, Japanese and Korean without boxes; this is the typography on top. Ordinary accented and symbol text renders correctly on both editions.

All seven Looks and Styles

Seven desktop layouts against the free edition's three, and seven colour Styles against four — so the computer in the study and the computer in the kitchen do not have to look like the same computer.

Scheduled restore points

Timeshift restore points that you schedule, on top of the automatic snapshot-before-every-update that both editions already take. Worth more across several machines than one: it is the difference between fixing a household's computer and rebuilding it.

The privacy toolkit

KeePassXC for a local password vault only you hold, Syncthing to sync files directly between the household's own machines with no cloud and no account, Flatseal to see what each app is allowed to touch, qBittorrent and Filelight.

How the licence works

Exactly like a single licence, with one number changed. There is nothing new to learn and nothing new to install.

One purchase, one receipt

You buy once and get one purchase code, starting with cs_. That same code claims every machine the pack covers — there are no per-computer keys to keep track of, and nothing to hand out or lose.

Claimed the same way

On each computer: install Dagric OS, open the Dagric Hub, pick Upgrade to Pro — already bought it?, and paste the code. That machine becomes Pro with its files and settings untouched. It is the same tool, the same steps and the same screens as a single licence — it just does not stop after the first computer.

Counted, not tracked

Each claimed machine is recognised by an anonymous fingerprint, never a serial number: a one-way hash of a hardware id, salted with your purchase, so the value means nothing outside that one receipt. We learn that a machine claimed the licence. We do not learn which machine, or whose. The privacy page has the detail.

Reinstalling is free

Wiping and reinstalling a computer you already claimed does not use up another slot — the same machine produces the same fingerprint and is recognised. Reinstall the household's computers as often as you like.

Verified once, then never again

Each machine checks the purchase the one time it is claimed, and after that there is no recurring licence check: no recurring activation, no expiry, no server any of your computers needs permission from to keep working. Unplug the house from the internet and every one of them still boots.

When a computer is replaced

A machine that died, a laptop that was replaced, a virtual machine that moved — write to support and the slot moves over at no cost. It is a message, not a process. The same is true for the small number of machines with no stable hardware id, where the fingerprint changes on reinstall; the upgrade tool tells you if yours is one.

What "one household" means, plainly: the computers in one home, owned or managed by the people who live there. It is not a site licence for an office, a school or a club, and it is not something to split with friends at other addresses — if that is what you need, write to us and we will work something out honestly rather than pretend a family licence covers it.

Don't buy the Family Pack if…

Six reasons to keep your money. We would rather lose the sale than take it from somebody who was going to want it back.

…you came here for the parental controls

They are free on every edition and they are not part of this purchase. Buying this adds nothing to them. The full state of that is above — and the honest answer for a parent with one computer is the free edition, at no cost.

…you have one computer

Then this is strictly worse than the single licence at $39, which is the same software. The Family Pack only makes sense once there is a second machine, and it will still be there when there is.

…you have fewer computers than the pack covers

The pack covers FAMILY_MACHINES_PLACEHOLDER machines. If your house has two and will keep having two, do the sum: two single licences cost $78, and if that is less than the pack, buy the two. We are not going to pretend otherwise to move the bigger number.

…those computers are nearly full

Pro needs 40 GB free on each machine against the free edition's 25 GB, because the creative suite, the Wine and gaming runtimes and the CJK fonts are really on the disk. Across a house of older laptops that is a constraint that repeats, and it will not get better after you have paid. Check every machine before you buy, not after.

…you only wanted Steam, Bottles, Heroic or Ollama

All four are one click from the Hub on the free edition, on every computer in the house, for nothing — and so are ProtonUp-Qt, ONLYOFFICE, Joplin, LocalSend, Cryptomator and Upscayl. If that list is the whole reason, install free everywhere and keep your money. Pro's gaming value is the 32-bit Vulkan, GameMode and MangoHud underneath them.

…it is not really one household

This licenses the computers in one home. It is not an office, school, club or reseller licence, and splitting it across addresses is not what it is for. If you need to cover an organisation, ask us — there is an honest answer and this page is not it.
