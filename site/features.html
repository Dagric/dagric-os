Everything, already working

Built like it's your machine.

Because it is. Every feature below ships enabled and quiet — no setup scavenger hunt, no settings to un-break.

Real-time footage. One running desktop, with motion and a spoken walkthrough—no composite screens or burned captions.

Privacy that isn't a setting

Zero Dagric telemetry

The OS sends no product analytics, crash reports or usage profiles to Dagric. It still makes documented network requests for things such as updates and firmware metadata. The privacy page lists each one, what it sends and how to switch it off.

No accounts, no ads

Your desktop works without signing in to anything, and no surface of it is rented to advertisers.

Local AI, if you want it

The Hub offers optional Ollama setup on either edition. Local models can run on your hardware; downloads need a connection. Review any model or service you add before sharing sensitive prompts.

Security you don't have to assemble

Hardened by default

AppArmor mandatory access control active, hardened kernel settings, firewall on — from the first boot, before you change a thing.

Updates on your terms

Security patches install silently in the background. The machine never restarts itself.

Verified releases

Every ISO ships SHA-256 checksums signed with our GPG key, so you can prove your download is untouched.

Secure Boot test record

The signed boot chain has been exercised in virtual firmware. Physical-machine validation is still pending. NVIDIA driver setup includes guidance for enrolling a signing key at reboot. See the security details before changing firmware settings.

Security Checkup

One click runs a Lynis audit and shows your hardening score — security you can see.

Optional device and app controls (Pro)

OpenSnitch provides application firewall controls. USB Protection lets you review and allow connected devices. Test your keyboard, mouse, and recovery path before enforcing device restrictions.

The core security tools are included in Free. Optional app and USB controls are Pro features.

Hard to break, easy to undo

Snapshots before updates

On the default btrfs install, Dagric snapshots the system before changes land.

Roll back from the boot menu

Something went sideways? Pick Dagric snapshots at boot and you're back to before — files intact, minutes flat.

Backups included

Simple file backup on Free; Borg + Vorta + rclone on Pro for versioned backups to any disk or cloud.

Drive-failure early warning

Dagric watches every disk's SMART health in the background and tells you in plain language — before it dies, while backing up still works. The Security Checkup shows each drive's status any time.

Comfortable from minute one

Migrate from Windows

One click in the Hub finds the Windows still on your PC and copies your Documents, Desktop, Pictures, Music and Videos into your new home — plus your Chrome, Edge and Firefox bookmarks, gathered into one file Firefox imports from its own menu. Windows is only ever read — never touched.

Dagric Looks

Switch your whole desktop layout in one click — classic taskbar, minimal bar, or Pro's dock layouts. Switch back anytime.

Dagric Styles

Set the desktop's mood in one click: light or dark, any accent color, Dagric wallpapers, even glassy blur effects. Four styles on the free edition (including a measured High Contrast), all seven on Pro. Mix any Style with any Look — and Reset brings back standard Dagric in one click.

The Dagric Hub

Drivers, printers, security, layouts, guides — every owner tool gathered in one window instead of scattered across menus.

Set up before you get there

Printers (with Print-to-PDF), scanners, Wi-Fi, Bluetooth, media codecs, streaming, NTFS/exFAT drives, firmware updates — and a real music library (Elisa), not just a file player — are configured in the image, not left for you. Run Check This PC from the live USB to see how your own machine fares before anything is installed.

Work with familiar documents

LibreOffice and Office-metric fonts help with common Word and Excel files. Check complex formatting, macros, and fonts with your own documents before switching. Full LibreOffice is included on Pro.

Windows-switcher care

Taskbar where you expect it, double-click as you expect it, NumLock on, task manager on Ctrl+Shift+Esc.

Accessibility tools

A talking screen reader (bootable from the live USB), a measured high-contrast theme, fingerprint login support, and keyboard-friendly design. Read the conformance report — including the three things it does not do.
