From download to desktop, in about 20 minutes.

No experience needed. You'll make a USB stick, try Dagric OS without touching your computer, and install it only when you're ready.

What you need

  • A USB stick, 8 GB or larger (it will be erased)
  • A PC from roughly the last 12 years (64-bit, 4 GB+ RAM recommended)
  • The Dagric OS ISO you downloaded

Step by step

  1. Write the ISO to USB. On Windows, use Rufus (pick the ISO, pick the stick, press Start) or Ventoy (install once, then just copy ISOs onto the stick). On macOS/Linux, balenaEtcher works the same way.
  2. Boot from the USB. Restart with the stick plugged in and tap the boot-menu key as the machine starts:
    MakerKey
    Dell, Lenovo, AcerF12
    HPF9 (or Esc)
    ASUS, MSI, GigabyteF8 / F11 / Del
    Most othersF12, F10 or Esc
    Choose the USB entry (the one that says UEFI if both appear).
  3. Try it, risk-free. Pick Live system in the menu. You get the complete Dagric desktop running from the stick — browse, test Wi-Fi and sound, open apps. Nothing on your disk changes.
  4. Install. When you're ready, double-click Install Dagric OS on the desktop. The installer walks you through language, time zone, and disk choice. On a blank machine choose Erase disk; alongside Windows, use Install alongside.
  5. Reboot and enjoy. Remove the stick when asked. First login, Dagric greets you, offers the NVIDIA driver if you have that hardware, and the Dagric Hub gathers every setup tool in one place.
Secure Boot? Leave it on — Dagric OS boots with Secure Boot. If you later install the NVIDIA driver, Dagric walks you through the one-time key-enrollment screen at reboot (choose Enroll MOK → Continue, enter the password you set).

Verify your download (recommended)

Every release is checksummed and GPG-signed. On Linux/macOS:

gpg --import dagric-signing-key.asc
gpg --verify SHA256SUMS.sig SHA256SUMS
sha256sum -c SHA256SUMS

Files: SHA256SUMS · SHA256SUMS.sig · signing key. On Windows, compare Get-FileHash the.iso in PowerShell against the list.

After you're in

  • Dagric Hub (press Meta, type “Hub”) — drivers, security checkup, layouts, the guide.
  • Dagric Looks — switch your desktop layout in one click.
  • Discover (the bag icon) — thousands of free apps, one click to install.
  • Snapshots — on the default btrfs install, Dagric snapshots before updates; roll back anytime from the boot menu under Dagric snapshots.
