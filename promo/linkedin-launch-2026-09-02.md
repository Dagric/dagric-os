## First founder post

I’ve been building Dagric OS because too many capable PCs are treated like they have reached the end of their useful lives.

Dagric is a privacy-first desktop project built on Debian + KDE. The goal is simple: give supported hardware a clear, capable desktop without product telemetry, forced-account thinking, or a maze of recovery options.

This is not a claim that every PC, driver, or game will work perfectly. It is an invitation to test the live USB, see the desktop running, and help make support better on real hardware.

The first tester wave is open: https://dagric.com/testers
