DAGRIC — User Guide

Everything you need for your first week. This page works offline.

Installing apps

Open Discover (the bag icon in the taskbar). Search, click Install, done. Everything is free, checked, and removable. Removing an app actually removes it — nothing comes back on its own.

Updates

Security updates install silently in the background. When bigger updates are ready, a tray icon appears — apply them whenever you like. Dagric never restarts your computer for you.

Wi-Fi, sound, displays

All in the system tray (bottom right). Click the network icon to join Wi-Fi, the speaker for volume and output device, and the display icon when you plug in a monitor or projector.

Printers

Plug the printer in (or have it on the same Wi-Fi), then open System Settings → Printers → Add Printer. Most printers are detected automatically.

Making it yours: Looks and Styles

Two tools shape the desktop, both one click and both reversible. Dagric Looks changes the layout — where the taskbar, dock and menus sit. Dagric Styles changes the mood — light or dark colors, accent color, wallpaper, and window effects like glassy blur. They combine freely: a Mac-style dock in deep Midnight, a classic taskbar in warm Dawn. Find both in the launcher or the Hub, and pick Reset in Styles any time to return to standard Dagric.

Bringing your files from Windows

Open the Dagric Hub and pick Migrate from Windows (or run dagric-migrate). It finds the Windows still on this PC, shows your Documents, Pictures, Music, Videos, Desktop and browser bookmarks, and copies what you pick into your new home folder. Windows is only ever read — nothing there is touched, so you can always boot back into it.

Your Windows drives and USB sticks

They just work. Plug in a USB stick or external drive (including NTFS-formatted Windows drives) and it appears in Dolphin, the file manager (folder icon in the taskbar).

Keyboard shortcuts worth knowing

  • Meta (the ⊞ key) — open the app launcher
  • Ctrl+Esc — system monitor (the task-manager reflex)
  • Meta+E — file manager
  • Print Screen — screenshots with Spectacle
  • Meta+L — lock the screen

Pairing your phone (Pro)

KDE Connect links your phone to this PC for notifications, file transfer and clipboard sharing. For your safety its ports are open only on networks you mark as Home — never on café or airport Wi-Fi. If pairing doesn't find your phone, open System Settings → Firewall and set the current connection's zone to home.

USB Protection (Pro)

Open the Hub and choose USB Protection to block malicious USB devices (the kind that pretend to be a keyboard and type commands). Plug in everything you normally use first — Dagric remembers those and blocks only strangers. Run it again any time to refresh the list or switch protection back off.

Backups & drive health

On Dagric Pro: Vorta makes encrypted backups to a drive or server, and rclone connects to Google Drive, Dropbox, OneDrive and 70+ other services. Timeshift takes system restore points — if an update ever misbehaves, roll back to yesterday. On every edition, Dagric watches your drives' SMART health and warns you in plain language if one starts failing — and the Security Checkup shows each drive's status any time.

Running Windows programs (Pro)

Double-click many .exe files and Wine runs them. For games, install Steam with one click from the Dagric Hub (it is never bundled), then enable Proton under Settings → Compatibility. The dagric-gaming command adds the community Proton-GE build. And for the rare app that won't run under Wine, Windows in a window: pick it in the Hub (dagric-vm) to enable virtual machines and run real Windows safely inside Dagric.

Terminal helpers that ask before doing anything: sudo dagric-drivers (NVIDIA), dagric-migrate (bring files from Windows), dagric-get-resolve (DaVinci Resolve), dagric-ai (private local AI), dagric-gaming (Proton-GE), dagric-vm (virtual machines, Pro).

Getting help

Visit dagric.com/support. Your system details for any support request: open Konsole and run cat /etc/os-release.
