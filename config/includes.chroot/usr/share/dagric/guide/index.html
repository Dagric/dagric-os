DAGRIC — User Guide

Everything you need for your first week. This page works offline.

Installing apps

Open Discover (the bag icon in the taskbar). Search, click Install, done. Everything is free, checked, and removable. Removing an app actually removes it — nothing comes back on its own.

Updates

Security updates install silently in the background. When bigger updates are ready, a tray icon appears — apply them whenever you like. Dagric never restarts your computer for you.

Wi-Fi, sound, displays

All in the system tray (bottom right). Click the network icon to join Wi-Fi, the speaker for volume and output device, and the display icon when you plug in a monitor or projector.

Printers

Plug the printer in (or have it on the same Wi-Fi), then open System Settings → Printers → Add Printer. Most printers are detected automatically.

Your Windows drives and USB sticks

They just work. Plug in a USB stick or external drive (including NTFS-formatted Windows drives) and it appears in Dolphin, the file manager (folder icon in the taskbar).

Keyboard shortcuts worth knowing

  • Meta (the ⊞ key) — open the app launcher
  • Ctrl+Esc — system monitor (the task-manager reflex)
  • Meta+E — file manager
  • Print Screen — screenshots with Spectacle
  • Meta+L — lock the screen

Backups

On Dagric Pro: Vorta makes encrypted backups to a drive or server, and rclone connects to Google Drive, Dropbox, OneDrive and 70+ other services. Timeshift takes system restore points — if an update ever misbehaves, roll back to yesterday.

Running Windows programs (Pro)

Double-click many .exe files and Wine runs them. For games, open Steam — enable Proton under Settings → Compatibility to play Windows games. The dagric-gaming command adds the community Proton-GE build.

Terminal helpers that ask before doing anything: sudo dagric-drivers (NVIDIA), dagric-get-resolve (DaVinci Resolve), dagric-ai (private local AI), dagric-gaming (Proton-GE).

Getting help

Visit dagric.com/support. Your system details for any support request: open Konsole and run cat /etc/os-release.
