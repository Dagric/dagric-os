Check This PC

What is inside this computer, whether Dagric will run well on it, and which parts need a driver.

On Windows this wasPC Health Check — the app that told you this PC could not have Windows 11

What it is

Check This PC reads the machine and writes you a plain-language report: how much memory and disk you have, what graphics chip and screen, which network and Wi-Fi cards, cameras, and every drive attached. It compares the numbers against what Dagric actually needs and tells you whether you are comfortable, tight, or short.

It changes nothing. It installs nothing, downloads nothing, and does not need the internet. It only looks.

It answers a different question depending on when you run it. From the live USB stick, before you install, it answers will this work on my computer? Afterwards it answers why is this one part not working? The Hub words the entry differently in each case for exactly that reason.

Five things you will actually do

  1. Run it before you install

    Boot the USB stick, open the Dagric Hub, and pick Check this PC — will Dagric work here? This is the cheapest way to find out whether your Wi-Fi card needs firmware, before you have committed anything to the disk.

  2. Read the memory and disk lines

    Dagric wants at least 3500 MB of memory and is comfortable from 7000 MB. It needs 25 GB of disk at minimum, is comfortable from 60 GB, and Pro wants 40 GB because of the creator applications. The report prints these numbers next to yours rather than just saying pass or fail.

  3. Look for missing firmware

    There is a section headed firmware files the kernel could not load. That list is the single most useful thing in the report: a Wi-Fi card, a graphics chip or a fingerprint reader that needs a firmware blob Debian cannot ship will appear there by name, and the guide's troubleshooting section covers what to do about it.

  4. Check Secure Boot before you worry about it

    The report says whether Secure Boot is on and whether the firmware is enforcing. Dagric ships a signed boot chain and works with it enabled; you do not need to turn it off. The line matters if you later install the NVIDIA driver, because an unsigned kernel module will not load under enforcing Secure Boot until it is enrolled.

  5. Save the report before you ask for help

    The Save button writes the whole thing, including the technical summary, to dagric-hardware-check.txt on your Desktop. Send that file with any support request — it answers most of the questions anyone would ask you first. From the live USB, save it to a USB stick or a phone: the Desktop there is in memory and disappears when you reboot.

One thing that will surprise you

It does not tell you your computer is too old. That is the whole reason it exists. The Windows tool with the same job handed out a verdict — unsupported processor, no TPM 2.0, buy a new machine — and a great many perfectly good computers were retired on the strength of it.

This one prints what it found and what Dagric needs, side by side, and lets you read them. A machine that falls short on one line usually still installs and runs; it just tells you which line, so you can decide rather than be told.

Where to find it

Dagric Hub → Check this PC, launcher → Check This PC, or dagric-hardware-check. With no desktop session it prints the same report to the terminal instead of opening a window, so it works over SSH and in a recovery shell.
