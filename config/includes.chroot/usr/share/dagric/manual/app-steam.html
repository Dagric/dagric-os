Games and Windows programs

SteamADD-ON

Your Steam library, running on Linux — usually with no effort at all.

On Windows this wasSteam on Windows

What it is

Steam is Valve's game store and launcher, and on Linux it carries Proton: a compatibility layer that runs Windows games without you doing anything. This is the same technology that powers the Steam Deck, which is why Linux gaming stopped being a hobby project a few years ago.

Most of your library will simply work. Some of it will not, and the honest dividing line is anti-cheat: a number of competitive multiplayer games refuse to run on Linux because their anti-cheat vendor has not enabled it.

Getting it

Steam is never bundled with Dagric. Valve's Subscriber Agreement means nobody may redistribute it, so an operating system that ships it preinstalled is breaking that agreement. Dagric installs it only when you ask.

Open the Dagric Hub → Steam, or run dagric-get-steam. A terminal window explains what Steam is, asks yes or no, and then asks for your administrator password. It enables 32-bit library support and installs Debian's steam-installer; Steam finishes updating itself on first launch.

On Dagric OS Pro the 32-bit graphics and Wine libraries Steam needs are already in place, so the download is small. Steam is also on Flathub if you would rather have it sandboxed — search for it in Discover.

Five things you will actually do

  1. Turn Proton on

    Steam → Settings → Compatibility → tick Enable Steam Play for all other titles and pick the newest Proton. Without this, only games with native Linux builds appear playable.

  2. Check whether a game works before you buy it

    protondb.com collects reports from players by game, with a rating and the tweaks people needed. Check it first; it is the single most useful habit in Linux gaming.

  3. Point Steam at a second drive

    Settings → Storage → add a library folder on the other disk. Games can be moved between libraries without redownloading.

  4. Force a specific Proton version for one game

    Right-click the game → Properties → Compatibility → tick the override and choose. Some older games run better on an older Proton, and ProtonDB will tell you which.

  5. Add launch options

    Same Properties window, General → Launch Options. gamemoderun %command% applies the performance governor; mangohud %command% adds the FPS overlay. See game performance tools.

One thing that will surprise you

Games with kernel-level anti-cheat will not run, and no amount of configuration changes that. Some titles — Valorant, and a handful of large competitive shooters — are blocked by the publisher's decision, not by a Linux limitation; the anti-cheat vendors ship Linux support and the publisher chooses whether to switch it on. If one of these is the game you play every evening, check before you wipe Windows. Everything else about Steam here is unremarkable, which is the good news.

Where to find it

After installing: launcher → Steam. Before installing: Dagric Hub → Steam.
