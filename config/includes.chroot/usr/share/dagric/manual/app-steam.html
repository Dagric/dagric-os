Games and Windows programs

SteamADD-ON

Optional access to your Steam library, with compatibility checked title by title.

On Windows this wasSteam on Windows

What it is

Steam is Valve's game store and launcher, and on Linux it provides Proton, a compatibility layer that can run many Windows games on Linux. Results vary by title, hardware, drivers, anti-cheat and other online services. A native Linux version or a Proton option is not a guarantee that every mode or feature works.

Getting it

Steam is not bundled with Dagric. It is a proprietary third-party client, so Dagric leaves the decision and download to you. Valve's current terms govern the client, account and content.

Open the Dagric Hub → Steam, or run dagric-get-steam. A terminal window explains what Steam is, asks yes or no, and then asks for your administrator password. It enables 32-bit library support and installs Debian's steam-installer; Steam finishes updating itself on first launch.

On Dagric OS Pro the open-source 32-bit graphics and compatibility dependencies are already in place. Steam is also available through Flathub; compare the package source and sandbox permissions before choosing that route in Discover.

Steam and related marks belong to Valve Corporation. Dagric is an independent project and is not affiliated with or endorsed by Valve.

Five things you will actually do

  1. Turn Proton on

    Steam → Settings → Compatibility → tick Enable Steam Play for all other titles and pick the version recommended for the title. Steam's labels and defaults can change, so use its current compatibility page as the source of truth.

  2. Check whether a game works before you buy it

    protondb.com collects reports from players by game, with a rating and the tweaks people needed. Check it first; it is the single most useful community checks in Linux gaming, but reports are not a guarantee.

  3. Point Steam at a second drive

    Settings → Storage → add a library folder on the other disk. Games can be moved between libraries without redownloading.

  4. Force a specific Proton version for one game

    Right-click the game → Properties → Compatibility → tick the override and choose. Some older games run better on an older Proton, and ProtonDB will tell you which.

  5. Add launch options

    Same Properties window, General → Launch Options. gamemoderun %command% applies the performance governor; mangohud %command% adds the FPS overlay. See game performance tools.

One thing that will surprise you

Online features can change compatibility even when a single-player mode works. Anti-cheat, launchers, account requirements and publisher updates can make a title work, partly work or stop working. Check the publisher's current requirements and recent community reports before replacing a setup you depend on.

Where to find it

After installing: launcher → Steam. Before installing: Dagric Hub → Steam.
