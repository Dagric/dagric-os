System and safety

Snapshot recovery

Roll the whole system back to before that update, from the boot menu.

On Windows this wasSystem Restore

What it is

On a standard Dagric install the disk uses btrfs, a filesystem that can take an instant, near-free copy of the entire system. Dagric uses that: every time software is installed, updated or removed, a snapshot is taken before and after.

Those snapshots appear as a submenu in the boot menu. If an update leaves the machine broken — even so broken that it will not reach the desktop — you restart, choose yesterday, and you are back. No recovery media, no reinstall, no phone call.

Five things you will actually do

  1. Boot into an older snapshot

    Restart. At the boot menu choose the snapshots submenu and pick one by date. The system starts as it was at that moment. Your documents are in your home folder and are not part of the snapshot, so nothing you wrote is lost.

  2. See what snapshots exist

    sudo snapper -c root list in a terminal. Each row shows the number, the date, and why it was taken — “apt (pre)” and “apt (post)” around every package operation, plus the baseline taken on your first boot.

  3. Take one yourself before you do something risky

    sudo snapper -c root create -d "before I edit the grub config". It costs almost no disk space and takes about a second. Do it before hand-editing anything in /etc.

  4. Make the rollback permanent

    Booting a snapshot is a look, not a commitment. To keep it, run sudo snapper -c root rollback from inside the booted snapshot and restart. Do nothing and the next normal boot returns you to the current system.

  5. Recover one file rather than the whole system

    Snapshots are mounted under /.snapshots/. Browse to the one you want and copy the file straight out of it with Dolphin. Far less drastic than rolling the machine back.

One thing that will surprise you

Snapshots are not backups, and it matters which one you need. They live on the same disk. They protect you brilliantly from a bad update, a mis-typed command or a package that broke something; they protect you not at all from a failed drive, a fire or a stolen laptop. Use Kup or Vorta onto a separate disk for that. You want both.

One caveat: this needs btrfs. If you chose ext4 when installing, snapshot recovery is not available and the setup helper quietly stands down. Pro's Timeshift covers ext4 with its rsync mode.

Where to find it

The boot menu, at restart. Setup is automatic on the first boot of an installed system, done by dagric-snapshot-setup — see helpers that run by themselves.
