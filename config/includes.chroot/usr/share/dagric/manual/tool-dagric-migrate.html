Migration Assistant

Bring your files, bookmarks, open tabs, and saved logins across from Windows.

On Windows this wasWindows Easy Transfer, and a very long evening with a USB stick

What it is

The Migration Assistant finds the Windows installation still on this computer, shows you what is in it, and copies over what you pick. It handles Documents, Desktop, Pictures, Music, Videos and Downloads, the bookmarks from Chrome, Brave, Edge, and DuckDuckGo, the tabs you had open, and your saved logins (Firefox plus exported Chromium CSV). It also produces Windows-browser-context.json and a Dagric-Migration-State-Pack.json, local continuation notes for browser setup, Windows folders, shortcuts, and recent work.

The Windows partition is only ever mounted read-only. Nothing there is moved, changed or deleted, so you can boot back into Windows afterwards and find it exactly as you left it. Files are copied, and a copy never overwrites something already in your new home folder.

Six things you will actually do

  1. Install first, then migrate

    If you run it from the live USB it warns you, and it is right to: the live session's home folder lives in memory and disappears at shutdown. Install Dagric, then run this from the Hub.

  2. Choose what comes over

    A tick list appears: Documents, Desktop, Pictures, Music and Videos are on, Downloads is off, bookmarks and open tabs are on, saved passwords are off. Untick Videos if space is tight — it checks free space before copying and stops rather than filling the disk.

  3. Import your bookmarks afterwards

    They arrive as ~/Windows-bookmarks.html. In Firefox: Bookmarks → Manage Bookmarks → Import and Backup → Import Bookmarks from HTML. Your open tabs come as ~/Windows-open-tabs.html and import the same way, arriving as a folder you can “Open All in Tabs”.

  4. Deal with saved passwords

    Firefox logins and any exported Chromium CSV passwords are merged into ~/Windows-passwords.csv; if the Firefox profile had a Primary Password you are asked for it. Import the file into Firefox, a password manager, or KeePassXC, then delete it — it is plain text, and the tool says so twice for a reason.

  5. Run it more than once

    It is safe to. Copies skip files that already exist, so a second run picks up the folders you did not tick the first time without duplicating anything.

  6. Continue from your migration checklist

    Run Restore Migration Notes from the launcher. It turns the local State Pack into a readable checklist for search engines, startup pages, enabled extensions, shortcut names and recent-work signals; it can also add a one-click launcher entry in KDE.

Restore Migration Notes: where to start

Restore Migration Notes opens a saved checklist to help you recreate your old setup. It does not install the listed applications, change browser settings for you, or roll back the operating system. For system checkpoints, use Dagric Rewind.

  1. Run Migration Assistant first. In Dolphin, open your Home folder and look for Dagric-Migration-State-Pack.json. Keep it in the top level of Home, rather than Documents, for the launcher to find it.
  2. Open Restore Migration Notes from the application launcher. It reads that State Pack and saves Dagric-Migration-Notes.html in the same Home folder, then opens the checklist in your browser. It also adds an Open Migration Notes launcher for later.
  3. Work through the checklist yourself and check each application as you set it up. These are local notes; you can open the HTML file in Dolphin even without internet access.

If no checklist opens: check that the State Pack exists in Home and belongs to this account. If it is missing, run Migration Assistant again to create it. If you kept it somewhere else, use Konsole to run dagric-restore-assistant "/full/path/to/Dagric-Migration-State-Pack.json" --open, replacing the quoted path with your file's actual location. Konsole shows a readable error if the file is missing or is not a valid State Pack.

Regenerating the checklist replaces the generated HTML. Keep any personal notes in a separate document. The checklist can include private folder names and web addresses, so review it before sharing.

What the State Pack does not collect

It is a local, private summary rather than a Windows clone. It contains no password, cookie, browser session, file contents, or Windows program installer. Recent links and Jump List files are read only for useful file or web destinations, where Windows left them available. Some apps store those records in private formats, so this is best effort.

One thing that will surprise you

Chromium-family browser passwords cannot be recovered, by anybody, and that is a good thing. They are encrypted with a key tied to your Windows user account, which does not exist on this machine. No tool can decrypt them here — if one claims to, be suspicious of it.

The fix takes two minutes and must be done while you still have Windows: in Chrome / Edge / Brave / DuckDuckGo, open Settings → Passwords (or Password Manager) and Export to CSV. Save the CSV, then run the migration again — it looks for that file and tells you where it found it.

One more thing to check before you wipe the old machine: if the Windows drive is BitLocker-encrypted, Dagric cannot read it without the recovery key. The tool detects that and says so plainly. Turn BitLocker off in Windows first, or copy your files to a plain USB drive.

For the closest possible handoff

The Migration Assistant can now make an app-and-continuity report, inventory Steam, and optionally copy selected developer, creative, Thunderbird, game-save, and personal-font material. It reads Steam libraries and game names only when you select Gaming continuity. Gaming migration does not copy a whole Steam userdata or config tree. It selects Windows Saved Games and Documents/My Games, per-game Steam Cloud remote leaves, screenshot image files, and personal controller-layout files. Steam itself is offered only through dagric-get-steam, which shows the third-party notice and asks first.

The continuity filter skips paths named like logins, sessions, authentication data, tokens, cookies, credentials, web caches, and private keys. That conservative filter is best effort because games can use arbitrary file formats and names. The report shows how many paths were filtered; review migrated material before sharing it with anyone.

If you used Migration Assistant from an earlier preview build, this update does not delete that earlier copy. Review the legacy ~/Dagric-Migration/Gaming/Steam_game_saves and ~/Dagric-Migration/Gaming/Controller_layouts folders yourself; remove them when you no longer need them.

For Wi-Fi names, printers, Bluetooth devices, monitors, the complete Windows app list, WSL distribution names, and cloud-folder warnings, run the included Dagric-Windows-Companion.ps1 while still signed into Windows. It can make either a local JSON inventory or an AES-encrypted transfer bundle; browser password exports remain a separate browser-confirmed action.

Where to find it

Dagric Hub → Migrate from Windows, launcher → Migration Assistant, or dagric-migrate.
