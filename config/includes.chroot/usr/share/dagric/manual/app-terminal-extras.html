nala, bat and zoxidePRO

Three small tools that make the terminal considerably more pleasant.

On Windows this wasnothing — these are quality-of-life additions
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Dagric OS Pro adds three utilities that experienced Linux users install on every machine they touch, so that you do not have to discover them yourself.

  • nala — a readable front end to apt, with parallel downloads, a proper progress display, and a history you can undo.
  • bat — cat with syntax highlighting, line numbers and paging.
  • zoxide — a cd that learns the folders you use, so you can jump to one by typing a fragment of its name.

Five things you will actually do

  1. Install and update the readable way

    sudo nala install packagename and sudo nala upgrade. The output is laid out in a table instead of a wall of text.

  2. Undo an apt operation

    nala history lists what you have done; sudo nala history undo <id> reverses one. Worth knowing about before the day you need it.

  3. Read a file properly

    batcat somefile.py — note the name, see the surprise below. It highlights the syntax, numbers the lines and pages long files automatically.

  4. Turn on zoxide

    It needs one line in your shell configuration. Add eval "$(zoxide init bash)" to the end of ~/.bashrc and open a new terminal.

  5. Jump to a folder

    After zoxide has watched you for a while, z proj takes you to the project folder you use most whose name contains “proj”. It is a small thing that you will use forty times a day.

One thing that will surprise you

bat is called batcat on Debian. Another, much older package already owned the name bat, and Debian will not let two packages fight over one command — so it was renamed rather than allowed to collide. Every tutorial on the internet says bat. If you want it to be, add alias bat=batcat to your ~/.bashrc.

Where to find it

A terminal. All three are commands, not applications.
