mpv

Plays every video and audio file you own, with nothing in the way.

On Windows this wasMovies & TV, Windows Media Player, and VLC

What it is

mpv is the video player, and it plays essentially everything: MP4, MKV, AVI, MOV, WMV, WebM, and the audio formats too. Dagric installs the full codec set alongside it and turns on hardware-accelerated decoding, so 4K video plays without the fan spinning up.

It has almost no interface on purpose. Move the mouse and a control bar appears at the bottom; leave it alone and there is nothing but the picture.

Five things you will actually do

  1. Play, pause and seek

    Space pauses. Left and right arrows seek five seconds, up and down sixty. f toggles full screen, m mutes, 9 and 0 change the volume.

  2. Turn on subtitles

    j cycles through the subtitle tracks in the file, v hides them. A .srt file sitting next to the video with the same name is picked up automatically; you can also drag one onto the window.

  3. Switch audio track

    # cycles the audio tracks — the way to get the original language on a film that starts dubbed.

  4. Play a whole folder in order

    Select the files in Dolphin and drop them onto the mpv window, or right-click → Open With → mpv with several selected. > and < move through the playlist.

  5. Stop now and carry on later

    Shift+Q quits and remembers your position; open the same file again and it resumes. Plain q quits without remembering.

One thing that will surprise you

Right-clicking pauses. mpv has no menu bar and no right-click menu — the right mouse button is bound to pause, which is disconcerting for about a minute and then rather good. Everything else is a single keystroke, and ? or the mpv manual page lists them all.

The player is also genuinely free of nonsense: no update nagging, no bundled browser extension, no “we noticed you play a lot of media”.

Where to find it

Double-click any video. Launcher → Videos (also mpv). To make it the default for a format, right-click the file → Properties → File type options.
