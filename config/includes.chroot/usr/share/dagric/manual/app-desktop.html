The desktop, panels and windows

Taskbars, virtual desktops, window snapping, and how to put it all back.

On Windows this wasTaskbar, Snap Assist and Task View

What it is

The desktop is KDE Plasma. The bar along the bottom is a panel, and everything on it — the launcher, the clock, the system tray, the task buttons — is a widget that can be moved, removed or added. Right-clicking almost anything gives you its settings.

You are not obliged to learn any of that. Dagric ships a comfortable Windows-shaped layout out of the box, and if you ever want a different shape — a centred taskbar, a side dock, a menu bar on top — Dagric Looks rebuilds the panels for you in one click, reversibly.

Five things you will actually do

  1. Snap a window to half the screen

    Drag it to the left or right edge, or press Meta plus an arrow key. Corners give you quarters. It behaves like Windows snapping, including dragging the shared edge afterwards to resize both.

  2. Use more than one desktop

    Ctrl+F1, F2, F3… switch between virtual desktops, and Meta+W opens the Overview, which shows every window and every desktop at once. Put email on one and work on another. Windows calls these Task View desktops; here they have been standard for twenty years.

  3. Change the wallpaper

    Right-click any empty part of the desktop and choose Configure Desktop and Wallpaper. Dagric ships more than twenty wallpapers, each in a branded and a plain version. The same dialog offers a Slideshow that rotates through a folder of your own pictures.

  4. Put a widget on the panel or the desktop

    Right-click the panel (or the desktop) → Add Widgets. Weather, a system monitor, sticky notes, a colour picker. Drag one out again to remove it.

  5. Undo a layout you regret

    Open Dagric Looks and pick Classic. It rebuilds the panels from scratch, so whatever mess a stray drag made is gone. Nothing else about your session is touched.

One thing that will surprise you

You can drag the taskbar clock, and you can break the taskbar entirely — and neither one is a disaster. Plasma really does let you edit the desktop, which is wonderful until an accidental drag leaves a panel somewhere silly. Dagric Looks rebuilds any layout in a second, so the correct response to a wrecked panel is one click, not a reinstall. Try things.

Where to find it

It is what you are looking at. Panel settings: right-click the panel → Enter Edit Mode. Window behaviour, shortcuts and effects live in System Settings under Window Management and Workspace Behaviour.
