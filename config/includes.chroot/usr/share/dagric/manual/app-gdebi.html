Files and getting around

Installing downloaded software

What to do with a .deb, a .AppImage, a .flatpakref — and what a .exe is not.

On Windows this wasdouble-clicking a .exe or .msi installer

What it is

Most software should come from Discover. But sometimes a vendor hands you a file, and it helps to know which is which.

A .deb is the Debian equivalent of an .msi — the native installer format. Dagric ships GDebi, so double-clicking a .deb opens a small window that shows what it is, warns you if it looks unhealthy, and installs it after you type your password. Zoom, Chrome and Visual Studio Code all ship this way.

Five things you will actually do

  1. Install a .deb you downloaded

    Double-click it in Dolphin. GDebi opens, tells you what the package is and what it will pull in, and installs on your word. It goes into the launcher like anything else.

  2. Run an AppImage

    An .AppImage is a whole application in one file and is not installed at all. Right-click → Properties → Permissions → tick Is executable, then double-click it. To remove it, delete the file.

  3. Open a .flatpakref

    Double-click it; Discover takes over and installs the app from Flathub. This is the tidiest of the three — it is sandboxed, it updates with everything else, and it uninstalls cleanly.

  4. Deal with a .exe or .msi

    These are Windows programs and will not run on their own. Bottles gives each one a tidy home, and it is available on every edition — the Dagric Hub has a row for it. On Dagric OS Pro, Wine is installed already and runs many of them directly; for the ones that refuse, there is a real Windows in a window.

  5. Remove something you installed by hand

    Discover's Installed page lists .deb packages alongside everything else, so removal is the same button. AppImages you simply delete.

One thing that will surprise you

You will barely ever need this page. The Windows habit of searching the web for an installer, judging whether the download site is a fake, and clicking through a wizard that offers you a toolbar — that entire ritual is gone. Nearly everything is one search in Discover, already checked, already signed, and updated with the rest of the system. Downloading installers from websites is the exception here, not the rule.

Where to find it

Mostly it appears by itself when you open a .deb. In the launcher it is Package Installer; to force it onto a file, right-click → Open With → Package Installer.
