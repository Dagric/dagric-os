System and safety

Kup

Back up your files onto a drive you plug in, with no configuration to speak of.

On Windows this wasFile History

What it is

Kup is KDE's backup tool and it lives inside System Settings rather than as a separate application. You tell it which folders matter and which drive to copy them to, and it prompts you to run a backup whenever that drive is plugged in.

It offers two kinds. A synchronised backup is a plain mirror of your files that you can browse in Dolphin without any special tool. A versioned backup keeps history, so you can go back to how a file looked last month.

Five things you will actually do

  1. Set up your first backup

    System Settings → Backups → Add New Plan. Choose the folders (your home folder, minus Downloads, is a good start), choose the destination drive, choose the type, and give the plan a name.

  2. Run one

    Plug the drive in. Kup notices and offers. You can also start it any time from the tray icon or the settings page.

  3. Get a file back

    For a synchronised backup, just open the drive in Dolphin and copy the file back. For a versioned backup, use the restore browser from the backup plan's page, which lets you pick a date first.

  4. Choose how often it nags

    Each plan has a schedule: manual, on an interval, or on the amount of data changed. “Every time the drive is connected” suits a backup drive that lives in a drawer.

  5. Exclude the big pointless things

    In the plan, exclude caches, Downloads, virtual machine disk images and Steam libraries. They are enormous and re-downloadable, and leaving them in is the usual reason a backup drive fills up.

One thing that will surprise you

It is in System Settings, not in the launcher, and so almost nobody finds it. Searching the launcher for “backup” does take you there, but if you were looking for an application icon you would conclude the machine had no backup tool. It has; it is under Backups.

And the usual reminder: a backup on a drive that lives permanently plugged into the computer is one power surge, one theft or one piece of ransomware away from being no backup. Unplug it.

Where to find it

System Settings → Backups. Or search backup in the launcher.
