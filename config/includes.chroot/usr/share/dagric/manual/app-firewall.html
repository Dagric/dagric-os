System and safety

The firewall

What can reach this computer from the network, and from which network.

On Windows this wasWindows Defender Firewall

What it is

Dagric runs firewalld, switched on from the first boot, with a settings page at System Settings → Firewall.

Its central idea is zones. Each network connection is assigned one: public is suspicious and allows almost nothing in; home is trusted and permits things like phone pairing and file sharing. The same laptop can therefore be open on your own network and closed in a café, without you remembering to change anything.

Five things you will actually do

  1. Check which zone you are in

    System Settings → Firewall lists your connections and their zones. New connections default to public, which is the safe way round.

  2. Trust your home network

    Set your home Wi-Fi's zone to home. This is what makes KDE Connect pairing and local file sharing work, and it is why they do not work at the airport.

  3. Open a port for something you are running

    In the Firewall settings, add the service or port to the relevant zone. Only do this for the zone that needs it — adding a rule to public opens it on every untrusted network you ever join.

  4. Turn SSH on properly

    Dagric ships with SSH removed from every zone's allowed services — not just public, because the bullet above sends you to home, and closing only the zone you left would be theatre. Enabling the server is a deliberate two-step: sudo systemctl enable --now ssh and then sudo firewall-cmd --permanent --zone=home --add-service=ssh followed by sudo firewall-cmd --reload. Use the zone you are actually on; firewall-cmd --get-active-zones names it. Omit --zone and the rule goes to public, which is the usual reason SSH still will not connect.

  5. See what is actually listening

    ss -tulpn in a terminal lists every port something is waiting on. On a fresh Dagric desktop this list is very short, which is the point.

One thing that will surprise you

You will almost never need to touch it, and that is not because it is doing nothing. A desktop Linux system runs very few network services to begin with — there is no equivalent of the sprawl of Windows services listening by default — so the firewall is a second line rather than the only one. The prompts you may remember from Windows Firewall asking whether to allow a program are about outbound traffic; that is a different tool, and on Pro it is OpenSnitch.

Where to find it

System Settings → Firewall. From a terminal, firewall-cmd --get-active-zones.
