Writing and documents

LibreOffice Writer

Letters, reports, CVs, anything with paragraphs in it.

On Windows this wasMicrosoft Word

What it is

Writer is the word processor. It opens and saves .docx, so the files you bring from Windows open, and the files you send to a colleague on Word arrive intact.

Dagric also installs the Carlito and Caladea fonts, which are metrically identical to Calibri and Cambria. That sounds like a footnote and is not: without them, every Word document you own would reflow, repaginate and break its layout the moment you opened it. With them, a document looks the same as it did on Windows.

Five things you will actually do

  1. Open the Word documents you brought over

    Double-click them in Dolphin. .doc and .docx both open. If you used the Migration Assistant, they are already in your Documents folder.

  2. Send something back to a Word user

    File → Save As and choose Word 2007-365 (.docx). Writer warns you that some formatting may not survive; for ordinary documents it does. To make .docx the permanent default, see the surprise below.

  3. Make a PDF

    The PDF button on the toolbar, or File → Export as PDF for the version with options — page range, image quality, and a password on the finished PDF.

  4. Use styles instead of fighting formatting

    F11 opens the Styles sidebar. Apply Heading 1 to your headings rather than manually bolding them, and the table of contents (Insert → Table of Contents and Index) builds itself. This is the single habit that makes long documents bearable.

  5. Track changes for someone else to review

    Edit → Track Changes → Record. The marks are compatible with Word's, so a reviewer on Windows sees your edits and you see theirs.

One thing that will surprise you

It saves as .odt unless you tell it otherwise, every single time. ODF is the open standard and LibreOffice prefers it, so the first time you press Ctrl+S on a new document you get a .odt and a dialogue asking if you are sure.

If everyone you exchange documents with uses Word, change it once and stop thinking about it: Tools → Options → Load/Save → General, and set Always save as to Word 2007-365.

Where to find it

Launcher → LibreOffice Writer, or just Word — the launcher search finds it under that name too. Double-clicking any .docx opens it.
