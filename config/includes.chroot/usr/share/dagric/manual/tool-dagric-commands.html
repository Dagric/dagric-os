Every dagric command

The complete list of the dagric-* tools, what each does, and where each one lives.

On Windows this wasnothing — this is the index

What it is

Every tool Dagric adds is a command beginning dagric-. Nearly all of them also have a Hub row and a launcher entry, because a tool only reachable from a terminal is a tool most owners will never use. Here is all of them.

Setting up and moving in

  • dagric-hub — the Hub, the menu that gathers everything else.
  • dagric-hardware-check — Check This PC: a read-only, offline report on whether this computer will run Dagric properly — the Wi-Fi chip and whether its firmware is on the disc, graphics, disk space, BitLocker, Secure Boot. It never asks for a password, mounts nothing, and writes exactly one file: the report, to a place you picked. On the live USB it is an icon on the desktop beside Install Dagric OS; on an installed system it stays in the launcher and the Hub, and its report is what to send when you ask for help.
  • dagric-rewind — the private system timeline: create paired before-and-after checkpoints, inspect a path-only change receipt, and open the safe Btrfs recovery route. It never records the screen or reads document contents.
  • dagric-firstrun — Set Up Dagric, the wizard at your first login: colours, wallpaper, text size, taskbar, and your files.
  • dagric-setup — Finish Setup: NVIDIA driver, HP printer support, Flathub.
  • dagric-migrate — the Migration Assistant: files, bookmarks, tabs and Firefox logins from Windows.
  • dagric-manual — this manual.
  • dagric-guide — opens the user guide: the short read about your first week (updates, printers, Wi-Fi, shortcuts). It picks the copy that matches your language, which is the one thing a launcher entry could not do on its own.
  • dagric-welcome — opens the written welcome page. See helpers that run by themselves.

Making it look how you want

  • dagric-appearance — the gallery: styles and layouts as pictures, with Keep and Revert.
  • dagric-upgrade — moves this machine to the next Debian release, when there is one. Run it with sudo. It refuses unless the next release has actually shipped, the package system is healthy, there is room, the machine is on mains power and no third-party repositories are enabled; then it snapshots first, downloads everything before installing anything, and rebuilds the graphics modules afterwards. On a machine with no snapshots it says so plainly and makes you type a different word to continue. Until the next Debian is released it simply tells you that you are on the newest version, which is not an error.
  • dagric-image-prep — strips this machine's identity so the disk can be cloned onto other computers. Run it with sudo on the reference machine, immediately before imaging, then power off rather than reboot. It removes the SSH host keys and the machine ID — the two things that must be unique per computer — so every clone generates its own on first boot. Without it, thirty cloned machines share one SSH identity and fight over addresses on the same network. Your files, accounts and software are not touched. Only useful if you are imaging several machines; ordinary owners never need it.
  • dagric-looks — Dagric Looks: the panel layout.
  • dagric-style — Dagric Styles: colours, accent, wallpaper and effects.
  • dagric-display — Dagric Display: text size and night colour, with a twenty-second undo.
  • dagric-get-variety — rotating wallpapers, offered rather than preinstalled.
  • dagric-app-names — why the apps have plain names: the rewriter that makes the launcher say Files instead of Dolphin.
  • dagric-brand-launcher — puts the logo on the launcher button at first login.

Hardware, safety and recovery

  • dagric-drivers — the NVIDIA driver helper, including Secure Boot enrolment. Needs sudo.
  • dagric-driver-offer — the one-off first-login offer to run the above.
  • dagric-security-checkup — the security audit and drive health report.
  • dagric-snapshot-setup — configures snapshot recovery on the first boot of an installed system.
  • dagric-usb-protect PRO — USB Protection: allow-list your devices, block the rest.
  • dagric-vm PRO — switches on the virtual-machine stack with consent.

Install-on-request helpers

Each of these opens a terminal, explains what the application is, and asks one yes/no question. Nothing is downloaded before you answer. The Hub lists them on Dagric OS Pro; on any edition you can also install these applications straight from Discover.

  • dagric-get-steam — Steam, never bundled.
  • dagric-get-heroic — Heroic: Epic, GOG and Amazon libraries.
  • dagric-get-protonup — ProtonUp-Qt.
  • dagric-gaming — Proton-GE for an installed Steam.
  • dagric-game-launch — the one entry here that installs nothing: a wrapper you paste into a game's launch options (dagric-game-launch %command%) to hold full performance and keep the screen from blanking for exactly as long as the game runs, and no longer. See GameMode, MangoHud and GOverlay.
  • dagric-get-bottles — Bottles: Windows programs in tidy containers.
  • dagric-get-onlyoffice — ONLYOFFICE: the familiar Office look.
  • dagric-get-joplin — Joplin: local-first notes.
  • dagric-get-localsend — LocalSend: private device-to-device sharing.
  • dagric-get-cryptomator — Cryptomator: encrypt before the cloud.
  • dagric-get-upscayl — Upscayl: offline AI image upscaling.
  • dagric-get-resolve — a guided walk through DaVinci Resolve's official download. Installs nothing itself.
  • dagric-ai — Ollama: local language models.

Where they are grouped

  1. Everything asks first

    Without exception. Every helper above states what it is about to do and waits for a yes, and the ones that need administrator rights ask for your password separately. Answering anything other than yes leaves the machine exactly as it was.

  2. Everything is readable

    They are all short shell scripts in /usr/bin/. If you want to know exactly what one does before running it, cat /usr/bin/dagric-migrate — or open it in Kate. Nothing is compiled and nothing is hidden.

  3. Most have a window as well as a command

    Search the launcher for the friendly name — Finish Setup, Migration Assistant, Security Checkup, USB Protection — or open the Dagric Hub, which lists them all.

  4. Terminal helpers hold their window open

    When one finishes it waits for you to press Enter before closing, so you can read what happened. That is on purpose.

  5. No consumer helper checks in

    None of the visible helpers checks in with anything. One of them, dagric-snapshot-setup, is also run by a one-time service on the first boot. Two more one-time services that are not commands at all create the Print-to-PDF queue and this machine's own SSH host keys. Each does its work once and stands down. The only other Dagric code that runs without you starting it is the helpers described in helpers that run by themselves.

One thing that will surprise you

You could delete every one of them and the operating system would carry on working perfectly. None of these tools is load-bearing: they are convenience wrappers around things Debian and KDE can already do. That is a deliberate design constraint — an owner should never be locked into a vendor's helper to administer their own machine.

Where to find it

All of them are in /usr/bin/. The friendly route is the Dagric Hub.
