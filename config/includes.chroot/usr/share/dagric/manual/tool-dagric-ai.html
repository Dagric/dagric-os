Local AI (Ollama)ADD-ON

Run a downloaded language model on your own hardware, with prompts and inference kept on this computer.

On Windows this wasChatGPT and Copilot — on your machine, without the account

What it is

Ollama downloads and runs large language models on this computer. The model file lives on your disk, and after the model is downloaded, prompts and inference stay on your processor or graphics card. Installed models work with the network unplugged.

That is the entire pitch. A local model is not as capable as the largest hosted ones, and in exchange nobody is reading your prompts, keeping them, or training on them.

Running it

Dagric Hub → Local AI — Ollama, launcher → Local AI Setup, or dagric-ai. A terminal window explains what Ollama is and asks yes or no.

Be aware of what “yes” means here: it downloads one reviewed Ollama release archive from Ollama's official GitHub project. Dagric pins the version, byte size and SHA-256 checksum, checks them before and after administrator approval, restricts what the archive may install, and restores a previous working copy if the service cannot start. It is outside Debian's archive, so the confirmation screen still names the source and the complete removal commands before you agree.

Five things you will actually do

  1. Run your first model

    ollama run llama3.2. The first run downloads the model (a couple of gigabytes) and then drops you into a chat prompt in the terminal. /bye leaves.

  2. Pick a model that fits your machine

    Roughly: a 3-billion-parameter model wants about 4 GB of memory, 7 to 8 billion wants about 8 GB, and larger models want more than most laptops have. If a model is slow or the machine starts swapping, use a smaller one — that is the whole tuning process.

  3. Use the graphics card

    Ollama uses an NVIDIA GPU automatically if the proprietary driver is installed — run the driver helper first. The difference between GPU and processor is roughly the difference between conversation and correspondence.

  4. Manage the models

    ollama list shows what you have downloaded, ollama rm modelname deletes one. They are large; check occasionally with Filelight.

  5. Give it a window

    Ollama is a command-line tool with a local API. Several graphical front ends exist on Flathub — search Discover for an Ollama client — and they all talk to the same local service.

One thing that will surprise you

Dagric does not pipe an internet script into a shell. The helper downloads one versioned Ollama archive over HTTPS from Ollama's official GitHub release, then verifies the expected byte size and SHA-256 digest before it asks for administrator approval. A narrow installation helper rejects unexpected archive paths, installs only the reviewed files and service, and restores the previous working copy if startup fails. Ollama is still outside Debian's archive; if that trust boundary is not acceptable, answer no. Nothing else on the machine depends on it.

Where to find it

Dagric Hub → Local AI — Ollama, or dagric-ai. Afterwards it is the ollama command.
