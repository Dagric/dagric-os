Cloud storage: rclone and Google DrivePRO

Reach Drive, Dropbox, OneDrive, S3 and seventy other services from this machine.

On Windows this wasthe OneDrive, Google Drive and Dropbox desktop apps
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Dagric OS Pro gives you two routes to cloud storage.

Google Drive inside Dolphin is the friendly one: add your Google account once in System Settings, and Drive appears in the file manager like any other folder. rclone is the powerful one: a command-line tool that speaks to more than seventy services — Drive, Dropbox, OneDrive, Box, pCloud, Backblaze B2, Amazon S3 and the rest — and can copy, sync, mount or encrypt against any of them.

Five things you will actually do

  1. Put Google Drive in the file manager

    System Settings → Online Accounts → Add Account → Google, and sign in through the window that appears. Drive then shows up in Dolphin's Places list, and every application can open and save there.

  2. Set up rclone for a service

    rclone config in a terminal walks through it with a menu: name the remote, pick the provider, and it opens a browser for you to authorise. Give the remote a short name — you will type it a lot.

  3. Copy files up or down

    rclone copy ~/Documents mydrive:Documents pushes a folder up; swap the arguments to pull it back. Add --progress to watch it work. copy never deletes anything; sync makes the destination match exactly, so read it twice before you run it.

  4. Mount a cloud folder like a drive

    rclone mount mydrive: ~/Drive --vfs-cache-mode writes makes the remote appear as a normal folder for as long as that command runs. Good for browsing, less good for editing enormous files.

  5. Encrypt before it leaves

    rclone's crypt remote encrypts file contents and names before upload, so the provider stores nothing readable. For a friendlier version of the same idea, use Cryptomator.

One thing that will surprise you

There is no OneDrive that keeps working silently in the background. Microsoft publishes no Linux client, and the third-party ones are best-effort. rclone will happily copy to and from OneDrive on a schedule, and Drive appears in Dolphin properly, but the always-there, always-synced icon in the corner is a Windows and macOS arrangement. If continuous sync is what you want, Syncthing between your own machines does it better and without a landlord.

Where to find it

Google Drive: System Settings → Online Accounts, then Dolphin. rclone: a terminal, starting with rclone config.
