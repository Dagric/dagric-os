Dagric Hub

One window that gathers every Dagric tool, so nothing lives only on the command line.

On Windows this wasnothing — Windows scatters this across Settings, Control Panel and OEM apps

What it is

The Dagric Hub is a menu. Open it, pick a row, and the tool it names opens. That is the entire design, and it exists because the alternative — a set of useful helpers that only people who read documentation ever find — is not a product.

It knows which edition you are running and shows only what that edition actually has. Nothing in the Hub changes anything on its own: picking a row opens a tool, and every tool asks before it acts.

Five things you will actually do

  1. Find your way around it

    The rows are grouped under headings. Every edition has Get started (the setup wizard, finish setup, migrate from Windows, the welcome guide, this manual), Appearance (the gallery, text size and night light, desktop layout, colours, rotating wallpapers) and System (NVIDIA driver, security checkup).

    Dagric OS Pro adds four more groups: Windows and apps, Privacy and files, Gaming, and Creator and AI.

  2. Set up a brand-new machine

    Work down the first group in order: Set up Dagric (the same wizard you saw at first login — it is re-runnable), then Finish setup, then Migrate from Windows, then read the Welcome guide. That is a complete first hour.

  3. Install one of the offered applications

    The rows that name an application — Bottles, ONLYOFFICE, Joplin, LocalSend, Cryptomator, Steam, Heroic, Upscayl and the rest — open a terminal window that explains what the app is and asks you a yes/no question. Nothing is downloaded before you answer.

  4. Read what happened

    Terminal helpers leave their window open when they finish, with “Press Enter to close…” at the bottom. That is deliberate: you should be able to read what a tool did to your computer, not watch a window vanish.

  5. Get back to the menu

    Clicking one of the grey heading rows simply reopens the Hub, so a mis-click costs nothing. Closing the window or pressing Esc does nothing at all.

One thing that will surprise you

The Hub never does anything itself. It has no “optimise” button, no one-click tune-up, and nothing that runs in the background afterwards. It is a signpost to tools that each ask for your consent separately. If you close it, nothing is left running and nothing was changed — which is not how the equivalent utility on a new Windows laptop usually behaves.

Where to find it

Launcher → Dagric Hub, or dagric-hub in a terminal.
