System and safety

Btrfs Assistant

Inspect the filesystem and its recovery snapshots without memorising terminal commands.

On Windows this wasSystem Protection and advanced Disk Management

What it is

Btrfs Assistant is the advanced control panel for Dagric's Btrfs filesystem. It shows subvolumes, disk use and snapshots. Most people should use Dagric Rewind for ordinary recovery; open this when you need to inspect what is underneath.

Before you change anything

A snapshot is not a second copy on another drive. Confirm that important files also have a real backup. Read the selected action twice before deleting a snapshot or subvolume.

Five things you will actually do

  1. See the current filesystem

    Open the Subvolumes page. The mounted system and home areas appear with their paths and identifiers.

  2. Review recovery points

    Open Snapper, select a configuration, and read the date and description before choosing a snapshot.

  3. Compare two snapshots

    Select the earlier and later entries, then use the changes view to see which files were added, removed or modified.

  4. Remove an old snapshot

    Select only a snapshot you recognise, choose delete, and confirm its date again. Never delete the currently mounted subvolume.

  5. Check space use

    Use the filesystem page to distinguish space used by current files from space retained by snapshots.

If you are unsure

Close the app without applying anything and run Dagric Rewind or Dagric Security Checkup. Inspection is safe; deleting or restoring is the point where care matters.

Where to find it

Launcher → Btrfs Assistant. Administrative actions ask for your password.
