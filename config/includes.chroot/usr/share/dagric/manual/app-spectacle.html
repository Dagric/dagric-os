Spectacle

Screenshots and screen recordings, on one key.

On Windows this wasSnipping Tool, Print Screen, and the Xbox Game Bar recorder

What it is

Spectacle takes screenshots. Press Print Screen and it appears with the shot already taken, offering to save it, copy it to the clipboard, or send it somewhere. Capture modes cover the whole screen, one monitor, the active window, the window under the pointer, or a rectangle you drag.

It also records the screen to a video file — region, window or whole screen — which covers the “show me what you mean” case without installing anything.

Five things you will actually do

  1. Grab part of the screen

    Press Print Screen, choose Rectangular Region, then drag. You can nudge the edges before releasing, and the magnifier helps you land on an exact pixel.

  2. Copy a shot straight into an email

    Take it, then press the Copy to Clipboard button (or its keyboard shortcut shown on the button). Paste into the message. Nothing is written to disk at all.

  3. Capture a menu that keeps closing

    Set a Delay of a few seconds before capturing, press Take a New Screenshot, then open the menu and wait. Ticking Include mouse pointer makes instructions much clearer.

  4. Record a short screencast

    Switch Spectacle from screenshot to Recording, choose region, screen or window, and press record. Stop from the tray. The result is a video file you can attach to a bug report or send to a relative.

  5. Choose where shots are saved

    Configure → Save. Set the folder and the filename pattern — a pattern with the date in it saves a great deal of later sorting.

One thing that will surprise you

Print Screen alone already did it. Windows trained a whole generation to press Print Screen and then paste into Paint to find out what they got. Here the key opens the tool with the capture already made and a preview in front of you, so there is no blind step. If you want the old copy-and-say-nothing behaviour, Spectacle's settings can do that too.

Where to find it

Print Screen. Or launcher → Screenshot (also found by typing Spectacle, snip or prtscn). The screenshot shortcuts are listed and editable in System Settings → Shortcuts.
