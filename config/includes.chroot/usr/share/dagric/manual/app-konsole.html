Konsole

The terminal. You can ignore it entirely — but it is the fastest way to be helped.

On Windows this wasCommand Prompt and PowerShell

What it is

Konsole is a terminal: you type a command, it runs. Nothing on this computer requires you to use it — every Dagric tool has a window and a button. But when you ask for help online or from support, the answer often arrives as a line of text to paste here, and it is worth knowing where here is.

Two facts make it much less frightening. Commands do not run until you press Enter, and anything that changes the system asks for your password first (that is what sudo means at the front of a line). If you have not typed a password, nothing important has happened.

Five things you will actually do

  1. Copy and paste properly

    Ctrl+Shift+C copies and Ctrl+Shift+V pastes — note the extra Shift. Right-click also offers Paste. Plain Ctrl+C means something else here: it stops whatever is currently running.

  2. Open a terminal already in the right folder

    In Dolphin, press F4 and a terminal panel opens at the bottom, already in the folder you are looking at. That saves ever having to type a path.

  3. Find out what version you are running

    cat /etc/os-release. Support will ask for this. Also useful: free -h for memory and df -h for free disk space.

  4. Split the window

    View → Split View, or open several tabs with Ctrl+Shift+T. Each tab is its own session.

  5. Undo a command you started by mistake

    Ctrl+C stops it. If the whole terminal is stuck, close the window — nothing in a terminal survives its window except work you explicitly started in the background.

One thing that will surprise you

Paste is not Ctrl+V, and that is on purpose. In a terminal Ctrl+C has meant “interrupt” since long before it meant copy, so terminals moved copy and paste onto Ctrl+Shift. It feels wrong for about a week.

The other habit worth building: never paste a command you were sent by a stranger without reading it, particularly one containing sudo or ending in | sh. That is the one genuine way to hurt this machine from a terminal.

Where to find it

Launcher → Terminal (it answers to Konsole, Command Prompt and PowerShell as well). In Dolphin, F4. The Dagric helpers open their own Konsole window when they need one, and hold it open at the end so you can read what happened.
