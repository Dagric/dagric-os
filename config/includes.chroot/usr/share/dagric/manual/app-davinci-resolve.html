DaVinci ResolveADD-ON

Studio-grade video editing and colour grading — free, but you download it yourself.

On Windows this wasPremiere Pro and After Effects

What it is

DaVinci Resolve is a professional post-production suite: editing, the industry's most respected colour grading tools, the Fusion compositor for visual effects, and the Fairlight audio desk — in one application. The free version is not a trial; it is genuinely free and is used on real productions.

For most people Kdenlive on Dagric OS Pro is the faster, lighter answer. Resolve earns its weight when colour matters, or when you are working to a specification someone else set.

Getting it

Resolve cannot be preinstalled by anybody. Blackmagic's licence forbids redistributing it, so an OS that bundled it would be breaking that licence — Dagric will not do that, and you should be suspicious of any distro that claims to.

Instead there is a guided helper. Open the Dagric Hub → DaVinci Resolve (or run dagric-get-resolve). It opens Blackmagic's download page in your browser and prints the exact steps in the terminal window:

  • Download the free Linux version from Blackmagic and register with them.
  • Unzip it, then run the installer it contains with administrator rights.
  • On an NVIDIA machine, run the driver helper first — Resolve leans heavily on the proprietary driver.

The helper itself installs nothing and changes nothing. It is a signpost.

Five things you will actually do

  1. Understand the pages

    The icons along the bottom are the workflow: Media to import, Cut or Edit to assemble, Fusion for effects, Color to grade, Fairlight for audio, Deliver to export. You move left to right through a project.

  2. Import footage that Resolve will accept

    The free Linux build is fussy about formats: it does not handle H.264 or H.265 in an MP4 container from consumer cameras and phones. Convert those to DNxHR or ProRes first — HandBrake or ffmpeg will do it. This is the single biggest stumbling block and it is not your fault.

  3. Grade a shot

    On the Color page, use the primary colour wheels for lift, gamma and gain, then add nodes for secondary corrections. Resolve's node graph is why professionals use it.

  4. Keep the machine happy

    Set optimised media and render cache in Project Settings, and give Resolve a fast scratch disk. It expects a workstation and will use every resource you allow it.

  5. Export

    The Deliver page. Pick a preset, set the range, add to the render queue and start it. H.264 export in the free Linux build may be limited; DNxHR or ProRes out, then HandBrake to MP4, always works.

One thing that will surprise you

“Free” here still means registering with Blackmagic. The download asks for your name and email. That is their condition, not Dagric's, and it is the reason this is a signposted download rather than a one-click install. If that trade is not one you want to make, Kdenlive asks nothing of you at all.

Where to find it

Dagric Hub → DaVinci Resolve, or dagric-get-resolve in a terminal. After installing, it appears in the launcher as DaVinci Resolve.
