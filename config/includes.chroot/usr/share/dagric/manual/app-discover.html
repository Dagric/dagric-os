Files and getting around

Discover

Install and remove software, and see what needs updating.

On Windows this wasMicrosoft Store

What it is

Discover is the software centre: the shopping-bag icon in the taskbar. Search for what you want, press Install, and it appears in the launcher. Everything in it is free, and removing an app really removes it.

It draws on two sources. Debian packages are the tested software the operating system itself is built from. Flathub is a much larger catalogue of desktop apps that run in their own sandbox — usually newer versions, and each one asks for its own permissions. Discover labels which is which on every listing, and if two versions exist you may choose.

Five things you will actually do

  1. Install an app

    Search, click the entry, press Install. You will be asked for your password for Debian packages; Flatpak apps installed just for you do not need it. It lands in the launcher when it finishes.

  2. Remove an app

    Go to Installed in the sidebar, find it, press Remove. It goes, and it stays gone — nothing reinstalls itself after an update.

  3. Apply updates

    The Updates page lists everything with a new version. Security fixes have usually already been applied silently in the background; this page is for the rest. See Updates.

  4. Update your laptop's firmware

    BIOS and firmware updates from the manufacturer appear on the Updates page too, alongside software. Dagric ships the LVFS backend, so a Dell or Lenovo firmware update is a normal click here rather than a bootable USB stick.

  5. Turn on Flathub if it is not on yet

    Finish Setup in the Dagric Hub has a tick box for it. Once enabled, the catalogue in Discover grows from a few thousand to tens of thousands of apps.

One thing that will surprise you

There is no account, no card on file and no purchase flow. Nothing in Discover costs money, nothing tracks what you install, and there is nobody to sign in as. The corollary is that Discover is not where you get Steam, Chrome, Zoom or Spotify's proprietary builds — those are separate, deliberate steps, because Dagric will not quietly hand you software under a licence you have not seen. The Dagric Hub collects the honest one-click versions of those.

Where to find it

The bag icon in the taskbar, or launcher → Software Store (also found by typing Discover or install).
