System and safety

BleachBitPRO

Reclaim disk space from caches and logs, and shred files properly.

On Windows this wasDisk Cleanup and CCleaner
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

BleachBit deletes the accumulated rubbish: browser caches, thumbnail caches, package caches, old logs, temporary files. It also shreds individual files so they cannot be recovered, and can wipe the free space on a disk.

It is genuinely useful and it is genuinely capable of deleting something you wanted. Read the tick boxes.

Five things you will actually do

  1. Do a safe first clean

    Tick only the obvious caches — browser cache, thumbnails, the apt package cache — then press Preview before Clean. Preview lists exactly what would go and how much space it frees.

  2. Understand what you are ticking

    Some options remove browser cookies, saved sessions or history. That is a legitimate thing to want and a very annoying surprise if you did not. Hover each item for its description.

  3. Clean system files too

    There is a separate administrator mode for things outside your home folder. It asks for your password. The package cache under /var/cache/apt is usually the biggest single win.

  4. Shred a file

    File → Shred Files. It overwrites before deleting. Note that on an SSD this guarantee is weaker than on a spinning disk, because of how SSDs manage their own storage — full-disk encryption is the real answer there.

  5. Find where the space actually went first

    Before cleaning, run Filelight. Very often the 40 GB you are hunting is one forgotten video or a virtual machine disk, not a cache, and BleachBit will not help with that at all.

One thing that will surprise you

Linux does not accumulate the way Windows did. There is no registry to rot, no fragmentation to defragment, and no slow decline that a cleaning tool reverses. A Dagric machine two years old is as fast as it was on day one. BleachBit reclaims space; it does not make the computer faster, and any tool that claims to is selling something.

Where to find it

Launcher → Disk Cleanup (also BleachBit). The administrator version is a separate entry, Disk Cleanup (Administrator).
