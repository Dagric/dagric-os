Writing and documents

LibreOffice Calc

Spreadsheets, budgets, lists and the sums that go with them.

On Windows this wasMicrosoft Excel

What it is

Calc is the spreadsheet. Cells, formulas, charts and pivot tables, and it reads and writes .xlsx. The function names are the same as Excel's — =SUM(), =VLOOKUP(), =IF(), =XLOOKUP() — so existing sheets recalculate rather than break.

Five things you will actually do

  1. Open an Excel file

    Double-click it. Formulas, formatting and multiple sheets come across. Save back with File → Save As → Excel 2007-365 (.xlsx).

  2. Add up a column

    Click the cell underneath it and press the Σ button on the toolbar; Calc guesses the range. Or type =SUM(B2:B40) yourself.

  3. Make a chart

    Select the data including its headings, then Insert → Chart. The wizard walks through type, data range and labels, and the chart lands in the sheet where you can drag and resize it.

  4. Build a pivot table

    Insert → Pivot Table. LibreOffice calls the fields Row, Column, Data and Filter, which is Excel's model under slightly different names. Drag fields into the boxes and press OK.

  5. Import a CSV cleanly

    Opening a .csv brings up an import dialogue — do not skip it. Set the separator, and crucially set the column type to Text for anything like a phone number or a postcode that must not be turned into a number or a date.

One thing that will surprise you

Excel macros will not run. LibreOffice has its own macro language (LibreOffice Basic) and a partial VBA compatibility layer, but a workbook that depends on serious VBA will not work here, and no amount of configuring will fix it. That is the one genuine incompatibility in the whole office suite.

If that describes a workbook you cannot live without, the honest options are ONLYOFFICE (better macro support in some cases), the web version of Excel in Firefox, or real Excel inside a Windows virtual machine on Pro.

Where to find it

Launcher → LibreOffice Calc, or search Excel or spreadsheet.
