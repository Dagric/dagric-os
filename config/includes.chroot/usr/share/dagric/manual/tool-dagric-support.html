Dagric Support Mode

Preview a useful system report before you decide whether to share it.

On Windows this wasSystem Information plus a reviewed support bundle

What it is

Support Mode creates a privacy-conscious summary of hardware, recovery state and Dagric changes. Preview is the default. There is no background collection, timer or automatic upload endpoint.

Five things you will actually do

  1. Open the preview

    Start Support Mode and read the report on this computer before saving or sharing anything.

  2. Check the allow-list

    Confirm the sections are relevant to the problem. A useful report should explain system state without copying personal documents.

  3. Look for identifiers

    Review hostnames, network addresses, usernames and hardware serials. Remove anything you do not want a recipient to have.

  4. Save only when needed

    Create a report for a specific support case and keep it in a folder you can find. Do not post it publicly by default.

  5. Delete the copy afterward

    Once the case is resolved, remove unnecessary exported reports from Downloads, email drafts and shared folders.

Sharing is a separate decision

Opening Support Mode does not send anything. Share a reviewed report only with a support person or issue tracker you trust, and only when it helps diagnose a real problem.

Where to find it

Launcher → Dagric Support Mode. It opens in preview mode.
