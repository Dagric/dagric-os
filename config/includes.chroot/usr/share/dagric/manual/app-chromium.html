ChromiumPRO

A second browser, for the site that insists on Chrome.

On Windows this wasGoogle Chrome
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Chromium is the open-source browser that Google Chrome is built from, without Google's proprietary additions. It exists on this machine for one reason: occasionally a banking site, a video-conference room or a corporate portal is only tested against Chrome, and having one to hand saves an afternoon.

Five things you will actually do

  1. Use it for the one site that needs it

    Keep Firefox as the default and open Chromium only when something misbehaves. Two browsers with separate cookies is also a genuinely useful privacy arrangement.

  2. Import bookmarks from Firefox

    ⋮ menu → Bookmarks → Import bookmarks and settings. It can read Firefox's profile directly, or an HTML file such as the one the Migration Assistant produced.

  3. Install extensions

    The Chrome Web Store works. uBlock Origin is worth adding here too — unlike Firefox, Chromium ships with no blocker at all.

  4. Open the developer tools

    F12. This is the reason many web developers keep Chromium around; the tooling is excellent and identical to Chrome's.

  5. Change the default browser

    System Settings → Default Applications → Web browser. Both are listed there.

One thing that will surprise you

Chrome Sync does not work, and that is Debian being careful, not a bug. Signing into a Google account to sync bookmarks needs private API keys that Google only issues to Google, so Debian's build ships without them. Everything else works normally. If you truly need Chrome Sync you can install Google's own Chrome as a .deb — see installing downloaded software — but be aware that you are then running a proprietary browser that reports back, which is precisely what Dagric is trying to save you from.

Where to find it

Launcher → Chromium.
