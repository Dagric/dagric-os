Security Checkup

A security audit and a drive-health report, in one window, in plain language.

On Windows this wasWindows Security — without the subscription upsell

What it is

The Security Checkup runs two things and shows you the result: a Lynis security audit of the whole system, and a SMART health check of every physical drive. It asks for your password once and does both in one go.

The point is not to find problems — on a stock Dagric machine it will not find many. The point is that a non-expert can see, in a number, that the security they were promised is actually there.

Five things you will actually do

  1. Run it

    Dagric Hub → Security checkup, or launcher → Security Checkup. It takes about a minute and shows a notification while it works.

  2. Read the hardening index

    A score out of 100 from Lynis. Higher is better. It measures the system's configuration against a long checklist — it is a posture score, not a threat detection, and it will never be 100 on a desktop that is also usable.

  3. Read the drive health line

    Every physical disk is reported as healthy or not. If a drive reports a SMART failure, the tool raises a separate warning telling you to back up now and plan to replace it. Believe it.

  4. Look at the detail

    The full audit is written to /var/log/lynis.log, and sudo lynis show details in a terminal explains each finding and what it suggests.

  5. Decide what to act on

    Most Lynis warnings on a desktop are hardening suggestions aimed at servers. Do not chase the score. The ones worth acting on are anything about a failing disk, an outdated package set, or a service you did not know was running.

One thing that will surprise you

It sells you nothing. There is no premium tier, no “3 issues found, upgrade to fix”, and no button that installs something. It runs two open-source audits and reports what they said. The security itself — AppArmor, the hardened kernel, the firewall, the silent updates — was already on before you ran this; the checkup just lets you see it.

Where to find it

Dagric Hub → Security checkup, launcher → Security Checkup, or dagric-security-checkup.
