GameMode, MangoHud and GOverlayPRO

An FPS counter, and a switch that tells the machine a game is running.

On Windows this wasthe Xbox Game Bar overlay, MSI Afterburner, RivaTuner
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Three small tools that work together.

  • GameMode tells the system a game has started, so the CPU governor goes to performance, background housekeeping backs off, and the machine stops being polite.
  • MangoHud draws an overlay: framerate, frame times, CPU and GPU load and temperature, memory. The Linux answer to an Afterburner overlay.
  • GOverlay is a window for configuring MangoHud so you never have to edit its configuration file.

Five things you will actually do

  1. Turn the overlay on for one Steam game

    Right-click the game → Properties → Launch Options, and enter mangohud %command%. Combine them: gamemoderun mangohud %command%.

  2. Choose what the overlay shows

    Open GOverlay, tick the metrics you want, set the position and size, and save. It writes MangoHud's config for you. A minimal overlay of framerate and GPU temperature is usually enough.

  3. Toggle it while playing

    MangoHud's default hides and shows the overlay on a keyboard shortcut (Shift+F12 unless you change it), and can start a frame log for benchmarking on another.

  4. Use it outside Steam

    Run any program with mangohud programname, or turn it on per-game inside Lutris and Heroic, both of which have a tick box for MangoHud and one for GameMode.

  5. Find out whether GameMode is actually active

    gamemoded -s in a terminal answers plainly. If it says inactive while a game is running, the launch option did not take.

One thing that will surprise you

The overlay tells you which component is the problem, which the Windows one never really did. Frame time graph flat and GPU at 99% means you are GPU-limited — lower the settings. GPU at 60% and one CPU core pinned means the game is CPU-limited, and lowering the resolution will not help. Five minutes with MangoHud saves an evening of guessing.

Where to find it

Launcher → GOverlay. MangoHud and GameMode have no windows of their own; they are switched on per game.
