Advanced screen-time controls

Timekpr-nExT exposes detailed per-user time rules behind Family Limits.

On Windows this wasadvanced family screen-time settings

Start with Family Limits

For a daily allowance or bedtime, open Family Limits. It provides the simpler Dagric interface. The Timekpr-nExT control panel is for more detailed schedules and service options. Both affect the same screen-time service, so review the current settings before changing them in a different tool.

Five things you will actually do

  1. Open the right control panel

    The launcher named (SU) Timekpr-nExT Control Panel (superuser mode) asks for administrator authentication. The panel without (SU) requires an account already authorized through the timekpr group. Use the authenticated launcher if you have not set up that delegation.

  2. Select the intended account

    Check the username before editing. Keep a separate administrator account available to undo changes; do not limit your only administrator. A new family account may need to sign in once before its settings appear.

  3. Review the full schedule

    Inspect the selected user's daily allowances and permitted hours. Check each relevant day, and explain the schedule to the person using the account before applying it.

  4. Check the expiry action

    Review what happens when time runs out. A forced sign-out or termination can lose unsaved work. Save open work before testing, and prefer locking when it meets your needs.

  5. Test and adjust

    Apply a small, deliberate change, then check the family account's remaining-time indicator. Reopen the control panel to confirm it saved. Correct the selected user's limits if the result differs from what you intended.

Access and recovery

Membership in the timekpr group grants control of these rules; keep that access with the responsible administrator. Screen-time settings are not a substitute for a standard user account. If you lose track of a rule, use the separate administrator account and Family Limits to remove that user's limits.

If changes do not take effect

Confirm that you selected the right account and authenticated successfully. Have the family member save work, sign out, and sign in again. If the panel cannot reach the service, use Support rather than changing system files by hand.
