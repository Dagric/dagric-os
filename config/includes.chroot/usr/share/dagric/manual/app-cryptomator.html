System and safety

CryptomatorADD-ON

Encrypt files before they ever reach Drive, Dropbox or OneDrive.

On Windows this wasBitLocker To Go, Boxcryptor, and hoping for the best

What it is

Cryptomator creates an encrypted vault inside a folder you already sync to the cloud. You unlock it and it appears as an ordinary drive; you work in it normally. What the cloud provider actually stores is scrambled file contents and scrambled file names.

You hold the only key. There is no recovery, no company account, and nothing to trust except mathematics.

Getting it

Two ways in, and they end up at the same app:

  • Dagric OS Pro — open the Dagric Hub and pick the row for it. A terminal window explains what the app is and asks one yes/no question.
  • Any edition — open Discover, search for it, press Install. It comes from Flathub, so turn Flathub on first if you have not: Finish Setup has a tick box for it.

Either route installs it just for your user account, needs no administrator password, and uninstalls cleanly from Discover's Installed page.

Five things you will actually do

  1. Create a vault

    Press Add Vault → Create New Vault, and put it inside your synced folder (for instance ~/Dropbox/Vault). Choose a strong passphrase and save the recovery key it offers you somewhere safe.

  2. Use it

    Unlock the vault with its passphrase. It mounts as a folder; drag files in, edit them, save. Lock it when you are finished and the plaintext disappears.

  3. Open the same vault on another device

    Let the cloud folder sync, then add the same vault in Cryptomator on the other machine or phone and unlock it with the same passphrase. Nothing is transferred except through the cloud folder you already had.

  4. Decide what belongs inside

    Documents, scans of identity papers, tax records, anything with someone else's personal data in it. Not your entire photo library — encrypted files cannot be deduplicated or thumbnailed by the provider, so the sync gets slower and dumber.

  5. Combine it with rclone

    On Pro, rclone can push the encrypted vault folder to any of seventy providers. The provider sees ciphertext either way.

One thing that will surprise you

Cloud “encryption” usually means encrypted from everyone but the provider. Drive, Dropbox and OneDrive all encrypt your files at rest — with keys they hold, so they can read the contents, hand them to anyone who compels them, and scan them. Cryptomator closes that gap by encrypting on your machine first. It is the only way the sentence “my cloud files are private” is actually true.

Where to find it

After installing: launcher → Cryptomator. Before installing: Dagric Hub → Cloud encryption — Cryptomator, or Discover.
