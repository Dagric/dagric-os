Files and getting around

Dolphin

Your files and folders, and every drive plugged into this computer.

On Windows this wasFile Explorer

What it is

Dolphin is the file manager — the folder icon in the taskbar, and the window that opens when you go looking for your documents. Your home folder holds Desktop, Documents, Downloads, Music, Pictures and Videos, exactly as Windows did, and the Places list down the left is the same idea as the Quick Access sidebar.

Anything you plug in appears in that Places list: USB sticks, external drives, phones, and the Windows partition still sitting on this machine. Dagric reads and writes NTFS and exFAT drives, so a disk you have been using with Windows for years needs no conversion and no ceremony.

Five things you will actually do

  1. Open the Windows drive that is still on this PC

    Look under Devices in the left-hand list — the Windows partition is usually the biggest one. Click it once, type your password if asked, and you are browsing your old files. To bring them across properly rather than by hand, use the Migration Assistant instead.

  2. Copy, move and rename

    Ctrl+C and Ctrl+V work exactly as you expect, and so does dragging. F2 renames. Select several files, press F2, and Dolphin renames them all as a numbered batch — useful for a folder of photos straight off a camera.

  3. Get two folders side by side

    Press F3. The window splits in two and each half browses independently, which is the fastest way to move files from a USB stick into Documents. F3 again puts it back.

  4. Find a file you have lost

    Ctrl+F opens the search bar. It searches file names and, for documents and PDFs, the words inside them. Searching from your home folder covers everything you own.

  5. Reach a network drive or a server

    Press Ctrl+L to turn the breadcrumb bar into a typing box, then enter an address such as smb://server/share for a Windows share, or sftp://user@host for a server. It mounts in place, and every app can then open files from it as if they were local.

One thing that will surprise you

Deleting is genuinely undoable, and permanent deleting is a separate key. Delete moves a file to the Trash, which lives in your home folder and keeps files until you empty it. Shift+Delete is the one that skips the Trash. Dolphin asks first either way.

The other small shock: Dagric is set to double-click to open, the same as Windows. Most Linux desktops default to single-click and it catches switchers out constantly, so we changed it. If you actually prefer single-click, it is in System Settings → Workspace Behaviour → General Behaviour.

Where to find it

The folder icon in the taskbar, or Meta+E (Meta is the ⊞ key). In the launcher it is called Files; typing Dolphin or Explorer finds it too — see why the apps have plain names.
