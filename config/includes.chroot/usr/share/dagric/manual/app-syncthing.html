Internet and communication

SyncthingPRO

Keep a folder identical on several of your own machines, with no server in between.

On Windows this wasOneDrive and Dropbox — without the company
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Syncthing keeps chosen folders in step across your devices. Change a file on the laptop and it appears on the desktop, and on your phone, within seconds. The devices talk directly and everything between them is encrypted; there is no account and no company holding a copy.

It is not a backup — a deletion syncs too. Pair it with Vorta or Kup for that.

Five things you will actually do

  1. Start it and open the control panel

    Syncthing runs as a background service and is configured through a web page on this machine. Start it for your user with systemctl --user enable --now syncthing.service, then open http://127.0.0.1:8384 in Firefox.

  2. Add another device

    Each device has a long Device ID. Paste this machine's ID into the other device and its ID into this one; both then ask you to confirm. The QR code on the same page saves typing when the other device is a phone.

  3. Share a folder

    Add Folder, choose the path, then tick the devices to share it with. They will be asked to accept and to choose where it lands on their side.

  4. Keep a device from writing back

    Set the folder type to Receive Only on a machine that should only ever get a copy — a media box, or a server. It prevents an accidental deletion there from propagating everywhere.

  5. Turn on file versioning

    In a folder's settings, File Versioning → Staggered. Overwritten and deleted files are kept for a while, which softens the sharpest edge of continuous sync.

One thing that will surprise you

The settings page is a web page, and that alarms people. Opening a browser to configure a file-sync tool feels like you have been sent to a website. You have not: 127.0.0.1 is this computer, the page is served by the program running on your own machine, and it is not reachable from anywhere else unless you deliberately change that.

Where to find it

http://127.0.0.1:8384 in a browser once the service is running. Launcher → Syncthing starts it with a tray icon in some setups.
