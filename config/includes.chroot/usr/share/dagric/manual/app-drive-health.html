System and safety

Drive health

Dagric watches your disks and warns you before one dies.

On Windows this wasnothing — Windows has no equivalent it shows you

What it is

Every modern hard disk and SSD keeps a running self-assessment called SMART: reallocated sectors, errors, hours powered on, wear. Dagric reads it.

The plasma-disks service checks your drives in the background and raises a plain-language notification if one starts to degrade. The Security Checkup reports the status of every drive whenever you run it. There is no dashboard to remember to visit — you are told.

Five things you will actually do

  1. Check your drives now

    Run the Security Checkup from the Dagric Hub. It reports each drive as healthy or not, alongside the security audit.

  2. Look at the detail

    sudo smartctl -a /dev/sda in a terminal (replace the device). The lines worth reading are Reallocated_Sector_Ct, Current_Pending_Sector and, on an SSD, Percentage_Used.

  3. Run a self-test

    sudo smartctl -t short /dev/sda takes about two minutes and does not interrupt you; -t long takes hours. Read the result afterwards with sudo smartctl -l selftest /dev/sda.

  4. Act on a warning

    Back up immediately — that day, not that week. A drive that has begun reallocating sectors is telling you it is failing, and the interval between the first warning and the last boot is unpredictable. Then replace it.

  5. Check a drive before you trust it

    Worth doing with any second-hand disk, or an external drive that has been in a drawer for three years, before you make it the destination for your backups.

One thing that will surprise you

This warning is one Windows never gave you. Windows reads SMART data too and, in almost all consumer configurations, says nothing about it until the disk has already failed. Dagric surfaces it because knowing your disk is dying is the difference between an inconvenient afternoon and losing everything. If you get this notification, believe it.

Where to find it

Notifications arrive on their own. On demand: the Dagric Hub → Security checkup, or smartctl in a terminal.
