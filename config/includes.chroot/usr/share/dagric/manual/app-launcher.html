Files and getting around

The launcher and search

The Start menu, and the fastest way to open anything on this computer.

On Windows this wasStart menu and Windows Search

What it is

The Application Launcher is the Dagric logo at the corner of the taskbar, and the Meta key opens it — the same reflex as tapping the Windows key. Applications are grouped by what they are for, there is a search box at the top, and the power and log-out buttons are along the bottom.

Behind it sits KRunner, a search box that appears in the middle of the screen when you press Alt+Space. It opens apps, but it also does arithmetic, converts units and currencies, finds files, and runs commands. It is the single biggest time-saver on the desktop and almost nobody discovers it on their own.

Five things you will actually do

  1. Open an app without hunting for it

    Tap Meta, type the first few letters, press Enter. Works for every application, and for System Settings pages too — typing printer takes you straight to the printer settings.

    Search by whatever name you happen to know. Dagric labels the apps for the job they do — Files, Photos, Terminal — but Dolphin, Gwenview, Explorer and Snipping Tool all find the right thing too. See why the apps have plain names.

  2. Pin something to the taskbar

    Find it in the launcher, right-click it, and choose Pin to Task Manager. Right-click gives you Add to Favourites too, which puts it on the launcher's front page.

  3. Do a sum without opening a calculator

    Alt+Space, then type 1024*7.5 or 25 GBP in EUR or 140 lb in kg. The answer appears as you type; Enter copies it.

  4. Find a document by name

    Alt+Space and start typing the file name. Matching files show up alongside apps, and Enter opens the file in whatever app owns it.

  5. Log out, lock or shut down

    The row of buttons at the bottom of the launcher. Meta+L locks the screen instantly, and Ctrl+Alt+Del brings up the log-out and shutdown panel, exactly as it always did.

One thing that will surprise you

Search results are not sponsored, and nothing you type leaves the machine. There is no web search stapled to the Start menu, no “suggestions”, no advertising panel. If you want a web search you can have one — type a question and pick the web-search result — but it is a choice, not the default.

Where to find it

The logo at the end of the taskbar, or the Meta key. KRunner is Alt+Space from anywhere, even with no windows open.
