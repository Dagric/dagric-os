Dagric Update

Install signed Dagric and system updates with a recovery point first.

On Windows this wasWindows Update with a restore point

What it is

Dagric Update handles normal updates within the installed release. It verifies package sources and creates an explicit recovery point before applying changes. It updates the installed system; it is not the USB installer.

Five things you will actually do

  1. Connect power and internet

    Plug in a laptop and use a stable network. Save work before updating applications that are currently open.

  2. Review what will change

    Read the summary, especially removals, held packages and restart requirements. Cancel if the list looks unrelated or unexpectedly large.

  3. Create the recovery point

    Let Dagric Update finish its pre-update checkpoint. Do not start the package change if recovery setup reports a failure.

  4. Apply without interruption

    Approve the password prompt and leave the computer powered on until the tool says it is complete.

  5. Restart when requested

    Reboot once, check the features you rely on, and use Dagric Rewind only if a new problem clearly began with the update.

Update versus reinstall

Use Dagric Update to stay current on this installation. Use Install Dagric OS only when intentionally installing from a USB drive; it can erase disks.

Where to find it

Launcher → Dagric Update. Discover also shows ordinary application updates.
