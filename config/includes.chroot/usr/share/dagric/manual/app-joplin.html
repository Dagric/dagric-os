Writing and documents

JoplinPROADD-ON

Notes and to-do lists that stay on your computer, in a format you can read.

On Windows this wasOneNote, Evernote, Notion and Sticky Notes

What it is

Joplin keeps notes, notebooks, tags and to-do lists. Every note is plain Markdown stored on this machine — no account, no sign-up, and it works with the wifi off.

Sync is optional and yours to choose: a folder, a Nextcloud or WebDAV server, Dropbox, or nothing at all. Whatever you pick, Joplin can encrypt end-to-end first, so the sync target only ever stores ciphertext.

Getting it

Joplin is not preinstalled. Dagric Hub → Private notes — Joplin, or search Private Notes in the launcher. A terminal window explains what it is and asks yes or no; nothing happens unless you say yes.

It installs from Flathub, just for your user account, so it never asks for an administrator password and it uninstalls cleanly from Discover's Installed page. Nothing else on the machine is touched.

Five things you will actually do

  1. Start writing

    Make a notebook in the left column, then a note. The editor is split: Markdown on the left, formatted result on the right. If you never learn any Markdown, the toolbar buttons for bold, lists and links write it for you.

  2. Make a checklist

    Create a note as a to-do rather than a note and it gets a checkbox. Inside any note, - [ ] thing makes a tickable line.

  3. Find an old note

    The search box searches the full text of every note instantly. Tags help too, and a note can carry as many as you like.

  4. Bring your OneNote or Evernote notes across

    Evernote exports .enex files and Joplin imports them directly (File → Import). OneNote has no clean export, so the practical route is to export each section to PDF or Word from OneNote on Windows before you leave, and attach those to Joplin notes.

  5. Sync to your phone

    Tools → Options → Synchronisation, pick a target, then turn on end-to-end encryption in the same dialogue and enter the same details in the Joplin app on your phone.

One thing that will surprise you

Your notes are just files, and that is the feature. There is no proprietary database and no company between you and your writing. If Joplin vanished tomorrow, the notes would still be readable Markdown you could open in Kate. That is the difference between software you use and a service you are a tenant of.

Where to find it

After installing: launcher → Joplin. Before installing: Dagric Hub → Private notes — Joplin.
