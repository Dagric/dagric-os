System and safety

Install Dagric OS

Move Dagric OS from a bootable USB drive onto this computer.

On Windows this wasWindows Setup

When you should see it

This launcher belongs to the temporary try-before-installing session started from a USB drive. It should not remain on the desktop after Dagric OS is installed. Set Up Dagric OS is the correct post-install tool.

Before you start

Back up irreplaceable files, connect power, and identify the correct internal drive by both size and model. Installation can erase a drive. Unplug backup drives you do not need during setup.

Five steps from beginning to end

  1. Choose language and region

    Select the language, keyboard and time zone you will actually use. Test a few punctuation keys in the keyboard box.

  2. Choose where Dagric goes

    Use the guided whole-disk option for a dedicated Dagric computer. Choose alongside or manual partitioning only when you understand the existing layout.

  3. Read the summary

    Confirm the target drive and every partition marked for deletion or formatting before pressing Install.

  4. Create your account

    Use your real display name, a short login name, and a password you can recover. This password also approves administrative changes.

  5. Restart into the installed system

    Wait for completion, restart, and remove the USB drive when prompted. Then open Set Up Dagric OS.

If the installer cannot see the drive

Stop rather than guessing. Check whether the firmware uses RAID or Intel RST, and use Check This PC from the live session. Do not delete unknown partitions to make the drive appear.

Where to find it

In the USB try-out session: desktop or Launcher → Install Dagric OS.
