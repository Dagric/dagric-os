ProtonUp-QtADD-ON

Install and switch between Proton and Wine builds without a terminal.

On Windows this wasnothing on Windows — this is a Linux gaming convenience

What it is

ProtonUp-Qt downloads and manages compatibility layers for Steam, Lutris and Heroic, including GE-Proton and community Wine builds. Pick a version, press install, and it appears in the game launcher's compatibility list.

It is the graphical alternative to Dagric's GE-Proton helper, and it does more: it manages several tools, several launchers, and removal as well as installation.

Getting it

Two ways in, and they end up at the same app:

  • Any Dagric edition — open the Dagric Hub and pick the row for it. A terminal window explains what the app is and asks one yes/no question.
  • Any edition — open Discover, search for it, press Install. It comes from Flathub, so turn Flathub on first if you have not: Finish Setup has a tick box for it.

Either route installs it just for your user account, needs no administrator password, and uninstalls cleanly from Discover's Installed page.

Five things you will actually do

  1. Install GE-Proton

    Choose Steam as the target, press Add version, select a GE-Proton, install. Restart Steam and it appears under Properties → Compatibility for any game.

  2. Keep an old version on purpose

    A title that regresses after an update may still work with the previous compatibility tool. ProtonUp-Qt lets several versions coexist so you can pin one game to one of them. Test before deleting a version that works for you.

  3. Review other supported launchers

    The target selector shows the launchers detected by the current ProtonUp-Qt release. Choose only a tool intended for that launcher; available tool names and supported targets can change between releases.

  4. Clear out old builds

    Each installed version has a remove button. They are several hundred megabytes each and they accumulate.

  5. Check it landed

    The list shows what is installed per launcher. If a new version does not appear in Steam, close Steam completely and reopen it — it reads the compatibility tools folder only at start-up.

One thing that will surprise you

Newer is not always better. A compatibility-tool update can help one title and regress another. Keep a known-working version until you have tested the features you use, including sign-in, online play and peripherals.

ProtonUp-Qt, its community compatibility tools, Dagric and the named game launchers are independent projects. Availability is not a compatibility guarantee. Review the license or EULA shown for each downloaded tool, runtime or game before installing it.

Where to find it

After installing: launcher → ProtonUp-Qt. Before installing: Dagric Hub → ProtonUp-Qt, or Discover.
