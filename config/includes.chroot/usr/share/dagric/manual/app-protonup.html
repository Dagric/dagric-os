ProtonUp-QtADD-ON

Install and switch between Proton and Wine builds without a terminal.

On Windows this wasnothing on Windows — this is a Linux gaming convenience

What it is

ProtonUp-Qt downloads and manages compatibility layers for Steam, Lutris and Heroic: Proton-GE, Wine-GE, Luxtorpeda and others. Pick a version, press install, and it appears in the game launcher's compatibility list.

It is the graphical alternative to Dagric's Proton-GE helper, and it does more: it manages several tools, several launchers, and removal as well as installation.

Getting it

Two ways in, and they end up at the same app:

  • Dagric OS Pro — open the Dagric Hub and pick the row for it. A terminal window explains what the app is and asks one yes/no question.
  • Any edition — open Discover, search for it, press Install. It comes from Flathub, so turn Flathub on first if you have not: Finish Setup has a tick box for it.

Either route installs it just for your user account, needs no administrator password, and uninstalls cleanly from Discover's Installed page.

Five things you will actually do

  1. Install Proton-GE

    Choose Steam as the target, press Add version, pick the newest GE-Proton, install. Restart Steam and it appears under Properties → Compatibility for any game.

  2. Keep an old version on purpose

    A game that worked last month and broke this month often runs fine on the previous Proton. ProtonUp-Qt lets several versions coexist so you can pin one game to one of them.

  3. Manage Lutris and Heroic too

    The target selector at the top switches between launchers. Wine-GE is the build to install for Lutris and Heroic; Proton-GE is for Steam.

  4. Clear out old builds

    Each installed version has a remove button. They are several hundred megabytes each and they accumulate.

  5. Check it landed

    The list shows what is installed per launcher. If a new version does not appear in Steam, close Steam completely and reopen it — it reads the compatibility tools folder only at start-up.

One thing that will surprise you

Newer is not always better, and this is the tool that teaches you that. Proton-GE releases weekly with fixes for specific games; it also occasionally regresses one that used to work. Keeping two or three versions installed and pinning individual games is normal practice, not a sign that something is wrong.

Where to find it

After installing: launcher → ProtonUp-Qt. Before installing: Dagric Hub → ProtonUp-Qt, or Discover.
