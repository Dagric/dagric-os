NVIDIA driver helper

Install the proprietary NVIDIA driver properly, including the Secure Boot part.

On Windows this wasGeForce Experience and the manufacturer's driver download

What it is

dagric-drivers looks for an NVIDIA card, and if it finds one, offers to install the proprietary driver from Debian's own non-free repository. It is never run for you and nothing is installed unless you answer yes.

AMD and Intel graphics need nothing at all: their drivers are open source and already in the kernel. The tool says so and stops.

Related: on the first login, if this machine has an NVIDIA card and no driver yet, a one-off dialogue offers to run this for you. Decline it and it never asks again — see helpers that run by themselves.

Five things you will actually do

  1. Run it

    Dagric Hub → NVIDIA driver, or sudo dagric-drivers in a terminal. It must run with administrator rights and will tell you so if it does not have them.

  2. Read what it found

    It prints the exact card it detected before asking anything. If the answer is “no NVIDIA GPU found”, that is the end of it and your graphics are already fully driven.

  3. Handle Secure Boot

    This is the part that matters. The NVIDIA driver builds a kernel module, and under Secure Boot an unsigned module will not load — which means a black screen after reboot. The tool checks Secure Boot before installing, tells you, sets up a signing key, and asks you to choose a one-time password.

  4. Finish the enrolment at the next boot

    Restart. A blue MOK Management screen appears: choose Enroll MOK, then Continue, and type the password you just set. The machine then boots into the NVIDIA driver. Skip this and you simply fall back to the open-source driver — you can re-run the tool any time.

  5. Reboot when it is done

    The driver takes effect at the next restart, and the tool says so. Nothing reboots you.

One thing that will surprise you

The black screen after installing an NVIDIA driver is the classic Linux disaster, and this tool exists to prevent it. Almost every guide on the internet tells you to install the driver and reboot, without mentioning Secure Boot at all — and on a modern laptop that is exactly the sequence that leaves you looking at nothing. Dagric checks first and walks you through the enrolment, because the alternative is a beginner's first evening ending in a recovery console.

Where to find it

Dagric Hub → NVIDIA driver, Finish Setup's first tick box, or sudo dagric-drivers.
