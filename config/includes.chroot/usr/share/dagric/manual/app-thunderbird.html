Internet and communication

ThunderbirdPRO

Email, calendar, contacts and feeds, in one window, stored on your machine.

On Windows this wasMicrosoft Outlook and the Mail app
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Thunderbird is a full email client from the makers of Firefox. It handles as many accounts as you like — Gmail, Outlook.com, your own domain, a work Exchange server over IMAP — with a built-in calendar, address book and task list.

Mail is stored on this computer, so it is searchable and readable with no connection, and it is included in your backups like any other file.

Five things you will actually do

  1. Add your email account

    Type your name, address and password. Thunderbird looks up the server settings for you for nearly every provider. Gmail and Outlook.com open a proper sign-in window for their own login and two-factor prompt.

  2. Choose IMAP, not POP

    When offered, take IMAP. Your mail stays on the server and stays in step with your phone; POP downloads it and removes it, which is a decision you make once and regret for years.

  3. Use the calendar

    The calendar tab is built in. New Calendar → On the Network subscribes to a Google, Nextcloud or CalDAV calendar; invitations arriving by email can be accepted straight into it.

  4. Set up a signature

    Account Settings → the account → Signature text, ticking the HTML box if you want formatting. Per account, so work and home can differ.

  5. Find an old message

    The quick filter bar at the top of the message list, or Ctrl+Shift+F for full search across every account with proper conditions. Search works offline on everything already downloaded.

One thing that will surprise you

An Outlook .pst file cannot be opened here. There is no Linux tool that reads Outlook's archive format reliably, and pretending otherwise would waste your evening. The clean answer is to set the account up as IMAP: your mail is on the server and Thunderbird simply downloads it. For mail that only exists inside an old .pst, export it to .eml or copy it to an IMAP folder while you still have Windows and Outlook running. Do that before you wipe the old machine.

Where to find it

Launcher → Thunderbird, or search email or Outlook.
