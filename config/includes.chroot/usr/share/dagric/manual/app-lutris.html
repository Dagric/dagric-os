LutrisPRO

An open-source library manager for games, emulators and compatibility runners.

On Windows this wasa desktop full of separate game launchers
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Lutris can organize games from several sources in one library, including local installers and emulators. Community-written install scripts may configure Wine versions, libraries and workarounds. Those scripts are third-party instructions: review their source and destination before running them.

Five things you will actually do

  1. Install a game with a community script

    Search the game on Lutris's website (or from within the app), press Install, and follow it. The script does the fiddly work — the right Wine build, DXVK, the fonts, the workaround for that one launcher — that you would otherwise be doing by hand. A script can become outdated when a game or service changes.

  2. Add a Windows game you already have

    + → Add locally installed game, choose Wine as the runner and point it at the .exe. Lutris makes it a proper library entry with its own settings and Wine prefix when that program is compatible.

  3. Give each game its own environment

    Every Lutris game has a prefix: a private fake Windows installation. Separate prefixes help reduce conflicts between games, though they are not a security sandbox.

  4. Run emulators

    Lutris handles console emulators as runners too, so a retro collection and a modern library live in the same window with the same artwork.

  5. Tune a game that stutters

    Right-click → Configure. Enable Esync/Fsync, DXVK, and GameMode; set the Wine version; cap the framerate. Change one thing at a time and note what helped.

One thing that will surprise you

Third-party launchers can change without notice. A service may work, partly work or stop working after an update, and a community fix may not be available. Check the current Lutris entry, vendor requirements and recent user reports before relying on a particular game or online feature.

Lutris is an independent open-source project. Names of stores, launchers and games identify optional compatibility targets; Dagric is not affiliated with or endorsed by their owners.
