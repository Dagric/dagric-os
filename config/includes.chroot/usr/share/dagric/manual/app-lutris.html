LutrisPRO

One launcher for everything that is not Steam: Battle.net, EA, Ubisoft, emulators, old discs.

On Windows this wasa desktop full of separate game launchers
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Lutris collects every game you own into one library, whatever it came from: Steam, GOG, Humble, Windows installers, emulators, or a CD-ROM from 2003. For the awkward ones it uses community-written install scripts that set up exactly the Wine version, libraries and registry tweaks a given game needs.

Five things you will actually do

  1. Install a game with a community script

    Search the game on Lutris's website (or from within the app), press Install, and follow it. The script does the fiddly work — the right Wine build, DXVK, the fonts, the workaround for that one launcher — that you would otherwise be doing by hand.

  2. Add a Windows game you already have

    + → Add locally installed game, choose Wine as the runner and point it at the .exe. Lutris makes it a proper library entry with its own settings and its own Wine prefix.

  3. Give each game its own environment

    Every Lutris game has a prefix: a private fake Windows installation. This is why one game's DirectX requirement cannot break another's, and it is the main advantage over running Wine by hand.

  4. Run emulators

    Lutris handles console emulators as runners too, so a retro collection and a modern library live in the same window with the same artwork.

  5. Tune a game that stutters

    Right-click → Configure. Enable Esync/Fsync, DXVK, and GameMode; set the Wine version; cap the framerate. Change one thing at a time and note what helped.

One thing that will surprise you

Some launchers fight back. Battle.net, the EA app and Ubisoft Connect all work under Lutris, and all of them occasionally break themselves with an update and need the install script re-running. This is not Lutris being unreliable — it is a third party changing an application that was never meant to run here. The community usually has a fix within days; the comments on the install script page are where to look.
