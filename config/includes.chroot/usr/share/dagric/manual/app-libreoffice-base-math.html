LibreOffice Base and MathPRO

A desktop database, and a proper equation editor.

On Windows this wasMicrosoft Access and the Equation Editor
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Base is the database part of the suite: tables, forms, queries and printed reports, either in its own file or connected to a real MySQL, PostgreSQL or SQLite database. It is what you reach for when a spreadsheet has stopped being the right shape — a club membership list, a collection catalogue, an invoice book.

Math is the equation editor. It is not a calculator: you type a formula in a compact notation and it renders the typeset mathematics for a document.

Five things you will actually do

  1. Start a database

    Open Base and let the wizard create a new embedded database. Design a table, define its fields, then use the Form Wizard to build a data-entry window over it. That is the whole Access workflow.

  2. Connect to an existing database

    In the same wizard, choose Connect to an existing database and pick the type. This is the useful mode: Base becomes a friendly front end over a database that lives elsewhere.

  3. Ask a question of your data

    Queries → Use Wizard to Create Query for point-and-click filtering and sorting, or Create Query in SQL View if you already know SQL.

  4. Print a report

    Reports → Use Wizard. It builds a printable, grouped, totalled document from a table or query.

  5. Put an equation in a document

    In Writer, Insert → Object → Formula Object. Type something like sum from i=1 to n x_i^2 and it renders as you type. The equation stays editable in the document afterwards.

One thing that will surprise you

An Access .accdb file will not open here. Access's file format is proprietary and Base cannot read it. If you have a real Access database to bring across, export each table to CSV from Access while you still can, and import those into Base — or keep Access running in a Windows virtual machine. Better to know that now than the week after you wipe the old machine.

Where to find it

Launcher → LibreOffice Base and LibreOffice Math. Math is normally reached from inside Writer rather than opened on its own.
