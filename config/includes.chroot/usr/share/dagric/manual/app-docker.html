Docker and PodmanPRO

Containers, both the familiar way and the rootless way.

On Windows this wasDocker Desktop
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Dagric OS Pro installs Docker with Compose, and Podman alongside it. Both run OCI containers and both take almost identical commands.

There is no Docker Desktop, and you do not need one: on Linux, containers run natively on your own kernel. The virtual machine that Docker Desktop runs on Windows and macOS exists only because those systems cannot do this themselves.

Five things you will actually do

  1. Use Docker without typing sudo every time

    sudo usermod -aG docker $USER, then log out and back in. Read the surprise below before you do — this is a real security decision, not a convenience setting.

  2. Run something

    docker run --rm -it debian:trixie bash gets you a shell in a fresh Debian in about a second. --rm throws it away afterwards.

  3. Bring up a stack

    With a compose.yaml in the folder, docker compose up -d starts it and docker compose logs -f follows the output. Debian's package provides the docker-compose command as well.

  4. Use Podman rootless instead

    podman run --rm -it debian:trixie bash. Podman needs no daemon and no group membership: containers run as your own user, so a container escape does not hand out root. Most docker commands work unchanged if you substitute podman.

  5. Reclaim the disk

    docker system df shows what is being used and docker system prune -a removes unused images, containers and networks. Container images accumulate tens of gigabytes quietly.

One thing that will surprise you

Membership of the docker group is equivalent to root. Anyone in it can start a container that mounts the whole filesystem and become root in one command — without a password, and without a sudo log entry. That is not a Docker bug; it is what a root-owned daemon accepting instructions from a socket means.

On a personal workstation it is a reasonable trade and everybody makes it. On a shared or high-value machine, use Podman rootless instead. Dagric deliberately does not add you to that group for you.

Where to find it

A terminal. There is no graphical Docker application; Podman Desktop is on Flathub if you want one.
