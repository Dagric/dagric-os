System and safety

TimeshiftPRO

Scheduled restore points, with a window and a calendar.

On Windows this wasSystem Restore
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Timeshift takes system restore points on a schedule you choose — hourly, daily, weekly, monthly — and lets you restore one from a window rather than from the boot menu.

It sits on top of the snapshot recovery every edition gets, rather than replacing it. The automatic before-and-after snapshots around each update are still there; Timeshift adds a calendar, a graphical restore, and an rsync mode that works on ext4 installs where btrfs snapshots cannot.

Five things you will actually do

  1. Choose a snapshot type

    The first-run wizard offers RSYNC or BTRFS. On a standard Dagric install pick BTRFS — the snapshots are instant and nearly free. Pick RSYNC if you installed onto ext4, or if you want the restore points on a different disk.

  2. Set a schedule

    Settings → Schedule. Daily with five kept is a sensible desktop setting. More than that mostly consumes disk.

  3. Include your home folder — or deliberately not

    Settings → Users. By default your documents are excluded, so a restore rolls back the system and leaves your work alone. That is usually what you want; including home turns Timeshift into a crude backup and it is not a good one.

  4. Restore

    Select a snapshot, press Restore, confirm the target. It walks through the changes it is about to make before doing anything.

  5. Restore a machine that will not boot

    Boot the Dagric live USB, install or run Timeshift there, and point it at the snapshots on the internal disk. This is the rescue path when the boot menu itself is broken.

One thing that will surprise you

It is not a backup, twice over. Restore points on the same disk die with the disk, and by default your documents are not in them at all. Timeshift protects the operating system. Protecting your files is Vorta or Kup, onto something you can unplug.

Where to find it

Launcher → System Restore (also Timeshift). It asks for your password because it works on the whole system.
