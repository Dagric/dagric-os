System and safety

AppArmor and the security baseline

What is protecting this machine while you are not thinking about it.

On Windows this wasWindows Defender, Smart App Control and UAC — loosely

What it is

Dagric is hardened before you change anything, and the pieces are worth knowing by name because none of them has an icon.

  • AppArmor confines programs to what they legitimately need. A compromised PDF reader or browser cannot roam the filesystem, because the kernel refuses.
  • A hardened kernel configuration: kernel pointers and the message log hidden from ordinary users, ptrace snooping restricted, kexec disabled, the BPF and perf attack surfaces locked down, network spoofing protections on.
  • A firewall, on from first boot, and silent security updates every day.
  • Home folders that are not world-readable, so users on the same machine cannot read each other's files.

Five things you will actually do

  1. See that it is on

    sudo aa-status lists the loaded profiles and which processes are confined. sudo lynis audit system produces a full audit with a hardening score.

  2. Run the friendly version of that audit

    The Security Checkup in the Dagric Hub runs Lynis for you and shows the score and the warning count in a window, along with your drive health.

  3. Work out whether AppArmor blocked something

    If a program mysteriously cannot read a file, sudo journalctl -k | grep -i apparmor will say so plainly. That is far quicker than guessing.

  4. Do you need an antivirus?

    Almost certainly not. There is no meaningful population of desktop Linux malware, software comes from signed repositories rather than download sites, and nothing runs with your privileges unless you install it. If you handle Windows files for other people, ClamAV from Discover will scan them — for their sake, not yours.

  5. Encrypt the disk

    This is chosen when you install Dagric, in the installer's Encrypt system option, and it is the single most valuable security setting on a laptop. See accounts and encryption.

One thing that will surprise you

Nothing here interrupts you. There is no equivalent of a security centre with a red badge, no scan that runs while you are trying to work, no subscription about to expire, and no dialogue asking whether you are sure you want to run the file you just double-clicked. The protection is in the kernel and in how software is distributed, not in a program that watches you and asks questions. That is why the machine feels quiet.

Where to find it

Nowhere — it is running. The visible face of it is the Security Checkup in the Dagric Hub.
