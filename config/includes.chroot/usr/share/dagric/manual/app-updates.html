System and safety

Updates

How Dagric keeps itself patched, and why it never reboots you.

On Windows this wasWindows Update

What it is

Security updates install silently, in the background, every day. You are not asked, because being asked whether you want a security fix is not a real choice. Everything else — new versions of applications, feature updates — waits for you on Discover's Updates page.

Dagric never restarts your computer for you. Not while you are presenting, not overnight, not ever. A kernel update takes effect at the next reboot, whenever you choose to have one. That is a deliberate promise and the setting behind it is switched off in the shipped image.

Five things you will actually do

  1. Apply the waiting updates

    Open Discover → Updates and press Update All. It handles Debian packages, Flatpak apps and firmware in one pass.

  2. Update from a terminal instead

    sudo apt update && sudo apt full-upgrade, and flatpak update for sandboxed apps. On Pro, sudo nala upgrade is the same thing with a much more readable display.

  3. Find out whether a restart is worth doing

    Only a kernel update really needs one. Compare what you are running with what is installed: uname -r against ls /boot/vmlinuz-*. If the newest installed kernel is not the one running, a restart will pick it up whenever suits you. There is no nagging bubble — you have to ask.

  4. Update the laptop's firmware

    BIOS and device firmware from the manufacturer appear in Discover's Updates list alongside software. From a terminal: fwupdmgr refresh then fwupdmgr update.

  5. Undo an update that went wrong

    On a standard install, reboot and pick a snapshot from the boot menu — see Snapshot recovery. Every apt run takes a snapshot before and after itself for exactly this.

One thing that will surprise you

An update never takes your software away. There is no equivalent of a feature update that reinstalls apps you deleted, resets your default browser, or re-enables a setting you turned off. Packages are updated in place; your choices are yours. If you removed something, it stays removed.

Where to find it

Discover → Updates. The tray notifies you when there are some; there is no separate updater application.
