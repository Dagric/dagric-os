Writing and documents

Kate

A plain-text editor that scales from a shopping list to a config file.

On Windows this wasNotepad, and most of Notepad++

What it is

Kate opens text files. Not documents — text: notes, lists, configuration files, code, anything where the words matter and the formatting does not. It is Notepad's job done well, with the parts of Notepad++ most people actually use built in.

It colours syntax for hundreds of file types, opens very large files without complaint, has a genuinely good find-and-replace, and keeps a sidebar of every document you have open.

Five things you will actually do

  1. Find and replace across a file

    Ctrl+R. The bar at the bottom does plain text, whole words, or regular expressions, and shows the number of matches as you type. Replace All is a single undo away if it goes wrong.

  2. Edit a system file safely

    Open it normally. When you save a file you do not own, Kate offers to save it with administrator rights and asks for your password, so you never need to launch an editor as root. Cancel and nothing is written.

  3. Work on several files at once

    The Documents sidebar on the left lists everything open. View → Split View puts two files side by side in one window.

  4. Get a terminal in the same window

    F4 opens a terminal panel at the bottom, already in the folder of the file you are editing.

  5. Turn on spell checking

    Tools → Spelling → Automatic Spell Checking. Useful when Kate is doing duty as a notes app.

One thing that will surprise you

Line endings are a real thing and Kate handles them for you. Windows ends every line with two invisible characters; Linux uses one. Kate detects which a file uses and keeps it, so a file you edit here and send back does not arrive as one long line. You can see and change the setting at the bottom right of the window — that little Windows/DOS or Unix label is not decoration.

Where to find it

Launcher → Text Editor (also found by typing Kate, Notepad or notepad++). Double-clicking a .txt opens it here.
