System and safety

KDE Partition Manager

See, format and resize drives with a clear preview before anything changes.

On Windows this wasDisk Management and diskpart

What it is

Partition Manager edits the map that tells a drive where each filesystem begins and ends. Changes are queued first and happen only after you press Apply. That preview is your chance to catch the wrong drive.

Before you change a drive

Back up its files, connect power, and identify it by size, model and contents. A partition operation interrupted by power loss can destroy data. Do not resize the installed system while it is mounted.

Five things you will actually do

  1. Inspect a drive

    Select the device on the left and read the graphical partition bar. Nothing changes while you only select and inspect.

  2. Format a removable drive

    Select its partition, choose a filesystem, give it a clear label, and inspect the pending operation before applying.

  3. Create a partition

    Select unallocated space, choose New, set its size and filesystem, then apply only after checking the device name.

  4. Resize safely

    Make a backup first. Shrink the filesystem before expecting space to appear, and never interrupt the operation.

  5. Undo a queued mistake

    Before Apply, remove the pending operation or close the app. After Apply begins, do not force-quit or power off.

Which filesystem?

Use exFAT for a removable drive shared with Windows and macOS, ext4 or Btrfs for Linux-only storage, and FAT32 only when an older device specifically requires it.

Where to find it

Launcher → Partition Manager. Opening devices and applying changes requires your password.
