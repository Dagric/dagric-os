System and safety

Orca

The screen reader: the desktop, read aloud.

On Windows this wasNarrator

What it is

Orca reads the screen aloud, and drives a refreshable Braille display. Orca ships on every edition of Dagric, with the speech engine and voice installed — which sounds obvious and is not: Orca's speech backend is only a recommended dependency in Debian, so a lean image can easily end up shipping a silent screen reader. Dagric pins it explicitly.

Accessibility is also a procurement requirement in much of the world, so this is part of the base system rather than an optional extra.

Five things you will actually do

  1. Start it

    Launcher → Orca, or orca in a terminal. Orca's own preferences window (Orca modifier + Space) sets the voice, rate, pitch and verbosity.

  2. Learn the Orca modifier

    Every Orca command is that key plus something. On a desktop keyboard it is the keypad Insert; on a laptop it is Caps Lock, set in preferences under Keyboard. Everything else follows from it.

  3. Read the screen

    Orca modifier + ; reads from the top; the flat review keys on the numeric keypad move by line, word and character. Web pages also have structural navigation — H for headings, K for links — when browse mode is on.

  4. Magnify instead

    If the need is low vision rather than blindness, start with Dagric Display, which makes the text and icons bigger and offers to put the change back if it goes too far. System Settings → Accessibility adds a screen magnifier and colour filters.

  5. Use a Braille display

    Plug it in. Orca speaks to a Braille display through BrlTTY, which is installed on every edition of Dagric. Orca's settings for it are under Braille in its preferences, and BrlTTY has its own configuration in /etc/brltty.conf for a display it does not detect automatically.

One thing that will surprise you

Orca works best in GTK applications, and Plasma is Qt. Support in Qt and KDE software is real but historically less polished than in GNOME's applications, so some parts of the desktop read better than others. It is improving steadily. If a screen reader is your primary way of using a computer, test the specific applications you depend on from the Dagric live USB before you commit to installing.

Where to find it

Launcher → Orca. Related settings: System Settings → Accessibility.
