Music and sound

AudacityPRO

Record and edit audio: voice-overs, podcasts, tidying up a recording.

On Windows this wasVoice Recorder, and Audacity on Windows
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Audacity records from a microphone and edits the result: cut, fade, amplify, remove noise, and export to MP3, WAV or FLAC. It is the standard tool for a podcast, a voice-over, or rescuing a recording of a lecture.

Debian builds Audacity from source with the telemetry and update-check code disabled, so the privacy row that surrounded it a few years ago does not apply to the copy on this machine.

Five things you will actually do

  1. Record your voice

    Choose the input device in the toolbar at the top, watch the level meter while you speak (aim for peaks around −12 dB), then press the red record button. Space stops.

  2. Remove background hiss

    Select two seconds of silence, then Effect → Noise Removal and Repair → Noise Reduction → Get Noise Profile. Select the whole track, open the same effect again, and press OK. Do not overdo it — heavy reduction makes voices sound underwater.

  3. Cut out a mistake

    Select the section and press Delete. Add a short crossfade at the join (Effect → Fading) if the cut clicks.

  4. Even out the volume

    Effect → Volume and Compression → Compressor, then Normalize to bring the whole thing up to a consistent level. This is what makes a home recording sound professional.

  5. Export

    File → Export Audio. MP3 for podcasts and sharing, WAV or FLAC if it is going into a video editor. Audacity's own .aup3 project file keeps your tracks and edits; it is not an audio file.

One thing that will surprise you

Saving does not produce an audio file. Just like GIMP, Audacity's Save writes a project you can carry on editing. The MP3 comes from File → Export Audio. Every new user loses ten minutes to this once.

Where to find it

Launcher → Audacity.
