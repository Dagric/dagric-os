Internet and communication

Wi-Fi, wired networks and VPN

Getting online, staying online, and connecting to a work network.

On Windows this wasthe network flyout and VPN settings

What it is

Networking is NetworkManager, driven from the network icon in the system tray. Click it for the list of Wi-Fi networks, the wired connection, any VPNs you have set up, and an airplane-mode switch.

Wi-Fi hardware works out of the box on the overwhelming majority of laptops because Dagric ships the firmware for Intel, Realtek, Atheros and Broadcom cards. This is one of the classic reasons a Linux install used to fail on the first evening, and it is the reason that firmware is in the base image rather than an optional extra.

Five things you will actually do

  1. Join a Wi-Fi network

    Click the network tray icon, pick the network, type the password, tick to store it. It is remembered and rejoined automatically from then on.

  2. Import a VPN configuration

    System Settings → Connections → + → Import VPN connection, and choose the file your provider or employer gave you. Dagric ships the OpenVPN, OpenConnect (Cisco AnyConnect) and L2TP/IPsec handlers, and WireGuard support is built into the kernel, so a .ovpn or .conf file just imports.

  3. Mark a network as trusted — or not

    System Settings → Firewall shows each connection's zone. Home allows things like phone pairing and file sharing; Public shuts them. Set café and airport wifi to public and leave it there.

  4. Share this machine's connection

    In the connection's settings, set the Wi-Fi mode to Access Point. Useful for tethering a tablet through a wired connection in a hotel.

  5. Diagnose a connection that will not work

    In order: is the network icon showing a connection at all; does ping 1.1.1.1 in a terminal answer (that tests the network); does ping debian.org answer (that tests DNS). Knowing which of the three fails turns a mystery into a five-minute fix.

One thing that will surprise you

There is no captive-portal nag — there is a captive-portal window. Hotel and airport networks that want you to accept terms are detected, and Plasma offers to open the sign-in page. Read what you are agreeing to; that page is the one part of the network you should be suspicious of, and Dagric will not click it for you.

Where to find it

The network icon in the system tray. Full settings: System Settings → Connections. Firewall zones: System Settings → Firewall.
