Heroic Games LauncherADD-ON

Your Epic, GOG and Amazon libraries, without their Windows launchers.

On Windows this wasthe Epic Games Launcher and GOG Galaxy

What it is

Heroic signs into Epic Games, GOG and Amazon Prime Gaming and installs your games from them, running Windows titles through Proton or Wine automatically. It is a clean, open-source replacement for launchers that have no Linux version at all.

Notably, it will claim the free Epic game every week, which is most people's actual reason for having an Epic account.

Getting it

Two ways in, and they end up at the same app:

  • Dagric OS Pro — open the Dagric Hub and pick the row for it. A terminal window explains what the app is and asks one yes/no question.
  • Any edition — open Discover, search for it, press Install. It comes from Flathub, so turn Flathub on first if you have not: Finish Setup has a tick box for it.

Either route installs it just for your user account, needs no administrator password, and uninstalls cleanly from Discover's Installed page.

Five things you will actually do

  1. Sign in

    Each store is a separate log-in on Heroic's first screen. Epic and Amazon open a browser window; GOG asks for your credentials. Your library appears once it syncs.

  2. Install and play

    Pick a game, choose an install folder, press Install. Heroic selects a compatibility layer for you; Windows-only games get Proton and it says so.

  3. Change the Proton or Wine version

    The game's settings page has a Wine version selector, fed by whatever is installed — including builds added by ProtonUp-Qt or the Proton-GE helper.

  4. Get the weekly free Epic game

    The store page inside Heroic shows it; claiming it adds it to your library permanently, whether or not you ever install it.

  5. Move a game to another drive

    The game's settings offer to move the installation. Doing it this way keeps Heroic's records straight; dragging the folder in Dolphin does not.

One thing that will surprise you

GOG games are yours to keep, and Heroic makes that obvious. GOG sells DRM-free installers, so a game you buy there can be downloaded, backed up, and run in ten years with no launcher and no account. Heroic can download the offline installers directly. On a machine you own, that difference is worth noticing.

Where to find it

After installing: launcher → Heroic Games Launcher. Before installing: Dagric Hub → Heroic — Epic, GOG, Amazon, or Discover.
