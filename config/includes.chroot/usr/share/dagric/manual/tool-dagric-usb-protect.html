USB ProtectionPRO

Block malicious USB devices — without locking out your own keyboard.

On Windows this wasnothing — Windows has no consumer equivalent
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

A BadUSB attack is a device that looks like a memory stick but identifies itself to the computer as a keyboard, and then types commands. Nothing about the operating system is broken; the machine simply believes what the device told it. USBGuard is the defence: only devices on an allow-list are accepted.

USB Protection is the tool that turns that on safely. Left to itself, USBGuard's default is to block everything and its shipped rule list is empty — switching it on naively would deauthorise your own keyboard and mouse with no way left to click “allow”. So Dagric ships it fully inert and this helper does the steps in the only safe order.

Five things you will actually do

  1. Plug everything in first

    Before you turn it on: keyboard, mouse, webcam, printer, drives, dock, headset. The tool takes a snapshot of what is attached right now and allows exactly those. Anything unplugged at that moment will be blocked when you plug it back in.

  2. Turn it on

    Dagric Hub → USB protection. It explains what will happen, asks you to confirm, then asks for your password. It generates the allow-list first and only then starts the daemon — and if the generated list comes out empty it refuses to arm at all.

  3. Live with it

    Your own devices work exactly as before. A new USB device — a friend's stick, something found in a car park — is blocked until you approve it.

  4. Add a device you have since bought

    Plug it in along with everything else and run the tool again. It regenerates the list from what is currently attached.

  5. Turn it off

    Run the tool again. If protection is already on it offers to switch it off and allow all USB devices again. It is a toggle, not a one-way door.

One thing that will surprise you

It is off out of the box, and it is masked rather than merely disabled. USBGuard's own packaging enables a companion service that pulls the blocking daemon in at every boot; on a live USB that could cut off the very stick the session is running from. Dagric masks both units so nothing can start them by accident, and this helper unmasks them only after an allow-list exists. If you were wondering why a security feature ships switched off — that is why.

Where to find it

Dagric Hub → USB protection, launcher → USB Protection, or dagric-usb-protect.
