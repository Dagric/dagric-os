DistroboxPRO

An Ubuntu, Fedora or Arch userland in a terminal, sharing your home folder.

On Windows this wasWSL — the Windows Subsystem for Linux
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Distrobox gives you another distribution's userland inside a container that shares your home folder, your display, your audio and your graphics card. You can run an Ubuntu 24.04 shell, install an Ubuntu-only package, run it, and see the results in your own Documents folder.

If you used WSL on Windows, this is the same idea from the other side, and the integration is considerably deeper.

Five things you will actually do

  1. Create a box

    distrobox create -i ubuntu:24.04 -n ubuntu. Any OCI image works: Fedora, Arch, openSUSE, an old Debian, a vendor's own image.

  2. Enter it

    distrobox enter ubuntu. You are at an Ubuntu prompt, in your own home folder, as yourself. sudo inside the box affects only the box.

  3. Install the thing that only exists for Ubuntu

    Add the vendor's apt repository inside the box and install normally. Your host system stays clean — which is the entire point.

  4. Put a container app in the Dagric launcher

    distrobox-export --app someapp from inside the box creates a launcher entry on the host. The application runs in the container and looks like a normal installed program.

  5. Throw it away

    distrobox rm ubuntu. Your files are in your home folder and are untouched, because they were never inside the container to begin with.

One thing that will surprise you

It shares your home folder by default, and that cuts both ways. The convenience is enormous — no copying files in and out — but a command run inside the box can delete your documents just as easily as one run outside it. A container here is an isolation of software, not of your data. Use --home to give a box its own separate home directory when you are running something you do not trust.

Where to find it

A terminal. Exported applications appear in the Dagric launcher like any other.
