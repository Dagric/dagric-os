Set Up Dagric

The wizard you meet at your first login, and can open again whenever you like.

On Windows this wasthe Windows out-of-box experience

What it is

Set Up Dagric opens once, at your first login, and asks a handful of questions that actually change the machine: light or dark, which wallpaper, an accent colour, how big the text should be, where the taskbar goes, and — if it finds a Windows installation on this disk — whether to fetch your files across now.

Every step is skippable. Closing the window at any point leaves a desktop that works, because every question has a sensible answer already selected.

Five things you will actually do

  1. Answer or skip

    Each screen has a way past it. Nothing is required, and nothing here is a setting you cannot reach again from the Dagric Hub later.

  2. Undo the whole thing

    The header carries Undo my changes, which puts the colours, accent, wallpaper, text size and panels back exactly as they were when the wizard opened. It is the answer to “what if I make it worse”, and it is one button.

  3. Bring your files over during setup

    If a Windows drive is on this PC the wizard offers to run the Migration Assistant there and then. Windows is only ever read. If you would rather do it later, say no — it is in the Hub.

  4. Open it again

    Launcher → Set Up Dagric, or dagric-firstrun. It only opens by itself once; run by hand it always opens, so you can redo the whole setup on a whim.

  5. Use it without the pictures

    On a machine where the graphical window cannot start, the same journey runs as a series of plain dialogues instead — light or dark, wallpaper, text size, taskbar, files. A first run that never appears would be far worse than a plain one.

One thing that will surprise you

It marks itself as done when the window actually appears — not when it starts, and not when you press Finish. That sounds like a detail and it is the difference between a wizard that works and one that annoys. Marking it at start would mean a login where the desktop was not quite ready burned your one chance to ever see it. Marking it at Finish would mean a wizard you deliberately closed came back at the next login, uninvited. Closing it is an answer, and Dagric treats it as one.

Where to find it

It opens itself at your first login. After that: launcher → Set Up Dagric, Dagric Hub → Set up Dagric (welcome wizard), or dagric-firstrun.
