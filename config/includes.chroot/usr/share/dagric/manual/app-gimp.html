GIMPPRO

Serious photo editing: layers, masks, retouching, the lot.

On Windows this wasAdobe Photoshop
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

GIMP is the heavyweight image editor: layers, layer masks, selections, curves and levels, the clone and heal tools, filters, and scripted batch work. If a tutorial says “in Photoshop, do this”, GIMP almost always has the same capability under a different name.

Dagric OS Pro sets up the PhotoGIMP profile for new accounts, which rearranges the panels and remaps the keyboard shortcuts to match Photoshop's. It makes the first hour dramatically less frustrating.

Five things you will actually do

  1. Crop and straighten a photo

    The Crop tool from the toolbox, drag, Enter. For a wonky horizon use Tools → Transform Tools → Rotate and nudge by a degree or two, then crop the corners off.

  2. Remove something from a picture

    The Heal tool for blemishes and small marks: Ctrl-click a clean area to sample, then paint over the flaw. The Clone tool works the same way and is better for larger, patterned areas.

  3. Work in layers

    Layer → New Layer, or drag another image into the window to bring it in as a layer. The Layers panel controls order, opacity and blend mode. Add a layer mask to hide part of a layer without deleting it.

  4. Fix exposure and colour

    Colors → Levels for the quick fix, Colors → Curves for control. Colors → Color Balance corrects a photo that has gone orange under indoor light.

  5. Export for the web or for email

    Ctrl+S saves GIMP's own .xcf format with all your layers intact. To produce a JPEG or PNG, use File → Export As and type a filename ending in .jpg or .png.

One thing that will surprise you

Save and Export are different things, and this trips up everyone exactly once. Ctrl+S saves a GIMP project; it will not produce a JPEG no matter how you name it. The JPEG comes from File → Export As (or Ctrl+Shift+E to re-export over the last one). It is deliberate — GIMP refuses to silently throw your layers away — but it is the single most common “where did my picture go” moment in the program.

If you would rather have GIMP's own stock layout instead of the Photoshop-style one, close GIMP, delete the GIMP folder inside ~/.config, and start it again.

Where to find it

Launcher → GIMP, or search Photoshop — the manual and the launcher both answer to that.
