BlenderPRO

3D modelling, animation, rendering — and a surprisingly good video editor.

On Windows this was3ds Max, Maya, Cinema 4D
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Blender is a complete 3D suite: modelling, sculpting, UV unwrapping, materials, rigging, animation, physics simulation, and two renderers (Cycles for accuracy, EEVEE for speed). It is used on television and in feature films, and it is free.

It is also the steepest learning curve of anything on this computer. Budget an evening for a beginner tutorial rather than expecting to poke at it successfully.

Five things you will actually do

  1. Learn the navigation first

    Middle mouse button orbits, Shift+middle pans, scroll zooms. The numeric keypad jumps to standard views: 1 front, 3 side, 7 top, 0 camera. Nothing else makes sense until this is automatic.

  2. Move, rotate and scale

    G grabs, R rotates, S scales. Follow any of them with X, Y or Z to constrain to an axis, or type a number for an exact amount.

  3. Model something

    Tab enters Edit Mode on the selected object. E extrudes a face, Ctrl+R adds a loop cut, I insets. Those four keys build a startling amount.

  4. Render an image

    Set the renderer and samples in the Render Properties tab, then F12. On a machine with an NVIDIA card, install the proprietary driver with Dagric's driver helper first and enable GPU rendering in Preferences — it is often ten times faster.

  5. Edit video in it

    Switch the workspace to Video Editing. Blender's sequencer handles cuts, transitions, colour and audio perfectly well, and it is worth knowing about when you already have Blender open.

One thing that will surprise you

Almost every command is a keyboard shortcut, and the menus are an afterthought. Blender was designed to be driven with one hand on the keyboard and one on the mouse, and it does not try to hide that. This is why it feels impenetrable for the first hour and extraordinarily fast afterwards. Do not fight it — learn G, R, S and Tab and the rest follows.

Where to find it

Launcher → Blender.
