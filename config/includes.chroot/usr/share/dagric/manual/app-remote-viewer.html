Remote ViewerPRO

Open the screen of a local virtual machine or a trusted remote desktop.

On Windows this wasRemote Desktop Connection or a virtual-machine console
This one is part of Dagric OS Pro. It accompanies the virtual-machine tools and is documented here so its purpose is clear.

What it is

Remote Viewer displays a desktop provided through SPICE, VNC or libvirt. It is a viewer, not the virtual machine itself. Closing the window may leave the guest running.

Five things you will actually do

  1. Open a local guest

    Start it from Virtual Machine Manager and choose its display. That supplies the connection safely without typing an address.

  2. Connect from a file

    Open a trusted .vv connection file. Treat connection files like sign-in links; do not open one from an unknown sender.

  3. Release the keyboard and mouse

    Use the grab-key combination shown in the window menu when the pointer appears trapped inside the guest.

  4. Resize the display

    Enable automatic resize when the guest supports it, or choose a guest resolution that fits the window.

  5. Shut down correctly

    Use the guest operating system's Shut Down command. Closing the viewer alone does not guarantee the guest stopped.

Connection safety

Connect only to a machine or service you control. Do not bypass certificate warnings for an internet address, and never expose VNC directly to the public internet.

Where to find it

Usually from Virtual Machine Manager. The separate Remote Viewer launcher accepts a supported connection address or file.
