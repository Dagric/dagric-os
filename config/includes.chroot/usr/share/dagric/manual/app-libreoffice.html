Writing and documents

LibreOffice

One starting place for documents, spreadsheets, presentations, drawings and formulas.

On Windows this wasthe Microsoft Office home screen

What it is

The LibreOffice Start Center opens the right part of the office suite and keeps recent files together. Writer handles documents, Calc spreadsheets, Impress presentations, Draw diagrams and PDFs, and Math formulas.

Five things you will actually do

  1. Start the right kind of file

    Choose Writer for pages of text, Calc for rows and numbers, Impress for slides, or Draw for diagrams and PDF work.

  2. Open an existing Office file

    Choose Open File and select a .docx, .xlsx or .pptx. Check complex layout before sending it back.

  3. Recover a recent file

    Select it from the recent list. If it is missing, open Dolphin and search by part of the filename.

  4. Save in the right format

    Use the LibreOffice format while editing when possible. Use Microsoft formats when collaborators require them, and PDF for a final copy that should not move around.

  5. Export a PDF

    Open the file and choose File → Export As → Export as PDF. Review the PDF in Okular before sharing.

A simple compatibility rule

Keep one editable master and one delivery copy. For an important Microsoft Office hand-off, save a second copy in the requested format and open that copy again to check it.

Where to find it

Launcher → LibreOffice, or open Writer, Calc, Impress and Draw directly.
