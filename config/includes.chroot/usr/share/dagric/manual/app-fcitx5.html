Typing in another language

Use Fcitx 5 to type characters that need more than a keyboard layout.

On Windows this wasinput methods and IME settings

What it is

A keyboard layout changes which character a key produces. An input method also lets you compose and choose characters while typing. Dagric includes Fcitx 5 with Japanese (Anthy) and Korean (Hangul) support; the Pro package selection also includes Chinese input methods. Installing fonts alone does not enable these typing methods.

Five things you will actually do

  1. Open input settings

    Open System Settings and search for Input Method. You can also use Fcitx 5 Configuration where that launcher is shown. It opens the configuration appropriate to your desktop.

  2. Add the language you type

    Use the add button and search for an installed method such as Anthy or Hangul. If the list only shows your current language, turn off that filter. Keep your ordinary keyboard layout available too.

  3. Choose a comfortable shortcut

    In Fcitx's global options, inspect the shortcut for activating or switching input methods. Change it if another app uses the same keys, then apply your settings.

  4. Try a short sentence

    Open Kate, activate the method, type a few words, and choose the intended characters from the candidate list. Then switch back to your ordinary keyboard and check that it still works.

  5. Make it work in your desktop session

    On a Plasma Wayland session, find Virtual Keyboard in System Settings and select Fcitx 5 if it is not already selected. Save your work and sign out and back in after changing session input settings.

What the two launchers do

Fcitx 5 starts the input-method service; it is not the settings window and may appear only in the tray. Fcitx 5 Configuration opens settings. Plasma normally exposes those settings inside System Settings, so the separate configuration launcher may be hidden there.

If typing still uses the wrong characters

Check the active keyboard and method first. If it works in Kate but fails in another app, close and reopen that app after saving your work. App support varies. If your language's method is absent, look for its Fcitx package in Discover; changing the display language does not install every input engine. Use Support if it remains unavailable.
