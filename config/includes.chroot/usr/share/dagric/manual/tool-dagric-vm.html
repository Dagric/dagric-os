Windows in a window (VM setup)PRO

Switch on the virtual-machine stack, with consent, and get pointed at a legal Windows ISO.

On Windows this wasturning on Hyper-V
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Dagric OS Pro preinstalls a complete open-source virtualisation stack — KVM, QEMU, libvirt, virt-manager, UEFI firmware and a software TPM — but leaves every part of it switched off. A machine that never runs a VM should not be running VM daemons or carrying a network bridge it did not ask for.

dagric-vm is the consent step that turns it on.

Five things you will actually do

  1. Run it

    Dagric Hub → Windows in a VM, or dagric-vm. It explains the three things it will do before doing any of them.

  2. Let it check your processor

    It looks for Intel VT-x or AMD-V support first. If virtualisation is switched off in your firmware it stops there and tells you how to switch it on — reboot, enter setup (often F2 or Del), find Virtualization, SVM or VT-x, enable, save — rather than letting you discover the problem an hour later.

  3. Approve the change

    Answer yes and give your password. It adds your user to the libvirt and kvm groups, starts the VM service, and starts the default NAT network so new machines have working networking.

  4. Log out and back in once

    Group membership only takes effect at your next login. The tool says so. Skip it and Virtual Machine Manager will complain that it cannot connect.

  5. Get Windows legally

    The tool prints Microsoft's own download address. Windows in a VM runs unactivated with minor cosmetic limits, or you can use a licence key you already own. Dagric never bundles Windows — that would not be legal and would not be honest.

One thing that will surprise you

Installing the software did not switch it on, and that is unusual. Debian's libvirt package normally enables its daemons at boot, which would mean every Pro owner ran a hypervisor service and a virtual network bridge with its own DNS server whether or not they ever opened a VM. Dagric turns all of that off at build time and lets this helper — and only this helper — switch it on, so that what the tool tells you it is doing is genuinely what is happening.

Where to find it

Dagric Hub → Windows in a VM, launcher → Windows in a Window (VMs), or dagric-vm.
