Vorta and BorgPRO

Encrypted, deduplicated backups — the serious option, with a friendly window.

On Windows this wasFile History, Backblaze, Acronis
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Borg is a backup engine with three properties that matter: it deduplicates (the same data is stored once, however many times it appears), it compresses, and it encrypts before anything is written. A daily backup of a 500 GB home folder can occupy very little new space each day.

Vorta is the window in front of it, so you never have to learn Borg's command line. Repositories can live on a plugged-in drive, a NAS, or a server you reach over SSH.

Five things you will actually do

  1. Create a repository

    In Vorta, Repository → New repository. Pick a local path or an SSH target, choose encryption (repokey with a passphrase is the normal answer), and write the passphrase down somewhere physical.

  2. Choose what goes in

    The Sources tab. Add your home folder, then use the exclusion patterns to drop caches, Downloads, VM images and game libraries.

  3. Schedule it

    The Schedule tab: an interval, or at a fixed time, or when a particular drive appears. Vorta can also be told not to run on battery or on a metered connection.

  4. Restore

    The Archives tab lists every backup by date. Extract opens the contents so you can pull out one file, or the whole thing. You can also mount an archive as a folder and browse it in Dolphin.

  5. Prune old archives

    The retention settings keep, for example, seven daily, four weekly and six monthly archives and delete the rest. Without pruning, a repository grows forever.

One thing that will surprise you

Lose the passphrase and the backup is gone. Borg's encryption is real encryption — there is no recovery service, no reset link and no support desk with a master key. That is precisely what you want from a backup you might store on somebody else's server, and it is unforgiving. Put the passphrase in KeePassXC and on paper somewhere else.

Then do the other thing nobody does: restore a file, on purpose, a week after you set this up. An untested backup is a hope.

Where to find it

Launcher → Encrypted Backup (also Vorta). The engine underneath is borg in a terminal if you ever want it.
