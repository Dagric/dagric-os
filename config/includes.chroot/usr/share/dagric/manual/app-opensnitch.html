System and safety

OpenSnitchPRO

See — and control — every outbound connection any program makes.

On Windows this wasLittle Snitch, GlassWire
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

An ordinary firewall controls what can reach in. OpenSnitch controls what can go out: it watches every connection a program tries to make and can ask you, per application, whether to allow it.

It is the single most revealing tool on the machine. Run it for an afternoon and you will find out exactly which of your programs talk to the internet, how often, and to whom.

Five things you will actually do

  1. Watch first, block later

    Dagric ships OpenSnitch in monitor mode: its default action is to allow, and it does not intercept connections it has no rule for. So out of the box it observes and never interrupts you. Leave it there for a week before changing anything.

  2. See what has been happening

    Open the OpenSnitch UI from the tray. The tabs list connections by application, by host and by port, with counts. Sort by application and read down the list.

  3. Turn on prompting

    In the UI's preferences, change the default action to deny and enable intercepting unknown connections. From then on a new connection raises a dialogue: allow or deny, once or forever, for this program or this destination.

  4. Write a rule

    Rules can be as broad as “allow this application anywhere” or as narrow as “allow only to this host on port 443”, and can expire after a set time. Blocking a single telemetry endpoint while leaving an application otherwise working is entirely possible.

  5. Back out safely

    If a rule breaks something, set the default action back to allow in the UI. Nothing is permanent and the daemon can be stopped with sudo systemctl stop opensnitch.

One thing that will surprise you

The first hour is uncomfortable. Once you turn prompting on you discover how much perfectly ordinary software connects to perfectly ordinary places — update checks, certificate revocation lists, time servers, font downloads — and the temptation is to block everything and then spend the evening wondering why the browser is broken. Allow the things you recognise, take your time, and remember that on a Dagric machine you started from a far quieter baseline than you are used to.

Where to find it

The OpenSnitch icon in the system tray, or launcher → OpenSnitch. The daemon starts with the system; the window is just a view onto it.
