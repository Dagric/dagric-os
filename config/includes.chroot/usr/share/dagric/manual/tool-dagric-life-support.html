Dagric Life Support

A read-only emergency assessment when the system feels full, slow or unstable.

On Windows this wasStorage Sense, health checks and recovery advice

What it is

Life Support checks resource and storage pressure, then recommends a recovery action. The assessment does not delete files, modify disks or start a rollback. You remain in control of the next step.

Five things you will actually do

  1. Run the assessment

    Open Life Support and let it finish. Keep the window open so you can read the full explanation.

  2. Read the severity first

    Distinguish an urgent storage or health warning from ordinary temporary load before changing anything.

  3. Protect files before repair

    If the report suggests storage or drive trouble, copy irreplaceable files to another drive before cleanup or recovery.

  4. Use the recommended tool

    Choose Filelight for space, Drive Health for hardware, Security Checkup for protection, or Rewind for a recent system change.

  5. Run it again

    After the safe action, reassess and confirm that the warning changed rather than assuming the problem is gone.

What it never does

It does not record your screen, upload a report, delete data or silently start a recovery. A read-only diagnosis is useful precisely because it can be run before you decide.

Where to find it

Launcher → Dagric Life Support. Results appear in a terminal window.
