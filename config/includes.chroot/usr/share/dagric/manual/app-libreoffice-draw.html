Writing and documents

LibreOffice DrawPRO

Diagrams, posters, and the best way to edit a PDF on this computer.

On Windows this wasMicrosoft Publisher, light Visio work, and a paid PDF editor
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Draw is the page-layout and diagram tool in the full LibreOffice suite. Boxes, arrows, connectors that stay attached when you move things, layers, and precise placement on a page — flowcharts, floorplans, certificates, a poster for the village hall.

Its quiet superpower is PDFs: Draw opens a PDF and lets you edit the text and objects in it directly, then save it back. On Windows that is a subscription.

Five things you will actually do

  1. Edit the text in a PDF

    File → Open and pick the PDF. Click into a line of text and change it. Then File → Export as PDF — not Save, which would write a Draw document.

    It works best on PDFs made from text. A scanned page is a picture, and no tool can edit words in a picture without recognising them first.

  2. Draw a flowchart

    Use the shapes on the toolbar, then the Connector tool between them. Connectors glue to shapes and re-route themselves when you drag a box, which is the whole point.

  3. Lay out a poster or a leaflet

    Format → Page Style to set the paper size and orientation, then place text boxes and images freely. Unlike Writer, nothing reflows — what you put at a spot stays at that spot.

  4. Delete something from a scanned document

    Open the PDF, draw a filled white rectangle over the part you want gone, and export. Be aware this covers rather than removes; for genuinely sensitive redaction, export a flattened image-based PDF afterwards.

  5. Reuse a drawing elsewhere

    Copy and paste a diagram straight into Writer or Impress. It arrives as an editable object, not a screenshot.

One thing that will surprise you

Draw will happily open a PDF that a PDF reader refuses to edit. It is one of the most useful things on a Pro machine and almost nobody looks for it under a program called “Draw”. The catch is that it rebuilds the page from what it can identify, so a densely typeset PDF may come apart into many small text boxes. Check the result before you send it.

Where to find it

Launcher → LibreOffice Draw. Or right-click a PDF in Dolphin → Open With → LibreOffice Draw.
