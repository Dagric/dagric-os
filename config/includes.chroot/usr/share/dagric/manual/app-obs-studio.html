OBS StudioPRO

Record your screen or stream live, with a proper mixer behind it.

On Windows this wasthe Xbox Game Bar recorder, Camtasia, and Streamlabs
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

OBS Studio composes a video from sources — a screen, a window, a webcam, an image, some text — arranged into scenes you switch between, and then either records it to a file or streams it live to Twitch, YouTube or anywhere else that speaks RTMP.

It is what nearly every streamer and tutorial-maker uses, on every platform. For a quick unadorned screen recording, Spectacle is less setup.

Five things you will actually do

  1. Set it up the first time

    Let the auto-configuration wizard run — it tests your machine and picks sensible resolution and bitrate. You can change everything later in Settings.

  2. Record your screen

    In the Sources box press + → Screen Capture (PipeWire). A permission dialogue asks which screen or window to share — that prompt is the desktop protecting you, not an error. Then press Start Recording.

  3. Add your webcam and microphone

    + → Video Capture Device for the camera; drag and scale it into a corner. Microphones appear in the Audio Mixer at the bottom, where you can set levels and add noise suppression from the gear icon → Filters.

  4. Build scenes you can switch between

    Make one scene for “full screen”, one for “camera only”, one for a title card. Click between them live, or bind them to hotkeys in Settings → Hotkeys so they work while another window has focus.

  5. Stream

    Settings → Stream, choose the service, paste your stream key, press Start Streaming. Test with an unlisted or private stream first — everybody's first attempt has the microphone muted.

One thing that will surprise you

Screen capture goes through a permission prompt every time, and that is a feature. On Wayland — the modern display system Plasma uses — no application can silently read your screen. OBS must ask, and the desktop shows you a picker. It feels like friction after Windows, where any program could quietly capture everything. Tick “remember” in the picker to reduce it to once per session.

Where to find it

Launcher → OBS Studio.
