Wine with a window: one tidy container per Windows program.

What it is

Bottles is a friendly front end to Wine. Each Windows program gets its own “bottle” — a self-contained fake Windows with its own settings, its own runtimes and its own registry — created from a template tuned for gaming, for applications, or for a specific piece of software.

It also carries a catalogue of installers for common programs, so a good deal of the guesswork about which components a given application needs has already been done.

Getting it

Two ways in. Both work on every edition, and they end up at the same app:

  • The Dagric Hub — open the Dagric Hub and pick Windows apps — Bottles. A terminal window explains what the app is and asks one yes/no question. That row is on the free edition too: Bottles is free software from Flathub, and there is nothing in fetching it worth charging for.
  • Discover — open Discover, search for it, press Install. It comes from Flathub, so turn Flathub on first if you have not: Finish Setup has a tick box for it.

Either route installs it just for your user account, needs no administrator password, and uninstalls cleanly from Discover's Installed page.

Five things you will actually do

  1. Create a bottle

    Press +, name it after the program, and choose Application or Gaming. Gaming bottles arrive with DXVK and the performance pieces already switched on.

  2. Install a program into it

    Open the bottle, Run Executable, and pick the installer. The program installs inside that bottle only and cannot see the others.

  3. Add dependencies

    The bottle's Dependencies tab lists the usual runtimes — Visual C++, .NET, fonts, codecs — and installs them with one click. This replaces most of what winetricks does by hand.

  4. Make a launcher entry

    Once installed, the program appears in the bottle's programs list; its menu offers to add a desktop entry so it shows up in the Dagric launcher like any other application.

  5. Throw it away and start again

    Delete the bottle. Everything that program did — registry, DLLs, config, the lot — goes with it, and nothing else is affected. That disposability is the whole argument for using Bottles rather than raw Wine.

One thing that will surprise you

“It works” is not one answer, it is four. A Windows program under Bottles can run perfectly, run with cosmetic glitches, run but fail at one specific feature (printing and scanning are common), or not start at all. Try the actual thing you need it to do — not just the splash screen — before you decide you have migrated successfully.

Where to find it

After installing: launcher → Bottles. Before installing: Dagric Hub → Windows apps — Bottles, or Discover.
