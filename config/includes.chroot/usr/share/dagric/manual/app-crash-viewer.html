Crashed Processes Viewer

See which program stopped, when it happened, and the useful technical details.

On Windows this wasReliability Monitor and crash reports

What it is

This viewer lists application crashes recorded by the system. A crash entry is evidence, not proof that the whole computer is broken. One old entry can be ignored; repeated recent entries for the same program are worth investigating.

Five things you will actually do

  1. Find the latest crash

    Sort by date and select the newest entry. Check the program name before reading the details.

  2. Tell a crash from a freeze

    A listed process ended unexpectedly. If the app is still open but not responding, use System Monitor instead.

  3. Copy useful details

    Copy the application name, time, signal and package version. Do not paste a full dump into a public post because it may contain paths or document names.

  4. Check whether it repeats

    Look for several entries with the same executable. Repetition after the same action makes a useful bug report.

  5. Prepare a private support report

    Use Dagric Support Mode to preview a privacy-safe summary, then attach only what you have reviewed.

If an app keeps crashing

Install updates, restart the app, and try once with extensions or third-party plug-ins disabled. Save work before reproducing the problem.

Where to find it

Launcher → Crashed Processes Viewer. It may also open automatically after a KDE application fails.
