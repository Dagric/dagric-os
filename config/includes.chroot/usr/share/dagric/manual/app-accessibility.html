System and safety

Accessibility settings

Make the keyboard, the mouse and the screen work the way your hands and eyes do.

On Windows this wasEase of Access / Accessibility settings

What it is

The launcher entry called Accessibility — described in the menu as “make the computer easier to use” — opens one page of System Settings. It is the page for people who find a standard keyboard or mouse hard to use: keys that repeat when you did not mean them to, modifier combinations that need two hands at once, a pointer that is hard to follow.

It is not the same thing as Orca, which reads the screen aloud for blind users, and it is not where you make text bigger — that is Dagric Display. Those three cover three different needs and it is worth knowing which one you want.

Every setting on this page is off when Dagric is installed. Nothing here changes until you turn it on.

Two things people look for here are somewhere else. The screen magnifier is part of the window manager rather than this page: press Meta++ to zoom in, Meta+- to zoom back out and Meta+0 for actual size, with no setting to turn on first. And high contrast is a Dagric colour style, not a switch: open Dagric Styles, or the Hub's Colors and mood row, and pick the high-contrast one.

Five things you will actually do

  1. Press shortcuts one key at a time

    Modifier Keys → Sticky keys. Ctrl+Alt+Delete becomes Ctrl, then Alt, then Delete — each pressed and released on its own. For anyone typing with one hand, a mouth stick or a head pointer, this is the setting that makes the rest of the desktop usable. Lock sticky keys holds a modifier down until you press it again, and there is an option to switch the whole thing off automatically the moment you do hold two keys together, so a two-handed user sharing the machine is not fighting it.

  2. Stop a shaky hand typing double letters

    Keyboard Filters → Bounce keys ignores a second press of the same key that arrives too soon. The delay starts at 200 ms. If your problem is the opposite — keys firing when a finger brushes them on the way past — Slow keys makes a key count only once it has been held down, starting at 500 ms. Both can beep when a key is accepted or rejected, which is how you learn what the delay is doing.

  3. Move the pointer without a mouse

    Mouse Navigation drives the pointer from the number pad. Useful when a mouse is temporarily impossible — a broken wrist, a dead trackpad on a laptop far from a shop — and not only as a permanent arrangement.

  4. See the beep instead of hearing it

    System Bell → Visual bell flashes the screen or inverts its colours for 500 ms instead of making a sound. This is for deaf and hard-of-hearing owners, and for anyone working somewhere they cannot have the machine making noises.

  5. Correct for colour blindness

    Color Blindness Correction shifts the colours the screen produces to separate the ones you cannot tell apart, with settings for the three common forms. Shake Cursor, further down, briefly grows the pointer when you shake it — the fastest fix there is for losing the mouse on a big or a bright screen.

One thing that will surprise you

Pressing Shift five times does nothing here, and on Windows it famously did. That dialog interrupting a game at the worst moment is a quarter-century-old complaint, and the shortcuts that cause it — Shift five times for sticky keys, Shift held for eight seconds for slow keys — are turned off by default on Dagric. They are in Activation Shortcuts if you want them, and they are genuinely worth having if you need these features but cannot always reach the settings app to turn them on.

If you do enable them, note what is already ticked underneath: the system bell rings when a shortcut fires, so the machine tells you it has changed something. There is also an option to switch sticky and slow keys back off after a set time — thirty minutes by default — which is the safety net for a shared or a public computer.

Where to find it

Launcher → Accessibility, or System Settings → Accessibility. The eight sections are System Bell, Modifier Keys, Keyboard Filters, Mouse Navigation, Activation Shortcuts, Screen Reader, Color Blindness Correction and Shake Cursor.

Changes need Apply. Defaults puts the whole page back to how Dagric shipped it, which is everything off — useful if a setting has made the keyboard behave in a way you cannot undo by feel.
