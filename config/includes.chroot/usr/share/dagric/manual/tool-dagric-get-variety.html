Rotating wallpapers (Variety)ADD-ON

Install the wallpaper changer — and find out why it is not preinstalled.

On Windows this wasWindows Spotlight and the wallpaper slideshow

What it is

Variety changes your wallpaper on a schedule, from your own folders and, if you switch it on, from online collections. It adds a tray icon for skipping, pausing and favouriting the current image.

It is not preinstalled, deliberately. Out of the box Variety can fetch wallpapers from third-party services, and an operating system that promises to be private by default should not start talking to anyone's servers without being asked. So it is offered rather than assumed.

Getting it

Dagric Hub → Rotating wallpapers, launcher → Rotating Wallpapers, or dagric-get-variety. A terminal window explains the trade-off, asks yes or no, and installs Variety from Debian's own archive (about 25 MB) after asking for your administrator password.

This one ships on every edition of Dagric, free included.

Five things you will actually do

  1. Decide whether you need it at all

    If you only want a slideshow of your own pictures, you do not. Right-click the desktop → Configure Desktop and Wallpaper → Slideshow, point it at a folder, done — nothing to install and nothing that talks to the internet.

  2. Install it

    Run the helper and answer yes. It launches into the system tray; right-click that icon for everything.

  3. Use your own pictures

    In Variety's preferences, remove the online sources and add your own folders. It then behaves like a much more capable version of Plasma's slideshow, with favourites and a “never show this one again” option.

  4. Turn on an online source, knowingly

    The sources list is where the internet comes in. Enable one and Variety will download images from it. That is a reasonable thing to want; it is just a decision Dagric will not make for you.

  5. Use Dagric's own wallpapers

    Point Variety at /usr/share/wallpapers/. Dagric ships more than twenty designs, each in a branded and a logo-free “Clean” version.

One thing that will surprise you

The reason it is a separate install is written into the tool itself. The helper explains the third-party-download issue before it asks you anything, and offers you the built-in alternative that needs no install. That pattern — tell the owner the trade-off, then let them choose — is how every consent helper on this machine works.

Where to find it

After installing: the tray icon, or launcher → Variety. Before installing: Dagric Hub → Rotating wallpapers.
