Writing and documents

Printers and scanners

Getting paper into the computer and out of it again, including Print to PDF.

On Windows this wasDevices and Printers, and Windows Fax and Scan

What it is

Printing on Dagric is handled by CUPS, the same printing system macOS uses, configured from System Settings → Printers. Modern network printers are found automatically and need no driver at all; older USB printers are covered by the Gutenprint driver set, which Dagric installs by default.

Scanning is Skanlite: a small window with a Preview button and a Scan button. It talks to USB scanners and to network all-in-ones over the driverless eSCL protocol.

Five things you will actually do

  1. Add a printer

    System Settings → Printers → Add Printer. Wait a moment for the list to populate, pick yours, accept the suggested driver. A printer on the same wifi usually appears without you doing anything.

  2. Print to PDF

    In any application's print dialogue, choose the printer called PDF. The file appears in a folder called PDF inside your home folder. This is a real print queue, so it works from every app including ones with no “export” feature.

  3. Scan a page

    Open Skanlite, press Preview, drag a box around the part of the glass you want, then Scan. It asks where to save. 300 dpi is right for documents; 600 and above is for photographs.

  4. Get an HP all-in-one working fully

    Open Finish Setup from the Dagric Hub and tick HP printer and scanner support. It installs HP's own open-source driver package, which some HP devices need for scanning and ink levels.

  5. Print double-sided or several pages to a sheet

    Both live in the print dialogue, under Page Handling or Properties depending on the app. If two-sided is missing, the printer's page in System Settings has an Installed options section where the duplex unit must be declared.

One thing that will surprise you

The driver hunt is over. There is no manufacturer website to visit, no 400 MB “printer software suite” with a tray icon and a shop in it, and no driver disc. Most printers made in the last decade speak a standard protocol and simply appear. The ones that do not are handled by drivers that were already installed before you plugged anything in.

Where to find it

Printers: System Settings → Printers. Scanning: launcher → Scanner (also Skanlite). Print to PDF: the printer named PDF in any print dialogue.
