Internet and communication

Firefox

The web browser, set up for privacy before you ever open it.

On Windows this wasMicrosoft Edge

What it is

Firefox is the browser Dagric ships. It is the Extended Support Release, which means it takes security fixes continuously but changes its interface only about once a year — the right trade for a machine somebody depends on.

Dagric configures it before you first open it: telemetry off, Firefox Studies off, Pocket removed, sponsored tiles off the home page, enhanced tracking protection on including cryptominers and fingerprinters, and the uBlock Origin ad blocker set up. There is no onboarding tour and no request that you sign in to anything.

Five things you will actually do

  1. Bring your bookmarks over from Windows

    The Migration Assistant collects them from Chrome, Edge and Firefox into ~/Windows-bookmarks.html. In Firefox: Bookmarks → Manage Bookmarks → Import and Backup → Import Bookmarks from HTML.

  2. Reopen the tabs you had open on the old PC

    The same tool can recover them into ~/Windows-open-tabs.html. Import it the same way; the tabs arrive as a bookmark folder, and right-clicking the folder offers Open All in Tabs.

  3. Sign in and sync

    Optional and entirely up to you. A Firefox Account syncs bookmarks, passwords, history and open tabs between this machine and your phone, end-to-end encrypted. Nothing pesters you to create one.

  4. Add or remove an extension

    ☰ menu → Add-ons and themes. uBlock Origin is already there; if you do not want it, remove it like any other add-on. That is a deliberate choice on our part — software you did not ask for should always be removable.

  5. Watch Netflix, Spotify and the rest

    They work. Dagric enables the DRM playback component Firefox needs (Widevine) so streaming services play instead of showing an error. It is the one proprietary component in the browser, it is enabled rather than locked on, and you can switch it off in Firefox's settings.

One thing that will surprise you

The ad blocker arrives on your first connection, not in the ISO. uBlock Origin is set up by policy but Firefox fetches it from Mozilla's add-ons site the first time it runs, so on a machine that has never been online you will briefly see an unfiltered web. Connect once and it appears by itself.

The other thing worth knowing: ESR looks a version or two behind whatever you read about online. That is intentional. Security updates land on the same day as everyone else's.

Where to find it

The Firefox icon in the taskbar, or launcher → Firefox.
