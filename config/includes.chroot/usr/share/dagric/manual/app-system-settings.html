Files and getting around

System Settings

One window for the whole computer: displays, sound, keyboard, printers, accounts.

On Windows this wasSettings and Control Panel

What it is

System Settings is where the machine is configured, and unlike Windows there is only one of it — no split between a modern Settings app and an old Control Panel hiding behind it. Everything is in one window with a search box at the top left.

Use the search box. It is genuinely good: type resolution, bluetooth, night, printer or autostart and it takes you to the right page without you learning the tree.

Five things you will actually do

  1. Set up a second monitor or a projector

    Display & Monitor. Drag the screens into the arrangement that matches your desk, choose which one is primary, and set the refresh rate and scaling. Plugging in usually configures itself; this is where you correct it.

  2. Add a printer

    Printers → Add Printer. Most modern printers on the same network or USB cable are found automatically. See Printers and scanners for the whole story.

  3. Make the text bigger, or warm the screen at night

    Both live on the Display & Monitor page, alongside a great many settings that can blank the picture. If you only want those two things, use Dagric Display instead — it asks the two questions, and puts a size back by itself if you do not confirm it.

  4. Change what happens when you close the laptop lid

    Power Management. Lid-close action, screen-off timers, and separate settings for on-battery and plugged-in. The battery icon in the tray offers the same power profiles — Power Save, Balanced, Performance.

  5. Manage user accounts

    Users. Add a family member, change a password, set a profile picture, or enrol a fingerprint if the laptop has a reader.

One thing that will surprise you

Nothing here reports back. There is no privacy dashboard to wade through, because there is no telemetry to switch off — Dagric does not collect any. There is no advertising ID, no “personalised experiences” toggle, and no account required to change a setting. The handful of things that would talk to the internet, like firmware update checks, are named plainly where they live.

Where to find it

Launcher → System Settings, or right-click the desktop and choose Configure Desktop and Wallpaper to land inside it. Many tray icons have a “Configure…” item that jumps to the right page directly.
