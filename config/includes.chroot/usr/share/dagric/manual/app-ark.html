Files and getting around

Ark

Zip files, and the dozen other archive formats things arrive in.

On Windows this wasthe built-in Zip support, WinRAR and 7-Zip

What it is

Ark handles compressed archives. Mostly you will never open it directly — it works from Dolphin's right-click menu, which is where the Windows habits already point.

It reads and writes ZIP, 7z, tar and the gzip/bzip2/xz family, and it opens RAR files. Dagric installs the full 7-Zip support alongside it, so a .7z someone emails you is a double-click, not an errand.

Five things you will actually do

  1. Unzip something

    Right-click the archive in Dolphin → Extract → Extract archive here, autodetect subfolder. That last option is the one you want: it avoids the classic mess of forty loose files landing in Downloads.

  2. Make a zip to email

    Select the files, right-click → Compress → Here (as ZIP). ZIP is the format to pick when the other end is on Windows or a phone.

  3. Put a password on an archive

    Open Ark, Archive → New, choose ZIP or 7z, and tick Encrypt contents. 7z encrypts the file names too; ZIP does not. For anything genuinely sensitive use Cryptomator instead — archive passwords are convenience, not security.

  4. Look inside without extracting

    Double-click the archive. Ark opens it like a folder; you can preview a single file, or drag just the one you need out onto the desktop.

  5. Deal with a split archive

    Multi-part files ending .z01, .part1.rar or .7z.001: put every part in one folder and open the first one. Ark finds the rest itself.

One thing that will surprise you

Ark can open RAR files but cannot create them. The RAR compression format is proprietary and its owner does not license the compressor for free redistribution, so no open-source OS ships one. Unpacking is fine; if you need to send a compressed file, send a ZIP or a 7z and the other end will manage.

Where to find it

Right-click any archive in Dolphin. To open it as an app, launcher → Archive Manager (also found by typing Ark, zip or 7-zip).
