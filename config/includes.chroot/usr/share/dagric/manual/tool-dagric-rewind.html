Dagric Rewind

Your computer has an Undo button — without recording your screen.

On Windows this wasrestore points, Recall, and a separate Sandbox

What it is

Dagric Rewind puts real system checkpoints on a timeline you can understand. Start a session before installing software, changing a setting, updating a driver, or trying an experiment. Finish it afterwards and Rewind shows which system paths were added, changed, or removed.

It records system changes only. It does not take screenshots, read your documents, capture typing, contact a cloud service, or require an account.

Package installs and updates that use APT or Discover already create a before-and-after pair in Dagric. Rewind recognizes those exact pairs and lists them as Software update (automatic), so you get a receipt even when you did not remember to start a session first.

Four things you will actually do

  1. Start before a risky change

    Open Rewind and choose the kind of change. Approve the administrator prompt. The first checkpoint is created before you touch anything.

  2. Finish and read the receipt

    Return to Rewind and press Finish & review. Click the finished session in the timeline to see Software, Settings, Boot, and other changed paths.

  3. Mark a known-good moment

    Use Create checkpoint before travel, a deadline, or a large upgrade. It joins Dagric's normal snapshot retention system.

  4. Recover safely

    Press Open safe recovery for Btrfs Assistant. If the machine cannot boot normally, use Dagric's snapshot submenu at startup. Rewind deliberately does not rewrite the running root filesystem behind your back.

What it does not protect

A root snapshot is not a backup of a failed drive, and the default Dagric layout keeps personal files separate from system snapshots. Keep a real backup of documents and photos. Rewind protects the operating system from a bad change; it does not claim to replace backup.

On the live USB, or on an installation that is not using Btrfs, Rewind explains why it is unavailable instead of showing a false Undo button.

Where to find it

Dagric Hub → Dagric Rewind, launcher → Dagric Rewind, or dagric-rewind.
