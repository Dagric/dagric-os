Files and getting around

KWallet

The keyring that remembers your Wi-Fi keys and app passwords so you do not have to.

On Windows this wasWindows Credential Manager

What it is

KWallet is the desktop's password store. When you tick “remember this” for a Wi-Fi network, a network share or an app login, that secret goes into an encrypted wallet rather than a plain file. Windows has exactly the same thing in Credential Manager, equally invisibly.

By default the wallet is unlocked by your login password, so you never see it. KWallet Manager is the app that lets you look inside, change the password, or delete a saved credential that has gone stale.

Five things you will actually do

  1. Forget a saved Wi-Fi password

    Usually easier from the network applet: click the Wi-Fi icon, right-click the network, Delete Connection. KWallet Manager is the place to go when a stale credential survives that.

  2. See what is stored

    Open KWallet Manager, unlock the wallet, and browse the folders. Each entry shows which application saved it.

  3. Change the wallet password

    Settings → Change Password. Beware: if you set a password different from your login password, you will be prompted for it every session. That is the trade-off for a wallet that stays locked even when you are logged in.

  4. Stop an app nagging for wallet access

    System Settings → KDE Wallet lists which applications may open it. Revoke one there and it will ask again next time.

  5. Keep your real passwords somewhere better

    KWallet is for what the desktop needs to remember. For your own logins — bank, email, everything — use a proper password manager: Firefox's built-in one, or KeePassXC on Pro.

One thing that will surprise you

If you change your login password, the wallet keeps the old one. The two are linked at setup but not afterwards, so a password change can leave you with a prompt for a password you have half-forgotten. Fix it in KWallet Manager under Change Password, and do it while the old one is still fresh.

Where to find it

Launcher → Saved Passwords (also KWallet). Settings for it live in System Settings → KDE Wallet.
