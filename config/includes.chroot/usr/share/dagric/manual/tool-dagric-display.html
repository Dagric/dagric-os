Dagric Display

Make the text bigger and warm the screen up at night. Nothing else, on purpose.

On Windows this wasDisplay settings: Scale and layout, and Night light

What it is

Dagric Display asks two plain questions — how big should the text be, and should the screen go warmer in the evening — and offers a third row that opens the full System Settings display page for everything else.

That page is a good one and a frightening one: resolution, refresh rate, mirroring, variable refresh, HDR, rotation and a scale slider, every one of them able to blank the picture. Somebody who left Windows because it stopped getting updates wants bigger text, and should not have to walk past six ways to lose the display to get it.

Five things you will actually do

  1. Make everything bigger

    Pick Text and icon size and choose a size. The sizes are described in words — “Bigger — what Windows usually picks for a laptop” — with the percentage beside them for anyone who thinks in percentages.

  2. Change your mind, safely

    A new size is a trial. The old one comes back by itself after twenty seconds unless you press Keep. This matters more than it sounds: a text size that is too big can push the button that fixes it off the bottom of the screen, and the setting survives a reboot — so turning the machine off and on again is not a way out. The countdown is the way out.

  3. Warm the screen up at night

    Pick Night colour. It offers off, on from eight in the evening until seven in the morning, or on all the time. Windows calls this Night light and people go looking for it by that name, so it is here under a name they will find.

  4. Choose which screen

    With more than one display connected it asks which one first, naming them in a way you can recognise rather than by connector code.

  5. Get to the full settings

    The last row opens System Settings → Display & Monitor for resolution, arrangement, refresh rate and the rest. The simple tool is a front door, not a wall.

One thing that will surprise you

Sizes your screen cannot carry are not offered at all. A 1366×768 laptop is never shown 150%, because at that scale the desktop would have fewer usable pixels than many dialogue boxes need — including the one you would use to undo it. Rather than let you choose it and then discover the problem, the option is simply not there.

Where to find it

Launcher → Text Size, Dagric Hub → Text size and night light, or dagric-display. The full page is System Settings → Display & Monitor.
