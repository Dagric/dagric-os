System and safety

FlatsealPRO

Decide what each sandboxed app is allowed to touch.

On Windows this wasApp permissions in Windows Settings
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Apps installed from Flathub run in a sandbox: they can only reach the files, devices and services their manifest asks for. Flatseal is the window that shows you those requests and lets you change them.

It only governs Flatpak apps. Software installed as Debian packages — most of what Dagric ships — is confined by AppArmor instead, which is not adjustable from a window.

Five things you will actually do

  1. See what an app can reach

    Pick it from the list on the left. The panel shows filesystem access, network, devices, and which system services it may talk to. Anything highlighted has been changed from the app's own defaults.

  2. Stop an app seeing your whole home folder

    Turn off All user files and add only the folders it actually needs under Other files. A media player needs Music; it does not need your tax returns.

  3. Take the camera or microphone away

    Toggle the device permissions off. If the app then genuinely needs them, it will ask through the desktop's portal instead — which is better, because you get to say yes each time.

  4. Cut an app off from the network

    Turn Network off for anything that has no business online: an image editor, a PDF reader, a game you play alone.

  5. Undo

    The reset button at the top of each app's page puts every permission back to what the app shipped with. Nothing here is irreversible.

One thing that will surprise you

Many Flatpak apps ask for far more than they need, and the sandbox is only as tight as the manifest. Plenty of them request access to your entire home folder simply because it was easier than declaring specifics. Flatseal is where you find that out, and it is a genuinely illuminating half hour. Tighten one app at a time and test it; if something breaks, the reset button is right there.

Where to find it

Launcher → Flatseal.
