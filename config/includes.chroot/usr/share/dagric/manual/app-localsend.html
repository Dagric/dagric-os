Internet and communication

LocalSendADD-ON

AirDrop between whatever devices you happen to own, with no account.

On Windows this wasNearby Sharing, AirDrop, and emailing yourself a file

What it is

LocalSend sends files and short messages directly between devices on the same network. No account, no cloud, no internet connection required, and nothing is stored anywhere in between. It is what AirDrop is, except it works across Android, iOS, Windows, macOS and Linux at once.

Getting it

Two ways in, and they end up at the same app:

  • Dagric OS Pro — open the Dagric Hub and pick the row for it. A terminal window explains what the app is and asks one yes/no question.
  • Any edition — open Discover, search for it, press Install. It comes from Flathub, so turn Flathub on first if you have not: Finish Setup has a tick box for it.

Either route installs it just for your user account, needs no administrator password, and uninstalls cleanly from Discover's Installed page.

Install the LocalSend app on the other device too — it exists for Android, iOS, Windows and macOS — and the two find each other on their own.

Five things you will actually do

  1. Send a file to your phone

    Open LocalSend on both. The phone appears in the list; select the file, pick the device, the phone asks whether to accept. That is the whole process.

  2. Receive a file

    Leave LocalSend open on the receiving machine. Incoming transfers ask for confirmation and land in the folder set in its settings — Downloads by default.

  3. Move a large video without the cloud

    Transfers run at local network speed, so a 4 GB file takes seconds on wired Ethernet or a minute on decent Wi-Fi. No upload, no download, no size limit imposed by anybody.

  4. Send text rather than a file

    The message option sends a snippet of text or a link straight to the other device's clipboard. Faster than emailing yourself a URL.

  5. Accept transfers automatically

    Settings has a quick-save option for devices you trust. Leave it off on a laptop you take to public places.

One thing that will surprise you

Both devices must be on the same network, and some networks forbid it. Hotel, campus and many corporate Wi-Fi networks use client isolation, which stops devices seeing each other on purpose. LocalSend will show an empty list and nothing is wrong with it. A phone hotspot that both devices join is the usual workaround.

Where to find it

After installing: launcher → LocalSend. Before installing: Dagric Hub → Local sharing — LocalSend, or Discover.
