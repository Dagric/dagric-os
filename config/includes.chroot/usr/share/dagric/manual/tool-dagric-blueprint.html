Dagric Blueprint

Preview the safe application and setting list that can rebuild this computer.

On Windows this wasa documented reinstall checklist

What it is

A blueprint records reproducible system choices: applications and settings that can be applied again after a reinstall. It does not copy personal documents, photos or passwords. Use a backup for those.

Five things you will actually do

  1. Preview the blueprint

    Open Dagric Blueprint. Its default action is read-only and shows what a rebuild would include.

  2. Separate settings from files

    Confirm that the list contains applications and safe preferences, not your personal data. Back up personal data separately.

  3. Check unfamiliar entries

    Look up an application in this manual before keeping it in a future rebuild plan.

  4. Save a reference copy

    Export or copy the preview to your backup drive so it remains available if this installation is lost.

  5. Review after major changes

    Preview again after installing or removing important tools, and keep the newest reviewed copy.

What it does not replace

Blueprint is not a disk image, snapshot or cloud sync service. For deleted files use a backup; for a recent system problem use Dagric Rewind.

Where to find it

Launcher → Dagric Blueprint. The preview opens in a terminal so the complete list stays readable.
