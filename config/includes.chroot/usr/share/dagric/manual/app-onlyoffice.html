Writing and documents

ONLYOFFICEPROADD-ON

An office suite that looks like Microsoft Office, for when LibreOffice feels foreign.

On Windows this wasMicrosoft Office — the ribbon and all

What it is

ONLYOFFICE Desktop Editors is a full, open-source office suite whose interface is a deliberate copy of Microsoft Office: the same ribbon across the top, the same tab names, the same places for the same buttons. If the thing stopping you from leaving Windows is that LibreOffice's menus feel wrong, this is the answer.

It also has the best .docx, .xlsx and .pptx fidelity in open source, because those formats are its native ones rather than an import filter.

Getting it

ONLYOFFICE is not preinstalled. Open the Dagric Hub and pick Office suite — ONLYOFFICE, or search Familiar Office Look in the launcher. A terminal window opens, explains what the app is, and asks a plain yes/no question. Answer anything other than yes and nothing at all happens.

It installs from Flathub, just for your user account, so it never asks for an administrator password and it uninstalls cleanly from Discover's Installed page. Nothing else on the machine is touched.

LibreOffice stays exactly where it is. You can keep both and decide later, or keep both forever — they do not conflict.

Five things you will actually do

  1. Open a Word, Excel or PowerPoint file

    Double-click it, or open ONLYOFFICE and use its start page. Documents open in their original format and save back to it — no conversion dialogue, no “keep current format?” question.

  2. Make it the default for Office files

    Right-click a .docx in Dolphin → Properties → the File type options button, and move ONLYOFFICE to the top of the application list. Do the same for .xlsx and .pptx.

  3. Find a feature you knew in Office

    Look on the ribbon tab with the same name. Review, References, Mailings and Insert are all where Office puts them, which is the entire point of installing it.

  4. Work on the three document types in one window

    ONLYOFFICE opens documents, spreadsheets and presentations as tabs in a single window rather than three separate applications.

  5. Remove it if you decide against it

    Discover → Installed → ONLYOFFICE → Remove. Your documents are untouched; only the editor goes.

One thing that will surprise you

It looks so much like Office that you may forget which one you are in. That is the intended effect, but it means the differences are the things that catch you: there is no OneDrive integration, no Microsoft account, and the collaboration features expect an ONLYOFFICE server you do not have. It is a local editor with a familiar face, which for most people is precisely what was wanted.

Where to find it

After installing: launcher → ONLYOFFICE Desktop Editors. Before installing: Dagric Hub → Office suite — ONLYOFFICE.
