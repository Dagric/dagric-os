ISO Image Writer

Turn a downloaded operating-system image into a bootable USB drive.

On Windows this wasRufus or balenaEtcher

What it is

ISO Image Writer copies a disk image to a USB drive exactly. It does not copy the image as an ordinary file. The destination drive is overwritten, including its current files and partition layout.

Five things you will actually do

  1. Download the image

    Get the image from the operating system's official website. Keep its checksum or signature when one is provided.

  2. Select the image

    Open ISO Image Writer and choose the downloaded .iso or supported image file.

  3. Identify the USB drive

    Match its size and model. Unplug other removable drives if the list is ambiguous.

  4. Write and wait

    Start the write, approve the password prompt, and leave the drive connected until verification finishes.

  5. Eject safely

    Use the eject control in Dolphin before unplugging. To start from it, restart and choose the USB drive in the computer's boot menu.

Important

The selected destination is erased. A USB drive may appear smaller or unreadable in another system afterward; Partition Manager can restore it for ordinary storage later.

Where to find it

Launcher → ISO Image Writer. You can also right-click a compatible image in Dolphin and choose the writer.
