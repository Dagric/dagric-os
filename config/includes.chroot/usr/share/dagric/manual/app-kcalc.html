KCalc

A calculator that goes from shopping arithmetic to hexadecimal.

On Windows this wasCalculator

What it is

KCalc is the calculator. It opens in a simple mode and grows into a scientific, statistical or programmer's calculator from the Settings menu, the same way the Windows calculator has modes.

For a quick sum you often do not need it at all: press Alt+Space and type the arithmetic straight into the search box.

Five things you will actually do

  1. Work out a percentage

    Type the number, press the % key, and the operators behave as they do on a desk calculator: 80 − 15 % gives you 68.

  2. Switch to scientific mode

    Settings → Science Mode for trigonometry, logs and exponentials. Numeral System Mode gives hex, octal, binary and bitwise operators.

  3. Use the memory keys

    MS stores, MR recalls, M+ adds to what is stored. The stored value survives while the window is open.

  4. Copy the answer out

    Ctrl+C copies the display. It pastes as a plain number, which is what a spreadsheet wants.

  5. Use constants

    In science mode, the Constants menu inserts physical and mathematical constants — the speed of light, Avogadro's number, and so on — at full precision.

One thing that will surprise you

The keyboard is faster than the buttons. Every key on the calculator has a keyboard equivalent, including Enter for equals and Backspace for a correction, so you can drive the whole thing from a numeric keypad without touching the mouse. Dagric turns Num Lock on at login for exactly this reason.

Where to find it

Launcher → Calculator (also KCalc). Or Alt+Space and type the sum.
