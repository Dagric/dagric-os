GE-Proton helper

Add an optional community Proton build and test it one title at a time.

On Windows this wasnothing — a Linux gaming convenience

What it is

GE-Proton is a community compatibility tool maintained by GloriousEggroll. This helper downloads its current release from the project's GitHub repository, verifies the published SHA-256 digest, and installs it into Steam's compatibility tools folder.

It also reminds you what Dagric OS Pro already installed for gaming: Wine and winetricks, GameMode and MangoHud, and the 32-bit Vulkan libraries Proton needs. Steam itself is never bundled — see Steam.

GE-Proton and Dagric are independent of Valve. A compatibility layer cannot guarantee that a game, anti-cheat system or online service will work, and each game and service remains governed by its publisher's current license and terms.

Running it

Dagric Hub → GE-Proton for Steam, launcher → Gaming Setup, or dagric-gaming. It opens a terminal, summarises what is already installed, and asks whether to download the latest GE-Proton from GitHub. Answer anything but yes and nothing happens.

It needs no administrator password — everything it installs goes into your own Steam folder.

Five things you will actually do

  1. Launch Steam once first

    The helper installs into Steam's own data folder, so that folder has to exist. If Steam has never been run it says so plainly and stops rather than creating directories Steam might later disagree with.

  2. Run the helper

    Answer yes. It asks GitHub for the newest release, downloads it and unpacks it. On a slow connection this takes a few minutes; the download URL is printed so you can see exactly what is being fetched.

  3. Enable it in Steam

    Steam → Settings → Compatibility, then per game under Properties → Compatibility choose a GE-Proton version, then test that title's actual features.

  4. Use the graphical alternative instead

    ProtonUp-Qt does the same job with a window, manages several versions at once, handles Lutris and Heroic as well, and can remove old builds. If you expect to do this more than once, install that.

  5. Undo it

    Delete the version's folder from ~/.local/share/Steam/compatibilitytools.d/. Nothing outside your home folder was touched.

One thing that will surprise you

It downloads from the internet, and it says so before it does. This is one of the few Dagric helpers that fetches something from outside Debian's archive or Flathub. It intentionally uses the project's release on GitHub and prints the exact URL it is about to use. If the machine is offline it reports that it could not find the release and changes nothing.

Where to find it

Dagric Hub → GE-Proton for Steam, or dagric-gaming.
