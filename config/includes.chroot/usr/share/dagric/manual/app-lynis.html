System and safety

Lynis

A detailed local security audit for administrators who want the evidence behind the summary.

On Windows this wasa combination of security baselines and system-audit tools

What it is

Lynis inspects local settings and reports warnings and suggestions. It does not automatically prove a machine is secure, and a suggestion is not automatically appropriate for a desktop. Dagric Security Checkup is the simpler first stop.

Five things you will actually do

  1. Run the friendly check first

    Open Dagric Security Checkup for an explanation written for this system. Use Lynis when you need the full audit.

  2. Start a local audit

    In Konsole run sudo lynis audit system, enter your password, and let it finish without closing the terminal.

  3. Read warnings in context

    Start with the warning and suggestion sections. Some recommendations are intended for locked-down servers, not everyday desktop computers.

  4. Save a support result

    Record the test identifier and short finding. Review logs for usernames, paths or network details before sharing.

  5. Verify after a change

    Change one setting at a time, rerun the relevant test, and confirm the feature you rely on still works.

Do not chase the score

A higher hardening score can come from disabling useful services without reducing your actual risk. Prioritise updates, backups, unique passwords, the firewall and fixes tied to a threat you really face.

Where to find it

Lynis is an advanced command-line tool. Search the launcher for Security Checkup, or run sudo lynis audit system in Konsole.
