KritaPRO

Digital painting and illustration, built by and for artists.

On Windows this wasPhotoshop for painting, Corel Painter, Clip Studio Paint
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Krita is a painting program, not a photo editor. Its strength is brushes: hundreds of them, with genuine pressure, tilt and speed response from a graphics tablet, plus brush stabilisers for steady inking, and a frame-by-frame animation timeline.

If you draw, this is the application on this machine you will spend the most time in. If you retouch photographs, use GIMP instead — they overlap far less than they look like they should.

Five things you will actually do

  1. Set up a graphics tablet

    Plug it in; most Wacom, Huion and XP-Pen tablets work with no driver at all. In Krita, Settings → Configure Krita → Tablet Settings to check pressure is registering, and System Settings → Tablet to map it to the right monitor.

  2. Pick a brush

    The brush presets docker (or press the brush-preset shortcut on the toolbar) groups them by behaviour: pencils, inks, wet paint, airbrush, texture. Start with the Basic set and build a favourites list with the tag system.

  3. Ink cleanly

    In the Tool Options for the brush, turn on Stabilizer and raise the distance. It smooths a shaky hand into a confident line, which is the single biggest quality jump for a beginner.

  4. Use layers and masks

    The Layers docker on the right. Krita has paint layers, vector layers, group layers, filter layers and transparency masks. Sketch on one layer, ink on another above it, colour on one below.

  5. Animate

    Settings → Dockers → Animation and Timeline. Add frames on the timeline, turn on onion skinning to see the frames either side, and export to a video or an image sequence when you are done.

One thing that will surprise you

It opens Photoshop files, including the layers. Krita reads and writes .psd, so a file from a collaborator or an old Windows machine comes across intact rather than as a flattened image. Its own .kra format is better for your own work — it keeps everything Krita can do, which PSD cannot always represent.

Where to find it

Launcher → Krita.
