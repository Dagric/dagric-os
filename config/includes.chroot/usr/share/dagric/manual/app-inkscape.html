InkscapePRO

Vector drawing: logos, signs, cut files, diagrams that scale forever.

On Windows this wasAdobe Illustrator and CorelDRAW
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Inkscape draws with shapes and paths rather than pixels, so the result stays sharp at any size — a business card or a billboard from the same file. It works natively in SVG, the web's own vector format, and exports PDF, EPS, PNG and the DXF that laser cutters and vinyl cutters want.

Five things you will actually do

  1. Draw a shape and reshape it

    Rectangle, ellipse and star tools from the left toolbar. Press N for the Node tool and you can drag the individual points and curve handles of any shape — that is the whole idea of vector drawing.

  2. Turn text into a logo

    Type with the Text tool, then Path → Object to Path. The letters become editable shapes, so the file no longer depends on the recipient having your font.

  3. Trace a scanned sketch or a photo

    Import the image, select it, then Path → Trace Bitmap. The preview updates as you move the threshold slider. It turns a pencil drawing or a low-resolution logo into clean, resizable curves.

  4. Combine and subtract shapes

    Select two shapes and use the Path menu: Union, Difference, Intersection, Exclusion. Almost every icon you have ever seen was made by cutting one simple shape out of another.

  5. Export exactly what you need

    Ctrl+Shift+E opens the export panel: the whole page, the drawing, a selection, or every object as a separate file, at whatever pixel size you specify.

One thing that will surprise you

It opens PDFs, and it is a very capable PDF editor by accident. Import a PDF page and every line of text and every graphic arrives as an editable object. For heavy page work LibreOffice Draw keeps the layout more faithfully, but for altering a logo or extracting one diagram from a report, Inkscape is the better tool.

Where to find it

Launcher → Inkscape, or search Illustrator or vector.
