This manual

How the manual works, how to search it, and how to reach a page from the terminal.

On Windows this wasGet Help, and searching the web for an answer

What it is

What you are reading. dagric-manual opens it in your browser, from files stored in /usr/share/dagric/manual/ on this computer. There is no internet connection involved and no page is ever fetched from anywhere — which matters, because the most likely moment to need a manual is before the wifi is working.

It is separate from the Welcome guide (Dagric Hub → Welcome guide), which is a short read for your first week. This is the reference: one page per application, and one page per Dagric tool.

Five things you will actually do

  1. Search it

    The box at the top of the front page filters as you type, and it searches the Windows names too — type Notepad and you get Kate, type Task Manager and you get System Monitor. Press / anywhere on that page to jump into the box, and Esc to clear it.

  2. Jump straight to a page from a terminal

    dagric-manual dolphin opens the Dolphin page; dagric-manual migrate opens the Migration Assistant. Partial names work.

  3. List every page

    dagric-manual --list prints every topic name, which is also the fastest way to find out whether something is covered.

  4. Hide what you do not have

    On the front page there is a tick box: Hide the things only Dagric OS Pro has. Tick it and the Pro-only entries disappear from every list.

  5. Bookmark it

    It is an ordinary web page. Bookmark the front page in Firefox, or drag a page's address onto the desktop. The address begins file:///usr/share/dagric/manual/.

One thing that will surprise you

The manual ships complete on both editions, Pro pages included. That is a deliberate choice. Hiding the Pro pages on the free edition would leave you believing Dagric cannot edit video or run virtual machines, which is false; leaving them unmarked would send you hunting through the launcher for software that is not installed, which is worse. So every page is here, Pro pages carry a PRO badge everywhere they appear, and on the free edition each one opens with a plain note saying it is not installed on this computer.

The edition is passed to the manual by the dagric-manual command, which reads it from the system. If you open the pages directly from the file manager instead, the manual does not know which edition you are on and says nothing either way — guessing wrong would be worse than staying quiet.

Where to find it

Launcher → Dagric Manual, Dagric Hub → App manual, or dagric-manual. The files live in /usr/share/dagric/manual/.
