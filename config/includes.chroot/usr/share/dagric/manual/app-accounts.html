System and safety

Accounts, passwords and disk encryption

Who can use this computer, and what happens if it is stolen.

On Windows this wasUser Accounts, Windows Hello and BitLocker

What it is

The account you made when installing Dagric is an administrator: it can change the system, but only after typing its password. There is no separate “run as administrator” account, and nothing runs with full privileges by accident.

Full-disk encryption is offered by the installer. If you took it, the disk is unreadable without your passphrase and a stolen laptop is a lost piece of hardware rather than a lost life. If you did not, it cannot be added afterwards without reinstalling — which is worth knowing now rather than later.

Five things you will actually do

  1. Add another user

    System Settings → Users → Add New User. Leave the administrator box unticked for a child or a guest; they get their own home folder that other users cannot read.

  2. Change your password

    Same page. If you use KWallet, change its password to match at the same time or you will get a prompt you do not expect.

  3. Set up fingerprint login

    System Settings → Users → Configure Fingerprint Authentication, if the laptop has a reader. Dagric enables the fingerprint module system-wide, so an enrolled finger works at the login screen, the lock screen and for administrator prompts. Your password continues to work as well.

  4. Lock the screen

    Meta+L. Set the automatic timeout in System Settings → Screen Locking. On a laptop that leaves the house, lock on lid-close.

  5. Check whether your disk is encrypted

    lsblk -f in a terminal: an encrypted install shows a crypto_LUKS layer. If you see one, you are covered. If not, and the machine travels, plan a reinstall or at least keep the sensitive material inside a Cryptomator vault.

One thing that will surprise you

Your password protects the running machine, not the disk. Anyone who can pick the laptop up can boot it from a USB stick and read every file on an unencrypted drive, in about four minutes, without knowing anything about you. This was equally true of Windows without BitLocker; it is simply not something most people are ever told. Encryption is the only setting that changes it.

Where to find it

System Settings → Users. Encryption is chosen during installation, in the disk step.
