KeePassXCPRO

A password vault that is a file on your disk, not an account with a company.

On Windows this wasLastPass, 1Password, Dashlane
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

KeePassXC keeps your passwords in an encrypted database file that you own. There is no subscription, no server and no company that can be breached, sold or shut down. The file is yours to back up, sync or keep on a USB stick.

It also stores two-factor codes, generates strong passwords, fills them into Firefox through a browser extension, and can type them into desktop applications.

Five things you will actually do

  1. Create your database

    Database → New. Choose a long passphrase — four or five unrelated words beat a short jumble of symbols — and save the .kdbx file somewhere your backups reach. This one passphrase is the only one you have to remember.

  2. Import the passwords from your old machine

    KeePassXC imports CSV. If you used the Migration Assistant to recover Firefox logins from Windows it produced ~/Windows-passwords.csv; import that, check it landed, then delete the CSV — it is plain text. LastPass, Bitwarden and 1Password all export CSV too.

  3. Fill passwords into Firefox

    Install the KeePassXC-Browser extension from Firefox's add-ons site, then in KeePassXC enable browser integration under Settings. The two connect once and you approve the link.

  4. Use it for two-factor codes

    Right-click an entry → TOTP → Set up TOTP and paste the secret the website gives you. Bear in mind that keeping the password and its second factor in the same vault means the vault is now the single thing protecting the account.

  5. Type a password into an app that has no extension

    Select the entry and press the auto-type shortcut; KeePassXC types the username, a tab and the password into the window that had focus. Works with anything.

One thing that will surprise you

Nothing syncs it for you, and that is the trade. There is no cloud behind KeePassXC, so getting the database onto your phone is your job — Syncthing, a cloud folder, or a copy on a USB stick. In exchange, no breach at a password company can ever involve your passwords, because no password company has them.

Keep a copy of the database file in your backups. If the file is gone and the passphrase is in your head, you have nothing.

Where to find it

Launcher → KeePassXC.
