Virtual Machine ManagerPRO

Run a whole other operating system — including real Windows — in a window.

On Windows this wasHyper-V, VirtualBox, VMware Workstation
This one is part of Dagric OS Pro. You are reading the manual on the free edition, so it is not installed on this computer. The page is here on purpose — you should be able to see exactly what Pro adds before you decide whether you want it.

What it is

Virtual Machine Manager runs other operating systems inside windows on this desktop, using KVM — the hypervisor built into the Linux kernel itself, so performance is close to bare metal.

This is the honest answer for the one Windows program that Wine cannot run: a real Windows, properly licensed, isolated from your files, that you can pause, snapshot and delete. Windows itself is never bundled with Dagric — you download it from Microsoft.

Switching it on

The whole stack is preinstalled on Dagric OS Pro, but it is switched off until you ask, so it costs nothing on a machine that never uses it. Run the VM helper — Dagric Hub → Windows in a VM — and it checks your processor supports virtualisation, adds you to the right groups, and starts the service. Log out and back in once afterwards.

Five things you will actually do

  1. Get a Windows ISO

    Microsoft publishes it at microsoft.com/software-download/windows11. Windows runs unactivated with minor cosmetic limits, or you can use a licence key you already own.

  2. Create the virtual machine

    New VM → Local install media → choose the ISO. Give it at least 4 GB of memory, 2 processors and a 64 GB disk. Tick Customise configuration before install so you can set the firmware.

  3. Satisfy Windows 11's requirements

    In that customisation screen, set the firmware to UEFI (Pro ships the OVMF firmware) and add a TPM device version 2.0 (Pro ships the software TPM). Those two settings are what Windows 11's installer is checking for.

  4. Share a folder with the guest

    Add a Filesystem device pointing at a folder, or simply use the network. Nothing of yours is visible inside the VM unless you put it there deliberately — which is the point of using one.

  5. Snapshot before you experiment

    The VM's Snapshots tab takes an instant copy of the whole machine. Break Windows, restore the snapshot, carry on. This is the freedom a virtual machine buys you.

One thing that will surprise you

If the machine will not start, it is virtualisation in the BIOS. Intel VT-x or AMD-V is switched off by default on a great many consumer machines. The Dagric VM helper checks for this first and tells you plainly rather than letting the failure happen later: reboot, enter the firmware setup (often F2 or Del), find Virtualization, SVM or VT-x, switch it on, save.

Where to find it

Launcher → Virtual Machine Manager, after running the VM helper once.
