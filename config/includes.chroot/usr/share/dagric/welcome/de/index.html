Willkommen bei Dagric OS

Dagric — day-ruler, Herr über den Tag. Ihr Computer, Ihr Tag, Ihre Regeln.

Was auf Deutsch vorliegt. Diese Seite und die Kurzanleitung für die erste Woche gibt es vollständig auf Deutsch. Die Programme selbst und das 95-seitige Handbuch sind auf Englisch — die englischen Namen stehen deshalb fett im Text, genau so, wie sie auf dem Bildschirm stehen.

Diese Übersetzung wurde noch nicht von einer Muttersprachlerin oder einem Muttersprachler gegengelesen. Im Zweifelsfall gilt die englische Fassung; Korrekturen sind willkommen unter dagric.com/support.

Sie kommen von Windows?

Öffnen Sie den Hub und wählen Sie Migrate from Windows — das Programm findet das Windows, das noch auf diesem PC liegt, und kopiert Ihre Dokumente, Bilder, Musik, Videos und Browser-Lesezeichen in Ihren neuen persönlichen Ordner. Windows selbst wird dabei nur gelesen, niemals verändert.

Alles installieren

Im Software Store (das Taschensymbol in der Leiste) finden Sie Tausende freier Programme — Büro, Spiele, Kreatives. Sie entscheiden; hinter Ihrem Rücken wird nichts installiert.

Das Web, aufgeräumt

Firefox kommt mit abgeschalteter Telemetrie, eingeschaltetem Tracking-Schutz, ohne gesponserte Kacheln und ohne Pocket — und mit dem Werbeblocker uBlock Origin, den Firefox beim ersten Start von der Add-on-Seite von Mozilla lädt. Sie wollen ihn nicht? Entfernen Sie ihn wie jedes Add-on: ☰ → Add-ons und Themes.

Ihre Dateien

Files (das Ordnersymbol) ist das, was unter Windows der Explorer war. Windows-Laufwerke, USB-Sticks und Netzwerkfreigaben funktionieren ohne Einrichtung. Programme sind hier danach benannt, was sie tun — die ursprünglichen Namen (Dolphin, Okular, Ark) finden sie bei der Suche trotzdem.

Updates, wie Sie wollen

Sicherheitsupdates werden still im Hintergrund eingespielt. Der Computer startet niemals von selbst neu — Sie starten neu, wenn es Ihnen passt.

Hilfe nötig?

Die mitgelieferte Kurzanleitung behandelt Drucker, WLAN, Programme, Sicherungen und Tastenkürzel — sie funktioniert offline, direkt auf diesem Computer.

Jedes Programm, erklärt

Öffnen Sie das Dagric Manual aus dem Startmenü: eine Seite zu jedem Programm — was es ist, was es unter Windows ersetzt und wie man die fünf Dinge tut, die man wirklich damit tut. Die Suche kennt die alten Namen: Notepad tippen und den Texteditor bekommen. Liegt auf diesem Computer, kein Internet nötig. Nur auf Englisch — 95 Seiten, deren Suche von den englischen Windows-Namen lebt.

Später anders entscheiden

Den Einrichtungsassistenten von Ihrer ersten Anmeldung gibt es weiterhin — Startmenü öffnen und Set Up Dagric tippen, dann gehen Sie Farben, Hintergrundbild, Schriftgröße und Leiste erneut durch. Ist die Schrift zu klein, erledigt Text Size das allein — und stellt sich nach zwanzig Sekunden von selbst zurück, wenn Ihnen das Ergebnis nicht gefällt.

Kommt Ihnen bekannt vor

Leiste, Startmenü, Systembereich — da, wo Sie sie erwarten. Strg+Umschalt+Esc öffnet den Task-Manager, genau wie unter Windows, und Meta (die ⊞-Taste) das Startmenü.

Ihr Schreibtisch

Lieber eine mittige Leiste, eine schlanke Leiste oder eine klassische? Öffnen Sie Dagric Looks aus dem Startmenü (oder dem Hub) und wählen Sie ein Layout mit einem Klick — Pro ergänzt Dock- und Oberleisten-Layouts. Danach setzt Dagric Styles die Stimmung: hell oder dunkel, Akzentfarben, Hintergrundbilder, sogar milchiges Glas. Jedes Look lässt sich mit jedem Style kombinieren. Jederzeit umkehrbar — es ist Ihr Schreibtisch.

Alles an einem Ort

Öffnen Sie den Dagric Hub aus dem Startmenü (Meta drücken, Dagric Hub tippen) — er versammelt die Treibereinrichtung, den Security Checkup, diese Anleitung und die Pro-Kreativwerkzeuge in einem Fenster. Wenn eine NVIDIA-Karte im Rechner steckt, bietet Dagric den Treiber bei der ersten Anmeldung von selbst an.

Sicher von Anfang an

AppArmor, ein gehärteter Kernel und eine Firewall sind aktiv, bevor Sie irgendetwas ändern. Security Checkup aus dem Startmenü zeigt Ihnen jederzeit Ihren Härtungsgrad und den Zustand jedes Laufwerks — Dagric warnt früh, wenn eine Platte auszufallen beginnt. Auf btrfs-Installationen lässt sich ein misslungenes Update aus dem Startmenü des Rechners rückgängig machen; die Schnappschüsse entstehen automatisch.

Das Dagric-Versprechen

  • Keine Telemetrie — es gibt nichts abzuschalten
  • Keine Werbung, nirgendwo im System
  • Kein Konto nötig, niemals
  • Keine vorinstallierte Zugabe — jedes Programm hier wurde bewusst ausgewählt
  • Jede Zeile des Systems ist offen und nachprüfbar
