Welcome to Dagric OS

Dagric — day-ruler. Your computer, your day, your rule.

Coming from Windows?

Open the Hub and pick Migrate from Windows — it finds the Windows still on this PC and copies your Documents, Pictures, Music, Videos and browser bookmarks into your new home. Windows itself is only read, never touched.

Install anything

Open the Software Store (the bag icon in the taskbar) to browse thousands of free apps — office, games, creative tools. You choose; nothing gets installed behind your back.

The web, cleaned up

Firefox arrives with telemetry off, tracking protection on, sponsored tiles and Pocket removed, and the uBlock Origin ad blocker already set up — it downloads from Mozilla's add-on site the first time you open Firefox. Don't want it? Remove it like any add-on: ☰ → Add-ons and themes.

Your files

Files (the folder icon) is what Windows called File Explorer. Windows drives, USB sticks, and network shares all work out of the box. Apps here are labelled by what they do — the original names (Dolphin, Okular, Ark) still find them when you search.

Updates, your way

Security updates install silently in the background. The computer never restarts by itself — you reboot when it suits you.

Need help?

The built-in user guide covers printers, Wi-Fi, apps, backups, and shortcuts — it works offline, right on this computer.

Every app, explained

Open the Dagric Manual from the launcher for a page on every application here: what it is, what it replaces on Windows, and how to do the five things you will actually do with it. Its search knows the old names — type Notepad and you get the text editor. Stored on this computer; no internet needed.

Change your mind later

The setup wizard you saw when you first signed in is still there — press the launcher and type Set Up Dagric to run through the colors, wallpaper, text size and taskbar again. If the text is too small, Text Size fixes that on its own, and puts itself back after twenty seconds if you don't like the result.

Feels familiar

Taskbar, start-style launcher, system tray — where you expect them. Press Ctrl+Shift+Esc for the Task Manager, just like Windows, and Meta (the ⊞ key) to open the launcher.

Shape your desktop

Prefer a centered taskbar, a minimal bar, or a classic taskbar? Open Dagric Looks from the launcher (or the Hub) and pick a layout in one click — Pro adds dock and top-bar layouts. Then open Dagric Styles to set the mood — light or dark, accent colors, wallpapers, even glassy blur. Mix any Look with any Style. Switch back anytime — it's your desktop.

Everything in one place

Open the Dagric Hub from the launcher (press Meta, type Dagric Hub) — it gathers driver setup, the Security Checkup, this guide, and the Pro creator tools into one window. If you have an NVIDIA card, Dagric also offers the driver automatically the first time you log in.

Secure by default

AppArmor confinement, a hardened kernel, and a firewall are on before you change a thing. Run Security Checkup from the launcher any time to see your hardening score and each drive's health — Dagric warns you early if a disk starts failing. On btrfs installs, a bad update can be undone from the boot menu — snapshots are automatic.

The Dagric promise

  • No telemetry — there is nothing to opt out of
  • No advertising, anywhere in the system
  • No account required, ever
  • No preinstalled junk — every app on this machine was chosen deliberately
  • Every line of the system is open and inspectable
