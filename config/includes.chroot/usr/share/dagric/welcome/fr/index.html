Bienvenue sur Dagric OS

Dagric — day-ruler, le maître de votre journée. Votre ordinateur, votre journée, vos règles.

Vous venez de Windows ?

Ouvrez le Dagric Hub et choisissez Migrer depuis Windows — il trouve le Windows encore présent sur ce PC et copie vos documents, images, musique, vidéos et marque-pages de votre navigateur dans votre nouveau dossier personnel. Windows est uniquement lu, jamais modifié.

Vous vous demandez où sont passés le menu Démarrer ou le Gestionnaire des tâches ? Le guide contient un tableau indiquant où tout est passé.

Installez ce que vous voulez

Ouvrez la Logithèque (l'icône en forme de sac dans la barre des tâches) pour parcourir des milliers d'applications libres — bureautique, jeux, outils créatifs. Vous choisissez ; rien ne s'installe dans votre dos.

Le web, selon vos choix

Firefox ESR provient directement de Debian, sans politique de navigateur propre à Dagric ni extension préinstallée. Vous contrôlez la confidentialité, la recherche, la page d'accueil et les modules complémentaires depuis les menus de Firefox.

Vos fichiers

Fichiers (l'icône en forme de dossier) est l'équivalent de l'Explorateur de fichiers de Windows. Les lecteurs Windows, les clés USB et les partages réseau fonctionnent immédiatement, sans configuration. Les programmes portent ici des noms qui indiquent ce qu'ils font — les noms d'origine (Dolphin, Okular, Ark) permettent aussi de les retrouver lors d'une recherche.

Les mises à jour, comme vous voulez

Les mises à jour de sécurité s'installent discrètement en arrière-plan. L'ordinateur ne redémarre jamais de lui-même : vous le redémarrez quand cela vous convient.

Besoin d'aide ?

Le guide utilisateur intégré couvre les imprimantes, le Wi-Fi, les applications, les sauvegardes et les raccourcis — il fonctionne hors ligne, directement sur cet ordinateur. Il contient aussi des solutions aux problèmes qui arrivent vraiment : pas de son, Wi-Fi qui ne se connecte pas, lecteur Windows qui ne s'ouvre pas.

Chaque application, expliquée

Ouvrez le Manuel Dagric depuis le menu Démarrer : une page pour chaque application présente ici vous explique ce qu'elle est, ce qu'elle remplace sous Windows, et comment faire les cinq choses que vous ferez vraiment avec. Sa recherche connaît les anciens noms : tapez Notepad et vous obtenez l'éditeur de texte. Il est stocké sur cet ordinateur ; aucune connexion Internet n'est nécessaire.

Vous pouvez changer d'avis plus tard

L'assistant de configuration que vous avez vu lors de votre première connexion est toujours là : ouvrez le menu Démarrer et tapez Configurer Dagric pour revoir les couleurs, le fond d'écran, la taille du texte et la barre des tâches. Si le texte est trop petit, Taille du texte règle cela tout seul, et se remet automatiquement comme avant après vingt secondes si le résultat ne vous convient pas.

Des repères familiers

Barre des tâches, menu Démarrer, zone de notification : là où vous les attendez. Appuyez sur Ctrl+Maj+Esc pour ouvrir le Gestionnaire des tâches, comme sous Windows, et sur Meta (la touche ⊞) pour ouvrir le menu Démarrer.

Façonnez votre bureau

Vous préférez une barre des tâches centrée, une barre minimale ou une barre classique ? Ouvrez Dagric Looks depuis le menu Démarrer (ou le Dagric Hub) et choisissez une disposition en un clic — la version Pro ajoute des dispositions avec dock et barre supérieure. Ouvrez ensuite Dagric Styles pour définir l'ambiance : clair ou sombre, couleurs d'accentuation, fonds d'écran, et même un effet de verre flou. Associez n'importe quel Look à n'importe quel Style. Vous pouvez revenir en arrière à tout moment : c'est votre bureau.

Tout au même endroit

Ouvrez le Dagric Hub depuis le menu Démarrer (appuyez sur Meta, tapez Dagric Hub) : il regroupe la configuration des pilotes, le Contrôle de sécurité, les guides et le manuel, les outils d'apparence, et les installateurs en un clic pour Steam, Bottles et les autres dans une seule fenêtre. Si votre ordinateur possède une carte NVIDIA, Dagric propose aussi automatiquement le pilote lors de votre première connexion.

Sécurisé par défaut

La protection AppArmor, un noyau renforcé et un pare-feu sont actifs avant même que vous ne changiez quoi que ce soit. Lancez le Contrôle de sécurité depuis le menu Démarrer à tout moment pour voir votre niveau de durcissement et l'état de chaque disque — Dagric vous avertit tôt si un disque commence à défaillir. Sur les installations btrfs, une mise à jour défectueuse peut être annulée depuis le menu de démarrage — les instantanés sont automatiques.

  • Aucune publicité, nulle part dans le système
  • Aucun compte requis, jamais
  • Aucun programme préinstallé superflu : chaque application de cette machine a été choisie délibérément
