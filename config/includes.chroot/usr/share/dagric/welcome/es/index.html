Bienvenido a Dagric OS

Dagric — day-ruler, el que gobierna tu día. Tu ordenador, tu día, tus reglas.

¿Vienes de Windows?

Abre el Hub y elige Migrar desde Windows — encuentra el Windows que sigue en este PC y copia tus Documentos, Imágenes, Música, Vídeos y marcadores del navegador a tu nueva carpeta personal. Windows solo se lee, nunca se modifica.

¿Te preguntas dónde están el menú de inicio o el Administrador de tareas? La guía tiene una tabla que te dice dónde está todo.

Instala lo que quieras

Abre la Tienda de software (el icono de bolsa en la barra de tareas) para ver miles de aplicaciones gratuitas: oficina, juegos y herramientas creativas. Tú eliges; no se instala nada a tus espaldas.

La web, a tu manera

Firefox ESR llega directamente de Debian, sin políticas de navegador específicas de Dagric ni extensiones preinstaladas. Tú controlas la privacidad, la búsqueda, la página de inicio y los complementos desde los menús de Firefox.

Tus archivos

Archivos (el icono de carpeta) es lo que en Windows se llamaba Explorador de archivos. Las unidades de Windows, las memorias USB y las carpetas compartidas en red funcionan directamente, sin configurar nada. Las aplicaciones de aquí tienen nombres que indican lo que hacen; si buscas los nombres originales (Dolphin, Okular, Ark), también las encontrarás.

Actualizaciones, a tu manera

Las actualizaciones de seguridad se instalan en silencio en segundo plano. El ordenador nunca se reinicia solo: tú lo reinicias cuando te venga bien.

¿Necesitas ayuda?

La guía de usuario integrada explica impresoras, Wi-Fi, aplicaciones, copias de seguridad y atajos de teclado; funciona sin conexión, en este ordenador. También incluye soluciones para los problemas que surgen de verdad: sin sonido, Wi-Fi que no se conecta, una unidad de Windows que no se abre.

Cada aplicación, explicada

Abre el Manual de Dagric desde el menú de inicio para ver una página sobre cada aplicación de aquí: qué es, qué reemplaza en Windows y cómo hacer las cinco cosas que de verdad harás con ella. Su buscador conoce los nombres antiguos: escribe Notepad y obtendrás el editor de texto. Está en este ordenador; no necesita internet.

Puedes cambiarlo más tarde

El asistente de configuración que viste al iniciar sesión por primera vez sigue ahí: abre el menú de inicio y escribe Configurar Dagric para repasar de nuevo los colores, el fondo de escritorio, el tamaño del texto y la barra de tareas. Si el texto es demasiado pequeño, Tamaño del texto lo arregla por sí solo, y vuelve a la configuración anterior después de veinte segundos si no te gusta el resultado.

Te resultará familiar

Barra de tareas, menú de inicio, bandeja del sistema: donde esperas encontrarlos. Pulsa Ctrl+Mayús+Esc para abrir el Administrador de tareas, igual que en Windows, y Meta (la tecla ⊞) para abrir el menú de inicio.

Personaliza tu escritorio

¿Prefieres una barra de tareas centrada, una barra mínima o una barra clásica? Abre Dagric Looks desde el menú de inicio (o el Hub) y elige un diseño con un clic; Pro añade diseños con dock y barra superior. Después abre Dagric Styles para elegir el ambiente: claro u oscuro, colores de énfasis, fondos de escritorio, incluso efecto cristal. Combina cualquier Look con cualquier Style. Puedes volver atrás cuando quieras: es tu escritorio.

Todo en un mismo lugar

Abre Dagric Hub desde el menú de inicio (pulsa Meta y escribe Dagric Hub): reúne en una sola ventana la configuración de controladores, la Revisión de seguridad, las guías y el manual, las herramientas de apariencia y los instaladores de un clic para Steam, Bottles y los demás. Si tienes una tarjeta NVIDIA, Dagric también te ofrece el controlador automáticamente la primera vez que inicias sesión.

Seguro por defecto

El confinamiento de AppArmor, un kernel reforzado y un cortafuegos están activados antes de que cambies nada. Ejecuta la Revisión de seguridad desde el menú de inicio cuando quieras para ver tu nivel de protección y el estado de cada unidad; Dagric te avisa con antelación si un disco empieza a fallar. En las instalaciones con btrfs, una actualización defectuosa se puede deshacer desde el menú de arranque; las instantáneas son automáticas.

La promesa de Dagric

  • Sin telemetría: no hay nada que desactivar
  • Sin publicidad, en ninguna parte del sistema
  • No necesitas ninguna cuenta, nunca
  • Sin basura preinstalada: cada aplicación de este equipo se eligió deliberadamente
  • Cada línea del sistema es abierta y verificable

Si nos necesitas

Todo lo anterior funciona sin conexión a internet. Cuando necesites la web, estas son las únicas tres direcciones que merece la pena recordar; las escribimos completas porque el ordenador con el que necesitas ayuda podría ser precisamente el que no funciona:

  • Ayuda de una persona — dagric.com/support
  • Algo no funciona — dagric.com/bugs
  • Qué añade Dagric OS Pro — dagric.com/pro
