Welcome to Freehold OS

A freehold is property you own outright. This computer is now yours.

Install anything

Open Discover (the bag icon in the taskbar) to browse thousands of free apps — office, games, creative tools. You choose; nothing is ever installed for you.

Your files

Dolphin (the folder icon) is your file manager. Windows drives, USB sticks, and network shares all work out of the box.

Updates, your way

Security updates install silently in the background. The computer never restarts by itself — you reboot when it suits you.

Feels familiar

Taskbar, start-style launcher, system tray — where you expect them. Press Ctrl+Esc for the system monitor, Meta to open the launcher.

The Freehold promise

  • No telemetry — there is nothing to opt out of
  • No advertising, anywhere in the system
  • No account required, ever
  • No preinstalled junk — every app on this machine was chosen deliberately
  • Every line of the system is open and inspectable
